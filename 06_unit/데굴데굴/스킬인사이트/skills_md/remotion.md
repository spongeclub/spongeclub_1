## 한 줄 요약
• React 코드로 영상을 만드는 Remotion 작업 시, 자주 빠지는 함정과 핵심 패턴을 한 번에 주입해 주는 도메인 스킬. "어떻게 짜야 하는지"를 매번 검색하지 않고도 1차 결과물까지 직진할 수 있게 해준다.

## 주요 내용
• 영상의 움직임(페이드, 이동 등)은 "지금 몇 번째 장면이지?"를 매 순간 물어보고 그에 맞춰 투명도·위치를 계산하는 방식으로만 만든다. (CSS 애니메이션 같은 웹사이트용 방식은 영상으로 뽑으면 깨짐)
• 영상을 여러 구간으로 나눠서, 한 구간이 끝나기 전에 다음 구간을 살짝 겹치게 놓으면 자연스러운 페이드 전환이 된다.
• 사진·동영상·폰트 같은 파일은`public/`폴더에 넣고 정해진 방법으로 불러와야 영상에 제대로 들어간다.
• 영상 크기(가로·세로), 초당 프레임 수, 전체 길이는딱 한 곳에 정해두는 파일(`Root.tsx`)이 있다. 거기만 바꾸면 끝.
• 30초짜리 영상 전체를 뽑는 건 몇 분 걸리니까,중간 한 장면만 사진으로 뽑아서 확인하는 방법이 따로 있다. 이걸로 빠르게 검토.

## 써본 상황 + 결과
• 어떤 상황에서: 짧은 세로형 소개 영상(1080×1920, 30초)을 처음부터 만들어야 했음. 조건은 한국어 폰트(Pretendard), 어두운 배경에 노란 포인트, 부드러운 페이드, 그리고 인스타·틱톡에서 화면 위아래에 뜨는 UI 버튼들에 글자가 가려지지 않도록 안전 영역(safe zone) 확보.
• 어떻게 썼는지: 빈 폴더에서 명령어 한 줄로 프로젝트 틀을 만들고 → 색깔·여백 같은공통 설정을 먼저 한 파일에 모아두고→ 본문 3개 장면을 시간 순서로 배치 → 각 장면의 핵심 순간 3장만 사진으로 뽑아 "글자가 안전 영역 안에 들어왔나, 폰트가 제대로 적용됐나" 눈으로 확인 → 최종 30초 영상 출력.
• 결과 / 인사이트: AI한테 그냥 "Remotion으로 영상 만들어줘"라고 하면 보통 웹사이트용 방식(CSS 애니메이션)으로 코드를 짜서 영상으로 뽑을 때 깨진다. 근데 이 스킬을 켜고 시작하면 처음부터 옳은 방식으로 코드가 나와서 다시 고치는 시간이 거의 없다. 결과물 디자인이 마음에 들었냐 안 들었냐는 별개로,"일단 한 번 돌아가는 영상"까지 도달하는 속도가 확 빨라지는 종류의 도구.
