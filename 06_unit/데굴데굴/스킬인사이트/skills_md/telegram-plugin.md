## 한 줄 요약
• 휴대폰 텔레그램으로 메시지를 보내면 컴퓨터의 Claude가 그 메시지를 받아서 처리할 수 있게 해주는 공식 플러그인. _길 가다, 침대 위에서, 회의 중에 떠오른 생각_을 휴대폰에서 한 줄 던지면 Claude가 받아서 정리해줌.

## 주요 내용
• 텔레그램에 본인 전용 봇을 만들고, 그 봇의 비밀번호를 컴퓨터에 저장하면 연동 끝
• "이 봇한테 메시지 보낼 수 있는 사람" 명단을 정해놓을 수 있음 (보통 본인만 — 모르는 사람이 못 끼어들어옴)
• 봇한테 메시지 보내면 → 컴퓨터의 Claude가 그 메시지를 받아서 봄
• Claude는 다시 답장을 보낼 수 있고, 이모지(✅:+1: 등)로 반응도 할 수 있고, 이전에 보낸 답장을_수정_도 할 수 있음
• 사진·파일도 보낼 수 있고, Claude가 받아서 읽을 수 있음
• 안전장치 내장 — 누가 봇한테 "관리자 권한 줘" 같은 위험한 요청을 보내도 무시함

## 써본 상황 + 결과
• 어떤 상황에서: 휴대폰에서 떠오르는 생각·아이디어·메모를 즉시 던지면, 노트북의 Claude가 자동으로 받아서 _정해진 폴더에 시간 순으로 저장 + 비슷한 옛 메모와 연결 + 태그 붙이기 + 답장으로 정리 결과 알려주기_하는_개인 캡처 시스템_을 만들고 싶었음. (Notion이나 Obsidian 같은 별도 앱 대신,_손에 가장 익은 텔레그램_으로 입력하는 게 핵심.)
• 어떻게 썼는지: 텔레그램에서 본인용 봇 1개 만들고 → 봇 비밀번호를 컴퓨터에 저장하고 → "이 봇한테 메시지가 오면 이렇게 처리해" 라는 규칙을 Claude한테 적어준 다음 → 테스트로 메시지 한 줄 보내봄.
• 결과 / 인사이트: 봇은 잘 만들어졌는데테스트 메시지가 바로 도착 안 함. 이유를 찾아보니 — Claude Code 프로그램을_지금 켜놓고 있을 때만_메시지가 처리됨. 노트북 덮어놓거나 Claude 안 열려있을 때 보낸 메시지는 그냥 흘러가버림. "어디서든 던지면 알아서 정리되는 시스템"을 원했다면별도 프로그램을 더 만들어야한다는 걸 알게 됨 (한 단계 더 큰 작업). -&gt; **이후에 GitHub Actions을 통해 "자동발송"까지 자동화 설정함.**
