## 한 줄 요약
- 보도자료(Press Release) 구조와 톤을 잡아주는 스킬.
  리드문 → 부연설명 → 대표 코멘트 → 기업 소개의 표준 5단 구조로 자동 생성됨.

## 주요 내용
- 5W1H 리드문, 부연설명, 대표 인용구, 기업 소개 등 언론사 게재 수준의
  보도자료 구조를 자동으로 잡아줌
- 미디어 피칭 전략, SNS 홍보 카피, 캠페인 기획까지 확장 가능
- 사용자 프로젝트 지침(브랜드 톤·금칙어·SEO 규칙)과 결합해 사용하면
  맞춤형 보도자료 산출 가능

## 써본 상황 + 결과
- 어떤 상황에서: 시놀(5060 중장년세대 소셜 플랫폼)의 6월 글램핑
  단체미팅 행사 보도자료를 작성해야 했음. 캠핏(캠핑 플랫폼)과의
  공동 주관 행사라 두 회사 정보를 모두 다뤄야 했고, "5060 소개팅"
  키워드를 SEO 측면에서 자연스럽게 녹여야 하는 요구사항이 있었음.
- 어떻게 썼는지:
  ① 시놀 프로젝트 커스텀 인스트럭션(브랜드 톤·금칙어 규칙)을 먼저 세팅
  ② "보도자료 쓸 거야"로 스킬 호출 → 필요한 정보 6가지(주제·일자·
     코멘트 화자 등) 자동 질의
  ③ 캠핏 정보는 정책브리핑·머니투데이 웹 검색으로 검증 후 삽입
  ④ 리드 → 부연설명 → 코멘트 → 기업 소개 순으로 단계별 수정·보강
- 결과 / 인사이트:
  ✓ 빈 상태에서 약 30분 만에 배포 가능한 수준의 보도자료 완성
  ✓ 스킬이 구조(뼈대)를, 프로젝트 지침이 톤(살)을 담당하는 분업
    구조가 가장 효율적이라는 것을 체감
  ✓ 사실 검증이 필요한 항목(파트너사 데이터, 수치)은 스킬이 자동으로
    [확인 필요] 플래그를 띄워줘서 누락 방지에 유용
  ✓ 한계: 스킬은 "구조"만 잡아주고, 브랜드 고유 톤·금칙어는 프로젝트
    지침이 없으면 일반적인 보도자료처럼 나옴. 두 가지가 결합되어야
    힘이 발휘됨
