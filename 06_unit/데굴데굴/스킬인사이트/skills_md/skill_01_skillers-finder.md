## 한 줄 요약
• 깃허브 못 다뤄도, 클로드한테 말만 걸면 원하는 스킬이 자동 설치됨 (진입장벽 0)

## 주요 내용
• skillers-finder = 클로드 코드 스킬을 컨텍스트 기반으로 추천 + 자동 설치해주는 도구
• 깃허브 직접 안 뒤져도 되고, "이거 쓸게" 한 마디로 설치까지 끝남

## 써본 상황 + 결과
**- 어떤 상황에서:**
• Claude Code 스킬이라는 게 있다는 것도 스폰지클럽 하면서 처음 알았고, 관련 지식이 0인 상태였음
• 뭘 다운로드해야 하는지, 어디서 받아야 하는지조차 몰랐음
• 특히 깃허브(GitHub) 웹사이트 자체가 너무 낯설어서 들어가도 어디를 눌러야 할지 막막했음
**- 어떻게 썼는지:**
• 오늘 에밀리 수업을 들으면서 skillers-finder를 처음 써봄
• 깃허브를 직접 뒤져보지 않아도, 클로드한테 말만 걸면 알아서 적합한 스킬을 찾아 추천해줌
• "이거 쓸게" 하니까 자동으로 설치까지 되어서, 제가 손댄 게 거의 없었음
**- 결과 / 인사이트:**
• 깃허브 못 다뤄도 원하는 스킬을 바로 받을 수 있다는 게 진짜 컸음. 진입장벽이 0에 가까워짐
• "뭘 받아야 할지 모르는 사람"이 가장 시간 많이 쓰는데, 그 부분을 도구가 대신 해주니까 시작 자체가 가능해짐
• 혼자 깃허브에서 헤매면서 포기했을 시간을, 바로 "써보는 경험"으로 바꿔준 게 가장 좋았음
• 에밀리 공유회 들으니까 "왜 이 스킬을 쓰는지"까지 이해돼서, 다음에 혼자서도 다시 돌려볼 수 있을 것 같음
