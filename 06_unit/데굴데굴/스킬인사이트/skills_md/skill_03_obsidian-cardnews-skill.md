## 한 줄 요약
• Obsidian에서 작성한 마크다운 파일을 인스타그램 카드뉴스(캐러셀) 로 자동 변환해주는 스킬

## 주요 내용
• md파일을 주면 HTML 캐러셀 (슬라이드 8장, 1080×1080px) 로 출력
• 디자인 시스템 자동 적용 (3색 팔레트, Pretendard 폰트, 외부 의존성 없음)
• 마스코트 캐릭터 등록해서 슬라이드에 일관되게 사용

## 써본 상황 + 결과
• 어떤 상황에서: 2주차 과제 제출 후, sns 인증을 하기 전에
• 어떻게 썼는지: 1주차, 2주차 내 과제 md 파일 경로를 알려주고 스킬 써달라 함
• 결과 / 인사이트: 과제 내용을 보고 알아서 카피를 만들어 카드뉴스까지 만들어주는 게 신기했는데, 내가 sns에 말하고 싶은 부분만 써주지는 않아서 몇 번 수정 요청함.
    ◦ 인스타그램에 올리려고 했는데 이미지 내에 텍스트, 캐릭터 크기가 상대적으로 작고 여백이 많아 수정요청함.
    ◦ 이 외에도 원하는대로 텍스트 내용, 크기, 위치 등 빠르게 수정하고 싶은데 클로드와 반복 수정하는 게 너무 오래걸려서 결국 디자인이랑 내용 좀 참고해서 canva로 만들었어요. 다음엔 canva로 수정할 수 있게 만들어달라고 하려고요!
