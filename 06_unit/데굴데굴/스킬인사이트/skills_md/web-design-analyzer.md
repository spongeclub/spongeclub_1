  해부해주는 디자인 분석 스킬 (좋다/나쁘다 평가가 아닌 토큰 추출)

## 주요 내용
- 분석 항목: 색 팔레트, 타이포그래피, 레이아웃 그리드,
  여백·간격, 시각 계층, 컴포넌트 패턴
- "이런 느낌으로 만들어줘" 같은 막연한 요구를 디자인 토큰으로 번역
- 트리거: "디자인 분석", "레퍼런스 분석", "벤치마킹",
  "디자인 뜯어봐줘", "이런 느낌으로 만들어줘"
- 출처: 커뮤니티 (anthropic-skills 플러그인, 한국어 description)

## 써본 상황 + 결과
- 어떤 상황에서: Claude가 강의 교안 디자인을 자꾸 구리게 줘서
  기존 교안의 디자인 토큰을 강제 입력하고 싶었음
- 어떻게 썼는지: "1주차_교안_표지.png 디자인 뜯어봐줘.
  색 팔레트·폰트 위계·여백 토큰으로 추출"
- 결과 / 인사이트: 이번 공유회/다른 강의준비들을 하면서 필요한 디자인을 통일 시킬때 사용해보니 훨씬 일관성을 잘 지켜주는것 같아요!
