## 한 줄 요약
- 디자인이 하나도 없던 도구를 → 캔바 풍 대시보드 + 디자이너 풍 카드뉴스 7장 출력까지

## 주요 내용
- skillers-finder = "이런 상황에 맞는 스킬 추천해줘" 하면 깃헙·레딧 직접 뒤져서 8~10개 골라주는 스킬. 이걸로 두 번 추천받음
- interface-design = 대시보드 화면 디자인을 한 마디로 갈아엎어주는 스킬
- claude-design + playwright-skill 조합 = AI 카드뉴스를 매번 다른 풍으로 만들어주는 두 스킬 조합

## 써본 상황 + 결과
- 어떤 상황에서: AI 카드뉴스 자동 생성 도구를 만들고 있었는데 (1) 대시보드 화면에 디자인이 하나도 없음 (2) 만들어진 카드뉴스도 매번 같은 흰 글씨 패턴이라 답답
- 어떻게 썼는지: skillers-finder 한테 두 번 추천받음 → "Canva 풍으로 바꿔줘" / "조합 깔아줘" 한 마디씩 → Claude가 자동 설치 + 코드 갈아끼움
- 결과 / 인사이트: 대시보드는 캔바 풍 보라→핑크 그라데이션으로, 카드뉴스 7장은 매번 다른 풍 (표지·거대 숫자·인용·본문 spread) 으로. 초보자도 해냄
