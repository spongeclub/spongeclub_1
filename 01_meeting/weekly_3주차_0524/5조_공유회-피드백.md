스폰지클럽 3회차 5조 조모임

스폰지클럽 3회차 5조 조모임은 각 조원이 이번 주 제작한 AI 활용 프로젝트를 순서대로 발표하고, 다음 발표자가 피드백을 제공하는 방식으로 진행되었다. 총 9명이 참여하였으며, 오혜인 대신 다른 조원이 진행을 맡았다. 발표 순서는 비키 → 상임 → 보미 → 거북이꿈 → 로이칸 → 덕수 → 키노 → 이안 → 윤재은 → 헤이즐 순이었고, 각 발표는 5분 내외로 진행되었다.

---

## 발표 내용 요약

### 비키 — 약기법 체크 및 성분 검색 툴

일본 약기법(화장품·건강기능식품 광고 규제법) 준수 여부를 자동으로 검토하는 툴과 성분명 변환 검색 툴을 하나의 앱으로 통합하여 제작하였다. 약기법 체크 기능은 화장품 카테고리와 상품군을 선택하면 적용 법규가 자동으로 표시되고, 분석 결과를 안심형·균형형·어필형·마케팅형 네 가지 답안으로 제공한다. 성분명 변환 기능은 히알루론산 등 성분을 입력하면 일본어·영어·학명·한국 식약처 표시명과 변형 표기, 오타 사례, 일본 시장 인지도까지 출력한다. 데이터 원천은 Claude의 웹 서치 기능이며, 공식 사이트를 우선 참조하도록 프롬프트를 설계하여 신뢰도를 높였다. 기존에는 일본 법률사무소 의뢰나 해외 IP 차단 사이트 우회 등으로 시간이 많이 소요되던 작업을 대폭 단축하였다.

### 상임 — 알뜰폰 요금제 비교 앱

초기에는 Claude와 티로(Tiro)를 활용해 영상 시청 시간 관리 앱을 시도하였으나 마음이 닿지 않아 중단하였다. 이후 알뜰폰 사용자들이 시즌마다 요금제를 비교·변경하는 불편함에 착안하여, 엑셀 데이터를 기반으로 요금제 비교 화면을 구현하였다. 결과물이 데이터를 단순 시각화하는 수준에 그쳐 아쉬움이 있었으며, 통신사 사이트 대부분이 텍스트 크롤링을 차단하고 있어 자동화에 한계가 있었다. 향후 블로그 관련 프로젝트와 병행할지 고민 중이다. 진행자는 블로그는 실제 운영하면서 발전시키고, 알뜰폰 앱도 OS 개선 차원에서 병렬로 진행할 것을 제안하였다.

### 거북이꿈 — 네이버 쇼핑 인사이트 키워드 분석 앱

네이버 데이터랩의 쇼핑 인사이트에서 인기 검색어를 크롤링하여 복합 키워드를 의미 단위로 분해하고 빈도를 정량 분석하는 앱을 제작하였다. 예시로 화장품 베이스 메이크업 '쿠션' 카테고리에서 20대와 50대의 검색 키워드를 비교하였으며, 20대는 헤라 블랙쿠션·정샘물·입생로랑 순, 50대는 이지투기미쿠션·헤라 블랙쿠션·입생로랑 순으로 나타났다. 소상공인이나 신규 시장 진입 시 빠른 시장 스터디 도구로 활용 가능하며, 연령별·기간별 데이터를 축적하면 다양한 분석 소스로 발전시킬 수 있다. 네이버가 공식 API를 제공하지 않아 HTML 크롤링 방식을 사용하였으며, 해외 IP 차단 등 제약이 있다.

### 덕수 — 레퍼런스 이미지 아카이빙 툴 (핫세트)

패키지 디자이너로서 레퍼런스 이미지를 체계적으로 정리하기 위한 아카이빙 앱을 제작하였다. 이미지를 업로드하면 후가공 유형(단지형, 유광 등) 키워드가 자동 선택되고 제목도 자동 입력되어 개인 아카이브를 구성할 수 있다. 잡타입 등 특정 유형으로 필터링하면 해당 레퍼런스 이미지가 자동 분류되어 표시된다. 향후 브랜드 키트와 통합하여 발전시킬 계획이며, AI 자동 분류 기준의 명확화가 과제로 남아 있다. 조원들로부터 개인 사용자에게도 유용할 것이라는 긍정적 반응을 받았다.

덕수는 인하우스 패키지 디자이너로 외주도 수행한다는 사실이 확인되어, 한 조원이 추후 연락 의사를 밝혔다.

### 이안 — 유튜브 영상 제작 자동화 에디터

정보 위주의 유튜브 영상(18~20분 분량)을 효율적으로 제작하기 위한 커스텀 에디터를 Claude Code로 구현하였다. 콘티 생성, 이미지 생성(외부 ChatGPT 모델 활용), 컷별 이미지 선택, 모션·자막 싱크, 영상 렌더링까지 일련의 작업을 지원하며, 모든 조작이 왼손 단축키(WASD, QEW 등)로 가능하도록 설계하였다. 4분짜리 영상 렌더링에 4분 이상 소요되는 비효율 문제를 발견하여, 에디터 내 렌더링 대신 프로젝트 파일을 Final Cut Pro나 키컷(Keycut)으로 내보내 하드웨어 가속 렌더링을 활용하는 방향으로 전환하였다(약 6배 속도 향상 예상). 코딩 작업은 Codex가 담당하였으며, 로컬 모델 연동도 추진 중이다. 피드백으로는 렌더링·자막·효과음 등 작업을 스프린트 단위로 분리하여 진행하는 방식이 제안되었다.

### 헤이즐 — 헤어숍 원장 대상 리드 수집 도구 (헤어짱 서비스)

회사에서 운영 중인 헤어숍 파트 원장 대상 예약·매출 관리 솔루션 '헤어짱'의 영업 리드 수집을 목적으로 기획하였다. Claude와 Gemini를 활용해 커뮤니티 글을 분석하여 원장들의 주요 페인포인트(세무 처리, 인스타그램 광고, 네이버 플레이스 노출)를 도출하였다. 광고 콘텐츠 제안 도구와 세무 도구는 정확성 및 분쟁 리스크로 보류하고, 네이버 플레이스 리뷰 답변 생성기와 플레이스 진단 도구를 우선 구현하였다. 리뷰를 붙여넣으면 답변을 자동 생성하면서 리드 정보를 수집하는 구조이다. 조원으로부터 맞춤 프로모션 생성기(상황별 이벤트 제안 → 이메일 발송) 추가를 제안받았다.

## 디자인 꿀팁 공유 (헤이즐)

헤이즐은 브랜드별 디자인 MD 파일을 모아놓은 사이트 링크를 채널에 공유하였다. 해당 사이트에서 원하는 기업(예: 애플)의 디자인 시스템 파일을 복사하여 Claude 프로젝트에 지침으로 등록하면, 컬러값·텍스트 사이즈 등을 일관되게 유지하는 PPT·보고서 템플릿 생성이 가능하다. Claude Design에서 직접 작업하면 퀄리티는 높으나 토큰 소모가 크므로, Claude에서 초안을 작성한 뒤 빈 파일로 내보내 Claude Code에서 디자인을 얹는 방식이 권장된다. PPT 내 도형 그래프에 엑셀 데이터를 연동하는 것도 가능하다.

## MVP 투표 및 기타 사항

발표 종료 후 구글 시트에서 셀 색칠 방식으로 MVP 투표를 진행하였으며, 헤이즐이 최다 득표(4표)로 이번 주 MVP로 선정되었다. 로이칸은 이번 주 발표를 진행하지 못하였다. 보미는 네트워크 불안정으로 화면 공유가 어려워 발표를 충분히 진행하지 못하였다.

오프라인 모임은 금요일 저녁과 일요일 오전 중 선택 가능하며, 사전 조사 결과를 바탕으로 일정이 확정될 예정이다. 조모임은 55분에 메인 회의실로 이동하는 것으로 마무리되었다.
