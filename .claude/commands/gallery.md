갤러리에 올릴 산출물 노트를 템플릿 기반으로 생성한다.
**노트 1개 = 갤러리 카드 1개.** 산출물이 여러 개면 각각 하나씩 만든다.
내용은 채우지 않고 **빈 템플릿만 올바른 위치·파일명으로** 생성한다 (멤버가 직접 채움).

## 트리거 문구
사용자가 다음 중 하나를 말하면 이 커맨드를 실행:
- `/gallery`
- "갤러리 노트 만들어줘"
- "산출물 노트 만들어줘"

## 실행 절차

### 1. 멤버 확인

- `99_meta/멤버목록.md`에서 사용자 본인의 **조와 닉네임** 확인
- 모르면 물어본다: "본인 조와 닉네임 알려주세요 (예: 3조 코니)"
- `role`(조원/조장/부조장)도 멤버목록에서 확인. 모르면 기본 `조원`.

### 2. 서비스 이름 받기

- 인자로 서비스명이 주어졌으면 그걸 사용
- 없으면 물어본다: "산출물(서비스) 이름이 뭐예요? 여러 개면 쉼표로 나열해주세요"
- **여러 개면 각 산출물마다 노트를 하나씩** 만든다

### 3. 템플릿 읽기

`99_templates/Gallery_submission_template.md`를 읽어 기준 템플릿으로 사용한다.

### 4. 노트 생성 (산출물마다 반복)

각 서비스명에 대해:

**경로**: `02_mission/gallery input/{조}/`
- 폴더가 없으면 만든다.

**파일명**: `{조}_{닉네임}_{서비스명}.md`
- 예: `3조_코니(황초롱)_Kernel Dashboard.md`
- 서비스명을 아직 안 정했으면 임시로 `{조}_{닉네임}_산출물1.md`, `산출물2.md` … 로 만들고 나중에 rename 안내
- 같은 서비스명이 이미 있으면 뒤에 `_2`, `_3` 붙이기

**내용**: 템플릿을 그대로 복사하되 아래만 채운다 (나머지는 빈 칸 유지):
- frontmatter `team` → 조 (예: `3조`)
- frontmatter `member` → 닉네임(본명) (예: `코니(황초롱)`)
- frontmatter `role` → 역할
- 본문 `# <서비스 이름>` → 실제 서비스명

> ⚠️ WHY·Before/After·기능·기술스택·삽질 등 **본문 섹션은 비워둔 채로** 둔다. 멤버가 직접 채운다.

### 5. 완료 보고

생성한 노트 경로를 나열하고 안내:
```
✅ 갤러리 산출물 노트 N개 생성:
  - 02_mission/gallery input/3조/3조_코니(황초롱)_Kernel Dashboard.md
이제 노트를 열어 캡처·WHY·기능 등을 채워주세요.
다 채우면 /submit 으로 제출하면 됩니다.
```

## 주의
- **빈 템플릿만 생성** — 본문 내용을 임의로 지어내지 않는다.
- 파일을 만들 때 **기존 같은 이름 노트를 덮어쓰지 않는다** (있으면 번호 붙이기).
- 멤버 본인 산출물만 만든다.

## 사용 예
```
/gallery                          → 서비스명을 물어보고 생성
/gallery Kernel Dashboard         → 해당 서비스 노트 1개 생성
"갤러리 노트 만들어줘"              → 동일 동작
```
