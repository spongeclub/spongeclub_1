크루 소개 페이지(/members)에 올릴 본인 자기소개 노트를 템플릿 기반으로 생성한다.
**노트 1개 = 크루 카드 1개.** 멤버 1명당 하나만 만든다.
내용은 채우지 않고 **빈 템플릿만 올바른 위치·파일명으로** 생성한다 (멤버가 직접 채움).

## 트리거 문구
사용자가 다음 중 하나를 말하면 이 커맨드를 실행:
- `/profile`
- "자기소개 노트 만들어줘"
- "프로필 노트 만들어줘"

## 실행 절차

### 1. 멤버 확인

- `99_meta/멤버목록.md`에서 사용자 본인의 **조와 닉네임** 확인
- 인자로 닉네임이 주어졌으면 그걸 우선 사용
- 모르면 물어본다: "본인 조와 닉네임 알려주세요 (예: 3조 코니)"

### 2. 템플릿 읽기

`99_templates/Profile_submission_template.md`를 읽어 기준 템플릿으로 사용한다.

### 3. 노트 생성

**경로**: `02_mission/profile input/{조}/`
- 폴더가 없으면 만든다.

**파일명**: `{조}_{닉네임}.md`
- 예: `3조_코니(황초롱).md`
- 같은 이름 노트가 **이미 있으면 덮어쓰지 않고** 안내만 한다 ("이미 있어요 — 그 노트를 열어 채우세요").

**내용**: 템플릿을 그대로 복사하되 아래만 채운다 (나머지는 빈 칸 유지):
- frontmatter `team` → 조 (예: `3조`)
- frontmatter `member` → 닉네임(본명) (예: `코니(황초롱)`)

> ⚠️ 한 줄 소개·SNS·프로필 이미지 등 **본문/SNS 칸은 비워둔 채로** 둔다. 멤버가 직접 채운다.

### 4. 완료 보고

생성한 노트 경로를 안내:
```
✅ 자기소개 노트 생성:
  - 02_mission/profile input/3조/3조_코니(황초롱).md
이제 노트를 열어 프로필 이미지·한 줄 소개·SNS 링크를 채워주세요.
다 채우면 /submit 으로 제출하면 됩니다.
```

## 주의
- **빈 템플릿만 생성** — 내용을 임의로 지어내지 않는다.
- 파일을 만들 때 **기존 노트를 덮어쓰지 않는다**.
- 멤버 본인 노트 1개만 만든다 (산출물처럼 여러 개가 아님).

## 사용 예
```
/profile               → 조·닉네임을 확인하고 본인 노트 1개 생성
/profile 코니          → 코니 노트 생성
"자기소개 노트 만들어줘" → 동일 동작
```
