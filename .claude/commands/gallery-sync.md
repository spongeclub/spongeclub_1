`02_mission/gallery input/` 에 올라온 제출 노트 중 **갤러리에 아직 없는 산출물**을 갤러리에 반영한다.
스크립트가 새 노트를 감지해 `gallery.json`에 추가하고 첨부 이미지를 720px JPEG로 최적화한다.
**반자동**이므로, 추가된 항목은 사람이 한 번 검수/다듬은 뒤 배포한다.

## 트리거 문구
- `/gallery-sync`
- "갤러리 동기화", "새 산출물 반영해줘", "갤러리 업데이트"

## 실행 절차

### 1. 최신화
- repo에서 `git pull` (멤버가 올린 새 노트를 받기 위해)

### 2. 빠진 노트 확인
```
cd _site && npm run sync:gallery:check
```
- "빠진 노트 0" 이면 추가할 게 없음 → 여기서 종료 보고.

### 3. 동기화 실행 (새 노트 추가 + 이미지 최적화)
```
cd _site && npm run sync:gallery
```
- `gallery.json`에 새 항목이 추가되고, `public/assets/gallery/`에 이미지가 생성된다.
- 카테고리는 노트 체크박스(OS/배포사이트/기타) 기준, 없으면 배포링크 있을 때 "배포 사이트".
- MVP는 frontmatter `mvp: true` 반영.

### 4. 검수 / 다듬기 (반자동의 핵심)
자동 추가본은 노트 원문 기반이라 거칠 수 있다. `gallery.json`의 **새로 추가된 항목**만 확인해 다음을 다듬는다:
- **주요 기능**: `features`(일반 배열) → 가능하면 `featuresSimple`(이모지+개조식)로 정리
- **삽질 & 인사이트**: 길면 개조식으로 축약 (이모지는 붙이지 않음)
- **한 줄 소개/설명**: 카드용으로 자연스럽게 다듬기
- **Before/After**: 표 형식 노트는 추출이 비어 있을 수 있으니 확인
- 카테고리/MVP가 맞는지, 이미지 순서가 자연스러운지 확인

> ⚠️ 기존 항목은 스크립트가 건드리지 않는다(notePath 기준 중복 제외). 검수도 새 항목만.

### 5. 빌드 확인 + 배포
```
cd _site && npx astro build   # 정상 빌드 확인
```
- 디자인/콘텐츠 변경이므로 **브랜치 생성 → 커밋 → PR → 스쿼시 머지** (main 보호됨).
- 미리보기로 새 카드·모달 이미지 확인 권장.

## 참고
- 스크립트: `_site/scripts/sync-gallery.mjs`
- `--dry`: 쓰지 않고 파싱 결과만 출력(검증). `--check`: 빠진 노트 목록만.
- 이미지 최적화는 macOS `sips` 사용(로컬 실행 전제).
