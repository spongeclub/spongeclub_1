# 📸 이미지 첨부 설정 통일 부탁드려요

## 왜?

지금 멤버마다 이미지 첨부 저장 위치가 달라서, **다른 사람이 `git pull` 받으면 이미지가 안 보이는** 문제가 생기고 있어요. 볼트 최상위가 `Pasted image xxxx.png` 파일들로 어지러워지기도 하고요.

설정 한 번만 바꾸면 끝납니다. **2분이면 돼요.**

---

## 어떻게 (단계별)

### 1️⃣ 옵시디언 좌하단 톱니바퀴 → `설정` 열기

### 2️⃣ 왼쪽 사이드바에서 `파일 및 링크` 클릭

### 3️⃣ 아래 4개 항목 그대로 맞춰주세요

| 항목 | 값 |
|------|-----|
| **새 첨부 파일을 생성할 위치** | `현재 폴더의 하위 폴더` |
| **하위 폴더 이름** (위 옵션 선택 시 나타남) | `attachments` |
| **새로 생성하는 링크 형식** | `파일에 대한 상대 경로` |
| **[[Wikilink]] 사용** | 🔘 **끄기 (OFF)** |

> 💡 `[[Wikilink]] 사용`을 끄면 이미지가 `![](attachments/xxx.png)` 형식의 표준 마크다운으로 저장돼요. 나중에 홈페이지 빌드할 때도 깨지지 않습니다.

### 4️⃣ 끝! 설정창 닫으면 자동 저장됨

---

## 확인 방법

미션 노트에 이미지 하나 붙여넣어 보세요.

- ✅ 본인 미션 폴더 안에 `attachments/` 가 생기고 이미지가 거기로 들어가면 성공
- ❌ 볼트 최상위에 `Pasted image xxxx.png` 가 생기면 설정이 안 바뀐 상태

---

## 이미 올린 이미지는요?

기존에 흩어진 이미지는 **운영진이 일괄 정리할 예정**이라 본인이 따로 옮기지 않아도 됩니다. 위 설정만 바꿔주시면 앞으로 새로 올리는 것들은 자동으로 제 자리에 들어가요.

---

## 막히면

- 옵션 위치를 못 찾겠으면 **스크린샷 찍어서 카톡방에 올려주세요** — 바로 짚어드릴게요.
- 설정 메뉴가 영문이면 항목명이 다음과 같이 보일 수 있어요:
  - `Default location for new attachments` → `In subfolder under current folder`
  - `Subfolder name` → `attachments`
  - `New link format` → `Relative path to file`
  - `Use [[Wikilinks]]` → **OFF**
