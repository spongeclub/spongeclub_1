# 📦 스폰지클럽 마무리 — 각자 작업물 가져가기

그동안 76명이 함께 쌓아온 공용 레포(`spongeclub_1`)를 정리합니다.
**본인이 만든 작업물은 각자 개인 레포로 가져가 주세요.** 스터디는 끝나도, 만든 건 계속 본인 손에서 자랍니다.

---

## 왜 가져가야 하나요

- 공용 레포는 **곧 읽기전용(archive)으로 동결**됩니다. 기록은 그대로 남지만, **더 이상 수정·커밋은 안 됩니다.**
- 계속 디벨롭하려면 본인이 쓸 수 있는 **개인 레포**가 필요합니다. 거기서 작업해야 커밋이 본인 레포로 쌓여요.
- 백업만 원하는 분도 가져가 두는 걸 권합니다.

> ⏳ 마감 날짜를 따로 박지는 않았습니다. 다만 **동결 전에** 받아가시길 권해요. 동결 후엔 열람만 가능합니다.

---

## 🚀 가장 쉬운 방법 — `/take-mine` (Claude Code)

본인 작업물(노트 + 참조 이미지)만 골라 **개인 GitHub Private 레포로 한 번에 이관**해주는 명령어를 만들어 뒀습니다.

```
/take-mine
```
또는 그냥 **"내 거 내 레포로 옮겨줘"** 라고 말해도 됩니다.

### 순서

**① 딱 한 번, 레포를 최신화합니다.** ⚠️ 이걸 해야 `/take-mine` **명령어 자체가 생깁니다.**
(명령어는 레포에 들어있어서, 오래된 클론에는 아직 없을 수 있어요.)

```bash
git pull
```
- 아직 로컬에 안 받았다면 먼저 클론:
  ```bash
  git clone https://github.com/spongeclub/spongeclub_1.git
  ```
- `git pull`이 충돌난다 / 다른 브랜치다 싶으면 → `git checkout main` 후 다시 `git pull`.

**② 그 폴더를 Claude Code로 엽니다.** (`/take-mine`은 터미널이 아니라 **Claude Code 대화창**에 칩니다.)

**③ Claude Code에 입력:**
```
/take-mine
```
또는 그냥 **"내 거 내 레포로 옮겨줘"**.

끝입니다. 조·닉네임만 확인하면 →
**추가 최신화 → 본인 노트·이미지 추출 → 개인 Private 레포 생성·업로드**까지 알아서 진행돼요.

> 💡 ①의 `git pull`은 **명령어를 받기 위한 단 한 번**입니다. 그 뒤로는 `/take-mine`이 실행될 때 알아서 최신 상태로 맞춰줘요(추가 git 명령 불필요).

**④ 끝나면 안내된 폴더(`../조N_닉네임`)에서 작업하세요.** 거기서 커밋하면 이제 **본인 레포로** 올라갑니다.

> 닉네임은 `99_meta/멤버목록.md` 표기 그대로 쓰면 됩니다 (괄호 앞 = 파일명에 쓰인 이름).
> `gh` 로그인이 안 돼 있으면 한 번 `gh auth login` 해주세요.

## 🛠 수동으로 하고 싶다면

Claude Code 없이 스크립트만 직접 돌려도 됩니다. 레포 루트에서:

```bash
# 1) 내 작업물 추출 (주차별 폴더로 평탄화 + 이미지 포함)
python3 take-mine.py 3조 흐민 --flat
#  → _export/3조_흐민/ 생성

# 2) 공용 레포 밖으로 빼서 독립 레포로
mv _export/3조_흐민 ../3조_흐민
cd ../3조_흐민
git init -b main
git add . && git commit -m "스폰지클럽 작업물 이관"

# 3) 내 GitHub에 Private 레포 만들고 push
gh repo create 3조_흐민-스폰지클럽 --private --source=. --remote=origin --push
```

`--flat` 을 빼면 원본 폴더구조 그대로 추출됩니다 (옵시디언 볼트에 그대로 합칠 때 적합).

## 무엇이 따라오나요

`조N_닉네임` 으로 이름 붙은 본인 노트 전부 — **미션(0~6주차)·프로필·갤러리·draft** + 그 노트들이 참조하는 **이미지**가 함께 나옵니다. 이미지 링크가 안 깨지도록 정리돼요.

---

## ❓ 자주 묻는 것

**Q. 내 거만 정확히 나오나요?**
→ 파일명이 `조N_닉네임`(예: `3조_흐민`)으로 시작하는 것만 골라옵니다. 닉네임 표기만 정확하면 본인 것만 깔끔히 나와요.

**Q. 이미지가 빠지지 않나요?**
→ `![](...)` 와 `![[...]]` 두 방식 모두 해석해서, 본인 노트가 실제 참조하는 이미지만 챙깁니다. 못 찾은 건 끝에 목록으로 알려줘요(대개 템플릿 자리표시자라 정상).

**Q. 이관 후 이전 공용 레포에서 또 작업하면요?**
→ 그건 곧 동결됩니다. **새로 만든 개인 레포 폴더에서** 작업하세요. 별도 설정이 아니라 "어디서 커밋하느냐"의 문제예요.

**Q. 잘 안 돼요.**
→ 본인 조장에게 문의하거나, 조·닉네임과 함께 막힌 지점을 공유해주세요.
