# 📌 과제 제출 규칙 & 이미지 첨부 방법

이번 주부터 적용되는 3가지 공지입니다. **꼭 읽고 본인 노트에 반영해주세요.**

---

## 1️⃣ 과제 제출 — `submitted: true` 체크 필수

**노트를 푸쉬했다고 자동으로 "제출 완료"가 되는 게 아닙니다.**
본인 노트 맨 위 frontmatter의 `submitted` 값을 직접 `true`로 바꿔야 제출로 인정됩니다.

### 제출 처리 방법

본인 과제 노트 맨 위를 보면 이렇게 생긴 영역(frontmatter)이 있어요:

```yaml
---
team: 1조
member: 닉네임
role: 조원
type: ot
week: 0
submitted: false   ← 이 값을
---
```

작성을 다 끝냈으면 **`false` → `true`** 로 직접 수정한 뒤 푸쉬해주세요.

```yaml
submitted: true   ✅ 이렇게
```

### 왜 이렇게 하나요

- 단순히 파일이 있는 것 ≠ 제출 완료 (작성 중인 초안과 구분 필요)
- 이 값을 기준으로 출석/제출 현황판이 자동 집계됩니다
- `false` 상태로 두면 "아직 작성 중"으로 분류돼요

### 조장 퀄리티 체크

각 조의 조장이 푸쉬된 노트를 한 번씩 훑어보고 퀄리티 체크를 합니다.
- 미션 헤더 빠짐 / 빈 섹션 / 깨진 이미지 등이 있으면 멘션
- 보완이 필요하면 다시 수정 후 푸쉬 → `submitted: true` 유지

## 2️⃣ 과제 현황판 — 이번 주 중 오픈

70여 명의 매주 제출 현황을 **한눈에 볼 수 있는 현황판**을 이번 주 안에 만들어 공유합니다.

### 보여질 정보 (예정)
- 조별 / 멤버별 주차 제출 여부
- 미션별 진행 현황
- 누적 제출률, 인사이트 공유 횟수

> 이 현황판이 작동하려면 **모든 멤버가 `submitted: true` 처리**를 해줘야 정확한 집계가 됩니다. ⬆ 위 1️⃣ 다시 한 번 확인 부탁드려요.

## 3️⃣ 이미지 첨부 방법 — `attachments/` 폴더 사용

지금 볼트를 보면 이미지들이 **여기저기 흩어져 있어요**:
- 보관함 루트(`/`)에 `Pasted image XXXX.png`
- 조 폴더 안에 그냥 던져진 스크린샷
- attachments 폴더 안에 들어간 것들

이번 주부터는 **본인 조 폴더 아래 `attachments/`** 로 통일합니다.

### 📂 폴더 구조 (이미 만들어져 있어요)

```
02_mission/
└── 1주차_0510/
    └── 1조/
        ├── 1조_닉네임_1주차_submit.md   ← 본인 노트
        └── attachments/                  ← 여기에 이미지 자동 저장!
            └── 스크린샷.png
```

### ⚙️ 옵시디언 설정 — 한 번만 바꿔두기 (필수)

이 설정을 안 바꾸면 이미지 붙여넣기 할 때마다 보관함 루트에 떨어져서 매번 손으로 옮겨야 해요.

1. 옵시디언 좌측 하단 **⚙️ 설정** 클릭
2. **파일 및 링크** (영문: Files and links) 메뉴 선택
3. **새 첨부 파일의 기본 위치** (Default location for new attachments) 항목을 다음으로 변경:
   - ✅ **현재 파일이 있는 폴더 아래의 하위 폴더** (Subfolder under current folder)
4. 바로 아래 입력창에 폴더명 입력:
   - ✅ `attachments`
5. **첨부 파일 폴더 만들기** 옵션이 있으면 **켜기** (없으면 무시)

### 🖼️ 이미지 추가하는 3가지 방법 (셋 다 OK)

설정을 위처럼 바꿔두면 **어떤 방법으로 넣어도 자동으로 `attachments/`에 저장**돼요.

**방법 A — 복사 붙여넣기 (가장 빠름)**
- 스크린샷 찍기 → 노트 본문에서 `Cmd + V` (Mac) / `Ctrl + V` (Windows)
- 노트에는 자동으로 `![[Pasted image XXXX.png]]` 가 들어감

**방법 B — 드래그 앤 드롭**
- 파인더/탐색기에서 이미지를 노트 본문 위로 끌어다 놓기

**방법 C — 직접 폴더에 넣고 링크 (수동)**
- 본인 조 `attachments/` 폴더에 이미지 파일을 직접 복사
- 노트에서 `![[이미지파일명.png]]` 또는 `![설명](./attachments/이미지파일명.png)` 입력

### ✅ 잘 됐는지 확인

푸쉬 전 본인 노트의 이미지 영역을 봤을 때:
- 이미지가 **보여지면** → OK ✅
- `![[XXX.png]]` 처럼 빨간색/깨진 링크로 보이면 → 파일 위치 잘못됨 ❌
  - 파인더/탐색기로 본인 조 `attachments/` 폴더에 실제 파일이 있는지 확인

### ⚠️ 자주 하는 실수

| 실수 | 결과 | 해결 |
|------|------|------|
| 보관함 루트(`/`)에 이미지 떨어짐 | 다른 조에서도 보임 (지저분) | 위 ⚙️ 설정 변경 |
| 절대경로 (`/Users/...`)로 링크 | 다른 사람 컴퓨터에서 안 보임 | `![[파일명.png]]` 또는 상대경로 사용 |
| 같은 파일명 중복 | 옵시디언이 자동으로 ` 1`, ` 2` 붙임 | 신경 쓰지 않아도 됨 |
| 너무 큰 파일 (10MB+) | 깃 푸쉬 느려짐, 레포 무거움 | 스크린샷은 PNG로, 사진은 1080p 이하로 |

## ❓ FAQ

**Q. 기존에 보관함 루트에 떨어진 `Pasted image XXX.png`는 어떻게 해요?**
→ 본인이 작성한 노트가 참조하는 이미지면 본인 조 `attachments/` 폴더로 옮기고, 노트의 링크도 같이 수정해주세요. 어떤 게 본인 것인지 모르겠으면 그대로 두면 됩니다 (조장이 정리 시에 처리).

**Q. `submitted: true`로 바꾸고 푸쉬했는데 이후에 수정하면요?**
→ `submitted: true` 유지한 채로 수정 → 푸쉬하면 됩니다. 다시 `false`로 내리지 마세요.

**Q. 이미지 안 보이는데요?**
→ `![[파일명.png]]` 형식이 깨졌거나, 파일이 `attachments/` 폴더에 실제로 없는 경우입니다. 옵시디언 좌측 사이드바에서 본인 조 `attachments/` 폴더를 펼쳐 파일이 있는지 확인.

**Q. 첨부 파일 위치 설정이 안 바뀌어요 (옵션이 회색)**
→ 옵시디언 버전이 너무 오래됐을 수 있습니다. 최신 버전으로 업데이트 후 다시 시도.

---

**요약 — 이번 주 세 가지 액션**
1. 본인 노트 frontmatter `submitted: true` 로 바꾸기 (제출 완료 시)
2. 옵시디언 설정 → 파일 및 링크 → 첨부 파일 위치를 `attachments` 하위 폴더로 변경
3. 현황판 오픈을 기다리면서, 본인 누적 제출 잘 챙기기 ✊
