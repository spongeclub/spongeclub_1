### 과정 (타임라인별 + 삽질)
**5/10~11 — 디스코드로 시작**  
텔레그램 계정이 있었는데 핸드폰 교체후 사용하지 않았고, 텔레그램은 핸드폰번호 기반인데도 계정이 있으면 SMS를 보내주지 않아 결국 텔레그램 측 이메일 문의를 넣어둠. 디스코드로도 구현이 가능하다고 하셔서 디스코드 연동 진행

**5/11~3 — CCR로 아침 인사 자동화 시도 → 실패**  
아침인사 자동화부터 만들고, 일정까지 알림달라고 했음. 현재 쓰고 있는 네이버 캘린더 연동이 안되서(네이버에서 외부로 동기화 공유 제공X) 일단 ,구글캘린더 연동함. 근데 디스코드에서 대화는 봇이랑 DM으로 하고, 알림은 DM이 아닌 채널로 보내줌. 결정적으로 실제 오전에 알림을 제대로 못보내줌.
==`CLAUDE 입장`== Claude Code Remote(CCR)로 매일 오전 8시 디스코드 웹훅 전송을 시도. 테스트는 성공했으나 실제 루틴 실행 시 Anthropic 클라우드 IP가 Discord·Google iCal·Telegram Bot API 모두에서 **403 차단**되는 것을 확인. CCR은 외부 API 호출이 필요한 개인 자동화에 근본적으로 부적합.

**5/13 — 텔레그램으로 전환**  
디스코드 알림자동화 실패를 겪고, 나도 텔레그램 쓰고 싶다!!를 외치며 텔레그램 문의 답변은 오지 않았으나 다시 로그인을 시도해보니, 계정을 삭제해줬는지 SMS코드를 보내줬고 새로 계정을 생성할 수 있었음.(오예!) 그래서 디스코드 대신 텔레그램으로 다시 연동. 연동코드 잘 입력되었는데 중간에 왜인지 모르게 끊겨서 다시 연동 끊고 재연동하기도 하며 결국 연동 성공.
클로드가 알아서 하긴 했는데 자동 알림이 CCR이 아닌 로컬에서 실행하는 걸로 바뀐 것 같음.
==CLAUDE 입장== CCR은 외부 API 호출에 쓰면 안 된다. Anthropic 클라우드 IP는 Discord, Google, Telegram 등 주요 서비스에서 차단된다. CCR은 Claude 자체 도구(파일 읽기·쓰기, 코드 실행 등)를 활용하는 루틴에만 적합하고, 외부 웹훅·API를 쓰는 개인 자동화는 로컬에서 돌려야 한다.
