# 2주차 과제 — 달빛그린

## 미션1: 각자만의 정의로 [운영체제]라고 정의내리는 OS 구현

### Summary

유튜브에서 본 내용을 그냥 흘려보내지 않기 위해 **콘텐츠 생산 OS**를 설계하고, 실제로 작동하는 웹 앱으로 구현했다.
핵심 구조는 세 층이다: ① 고유한 캐릭터가 전체 콘텐츠의 말투·시각·기준을 고정하고, ② 유튜브 요약(전반부) + 개인 인사이트(결론부)가 콘텐츠 골격을 이루며, ③ 그 결과물이 캡컷에 바로 쓸 수 있는 클립별 대본으로 자동 출력된다.

**OS 선언문**: 나는 캐릭터로 말하고, 유튜브로 뼈대를 세우고, 인사이트로 마무리한다.

| **역할** | 모든 콘텐츠에서 "이 캐릭터라면 어떻게 말할까?"를 기준으로 삼는 필터 |

#### 2. 콘텐츠 구성 템플릿

```
[전반부 — 유튜브 요약, 약 30~35초]
- 훅: 영상의 핵심 문제의식 한 줄
- 포인트 1 / 포인트 2 / 포인트 3 (각 5~7초)
- 브릿지: "그런데 나는 여기서 이런 생각이 들었어"

[결론부 — 개인 인사이트, 약 20~30초]
- 반전 or 확장: 영상이 말 안 한 부분, 혹은 내 경험과 충돌한 부분
- 한 줄 결론: 캐릭터의 시선으로 압축
- CTA: 질문형으로 댓글 유도
```

#### 3. 앱 구조

```
[입력]

  - 달빛그린 OS 적용
        ↓
[출력]

  ├── 화면 자막 (캡컷에 바로 붙여넣기)
  └── 나레이션 (말할 내용 그대로)
  + 인스타 캡션 & 해시태그
```

### 과정 (타임라인별 + 삽질)

**Phase 1 · 캐릭터 정의 + OS 설계**
- 처음엔 말투 고민 없이 콘텐츠부터 만들려 했음 → 매번 톤이 달라지는 문제 발생
- 캐릭터를 먼저 고정하면 "이 대사, 달빛그린이 할 말인가?"라는 기준이 생김
- 브릿지 문장("그런데 나는 여기서")이 전반부↔결론부 연결 역할을 한다는 걸 발견

**Phase 2 · 앱 구현 (Next.js + Claude API + Vercel)**
- 코딩 경험 거의 없는 상태에서 시작 → Claude와 함께 Next.js 프로젝트 처음부터 구축
- `.env.local` 파일 인코딩 문제 (PowerShell echo → UTF-16 저장) → Set-Content로 해결
- TypeScript 에러 연속 3번 → `.tsx`를 `.jsx`로 바꾸고 타입 문법 제거로 해결
- Vercel 배포 실패 반복 → 에러 로그 보면서 하나씩 수정

**삽질 포인트**
- 터미널에 코드를 붙여넣는 실수를 두 번 함 (파일 편집창과 터미널을 헷갈림)
- 서버를 두 개 켜서 포트 충돌 발생 → taskkill로 해결
- TypeScript는 `.tsx`에서만 쓰는 문법이 있음. `.jsx`에서 `e: any` 쓰면 파싱 에러

### 공유할만한 인사이트

**1. 캐릭터가 없으면 콘텐츠는 뉴스가 된다**
요약만 잘해도 "누가 만든 요약인지" 지워진다. 캐릭터를 고정하면 같은 정보도 "달빛그린이 본 세계"가 된다. OS에서 캐릭터는 CPU가 아니라 운영체제 그 자체 — 모든 출력물의 필터.

**2. 유튜브는 뼈대, 인사이트는 살**
영상 요약만 하면 리포팅. 내 인사이트만 말하면 근거가 없음. 둘을 조합하면 "검증된 정보 + 내 시선"이라는 신뢰 구조가 생긴다.

**3. 구조가 곧 속도다**
템플릿이 없을 땐 매번 "어디서 시작하지?"로 30분을 썼다. 구조가 고정되면 소재만 바꾸면 되니 대본 초안이 15분 안에 나온다. 그걸 앱으로 만드니 3분으로 줄었다.

**4. 코딩 몰라도 앱은 만들 수 있다**
Node.js가 뭔지도 몰랐는데 Claude랑 같이 하니까 Vercel 배포까지 됐다. 에러 메시지를 읽고 → 원인을 찾고 → 수정하는 사이클을 반복하는 것, 그게 전부였다.

### 공유할만한 인사이트

**사랑의 기준은 상대가 아니라 내 가슴이다**
연애가 공허한 이유는 대부분 "상대가 부족해서"라고 생각하기 쉽다. 그런데 라이프 코드는 다르게 말한다 — 사랑이 없는 거라고. 내가 덧붙인 건 하나다. 사랑의 기준을 상대에게서 찾으면 계속 흔들린다. "지금 내 가슴이 충만한가?" — 이 질문이 기준이 되면 훨씬 명확해진다.

**콘텐츠 OS를 돌리니 정말 빨라졌다**
예전에는 뭘 쓸지 고민하다 30분이 지나갔다. OS 구조(훅 → 요약 → 브릿지 → 인사이트 → CTA)가 고정되니 소재만 넣으면 됐다. 앱으로 만들고 나서는 초안이 3분 안에 나온다.
