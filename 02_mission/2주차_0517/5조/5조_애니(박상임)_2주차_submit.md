### 과정 (타임라인별 + 삽질)
1. 수정 방향성에 대한 고민 : 지난주 만든 CPA 블로그  점검 vs 신규 서비스 (나만의 대시보드, 체험단 몰아보기) 
2. 지난주 만든 CPA 블로그 점검으로 정했는데 기존에 클로드 코드에서 하다가 클로드 채팅에서 진행하니 스킬까지 다 만들고 나서 지난주 만든 회고록 보여주니 이건 새로 만드는게 아니라 기존거를 개편해야한다고 함 
3. 기존에 만들었던 프로세스를 개편하더니 이번에 만든 스킬을 단계중 하나로 추가하기로 함
4. 클로드 채팅에서 스킬,md 파일을 만들어줬는데 어디에 어떻게 넣어야 할지 몰라서 헤맴 (터미널이 아니라 폴더 구조를 찾아서 임의로 업로드)
5. 클로드앱 내 코드 채팅에서 스킬 작동여부 확인
   ㄴ 실제로 작동해보니 네이버에서 계속 차단했으나 그래도 구글에서 해냄6. ![](attachments/Pasted%20image%2020260517022213.png)
6. 앞으로 해야할 것
   ㄴ 주어진 글감으로 실제 글 발행
   ㄴ 기존 프로세스 다시 잡기
     ㄴ 처음 만들었던 데일리 브리프는 별도로 빼기 : 아예 통합 대시보드 느낌으로, 블로그 데이터는 내가 직접 입력해도 그외 사이트는 Claude_in_Chrome 기능 활용
   ㄴ처음 스터디를 시작하면서 내가 만들어 보고 싶었던 것 (체험단 사이트 몰아보기) 에 대한 신규 스터디
