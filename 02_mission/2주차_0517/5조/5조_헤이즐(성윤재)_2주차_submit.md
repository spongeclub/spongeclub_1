## 미션2: <정보 공유>

### Summary
- 기능: 매일 7시 오늘의 날씨와 주식 시황 공유
- 방식: 스케줄 기반 자동 트리거 → API 호출 → 클로드 정리
- 배운점: 목적별 파일 구성 필요, 기존 명령어 반영 여부 확인 필요
### 최종 구현 결과물
![[스크린샷 2026-05-17 오후 2.24.04.png]]
### 과정 (타임라인별 + 삽질)
- 미션1과 동일한 텔레그램 프로필을 통해 운영되는 것 이기에, 기존에 만들어둔 파일에 덧대어 만드는 방식으로 판단. 하지만 따로 구현이 필요한 것이었음
-  맥에서 `.py` 파일을 더블클릭하면 텍스트 편집기가 열림. "터미널로 열기"도 잘 안 됨. `.command` 파일(맥 전용 실행 스크립트)을 만드는 게 유일한 해결책이었음
- Alpha Vantage API가 한국 주식을 지원하지 않음 yfinance`라는 다른 무료 라이브러리로 교체후 실행 완료
- 텔레그램은 봇이 먼저 메시지를 보낼 수 없고, 사용자가 먼저 `/start`를 보내야 채팅 ID가 생김. 이걸 몰라서 전송이 안 됐음
-  "어제 대비 기온" 항목을 보고할 수 있도록 했으나, 제작 과정에서 클로드가 스스로 제거. 프롬프트에 다시 시정요구 후 반영
### 공유할만한 인사이트
- 동일한 텔레그램 프로필을 통해 운영되더라도 채팅의 목적이 다르다면 따로 파일 구축 필요
- 클로드에게 맡기면 스스로 스펙아웃 처리를 할때도 있음. 결과물이 내가 원했던 내용이 맞는지 대조 필요

## 미션3: <하루 회고>

### Summary
- 기능: 매일 밤 10시 하루 회고를 물어보고, 답하면 일론 머스크 스타일로 피드백
- 방식: 스케줄 기반 자동 트리거 → 사용자 답변 수신 → 클로드 API 호출  → 머스크 페르소나 응답
- 배운점: 같은 토큰으로 봇 두 개 동시 실행 불가. 프롬프트 기반 피드백 퀄리티 개선 가능성
