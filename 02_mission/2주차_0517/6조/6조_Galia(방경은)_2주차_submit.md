7. 옵시디언에서 쌓인 데이터 대시보드화
	* ![](attachments/스크린샷%202026-05-16%20오후%2010.13.13.png)
	**Obsidian 시각화 작업 정리**
	1) 초기 세팅
		* Sullivan 데이터 폴더(`sullivan/data/`)가 이미 Obsidian vault로 연결되어 있음 확인
		* `HOME.md` 생성 — vault 배경 설명 (폴더 구조, 데이터 형식, 사용법)
		* `Dashboard.md` 생성 — Dataview JS 기반 시각화 노트
	2) 플러그인 설치
		* Dataview (필수, JS Queries 활성화)
		* Charts (차트 렌더링)
		* Tracker
		* Calendar
	3) 습관 데이터 보강
		* 습관 시스템은 05.15부터 도입됐는데, 이전 할일 데이터에서 역추적해서 05.11, 05.12 습관 기록 추가
		* 05.13~14는 기록 없어서 빈 칸
	4) 성장 키워드 차트 변경
		* 도넛 차트 → 워드클라우드 스타일로 변경 (자주 쓴 단어 클수록 크게)
	5) 브리핑을 습관 항목으로 추가
		* 아침: `/brief` → 수면시간/컨디션 보고, 오늘 할 일 확인
		* 저녁: `/brief` → 오늘 한 일 회고, 성장 기록
	6) 디자인 다듬기
		* 1차 — 차트 합치기 & 색상 통일
			* 수면시간 차트 + 취침시간 차트 → 하나로 통합 (바+라인 복합 차트)
			* 할 일 완료율에 컬러 프로그레스바 추가
			* 보라 기반 테마로 통일
		* 2차 — 색 너무 많다 → 3색으로 축소
			* 보라 + 연보라 + 회색만 사용
		* 3차 — 색 너무 적다 → 적절히 조정
			* 수면: 보라(바) + 연보라 점선(취침) + 핑크(컨디션)
			* 할 일: 보라 + 회색
			* 습관: 보라(완료) / 회색(미완료) / 달성률 텍스트 3단계 색
			* 성장 키워드: 태그별 색 분리 — 배움=보라, 느낌=핑크, 성취=민트
	7) 습관 트래커 형태 변경
		* 라인 차트 → 히트맵 테이블 (습관별 × 날짜별 칸)
		* 각 습관의 달성률 % 표시
		* 불필요한 섹션(수면 테이블 중복, 주간 히스토리) 삭제
	* 최종 Dashboard 구성
		* 수면 — 복합 차트 (수면시간 바 + 취침시각 라인 + 컨디션 라인)
		* 할 일 — 프로그레스바 + 카테고리별 가로 스택 바
		* 습관 트래커 — 히트맵 테이블 (항목별 달성률)
		* 성장 키워드 — 태그별 색 구분 워드클라우드 + 범례
