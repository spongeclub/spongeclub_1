# 무브나우 (MoveNow) — 헬스장 기업계정 SaaS 기획

## 미션1: 각자만의 정의로 [운영체제]라고 정의내리는 OS 구현

### Summary

황철순 OS(매주 운동 루틴 짜주는 것)를 만들다가 "이걸 수익화해보자"로 방향 전환. 웹 기반 헬스장 관리 앱 **무브나우(MoveNow)** 기획으로 발전시킴. 대구 헬스장 100개 기업계정을 1년 목표로 잡고 전략·스택·영업 방식까지 구상 완료.

### 최종 구현 결과물

아직 구상 단계. 기획 문서(전략, 스택, 영업 방식, 커스터마이징 룰) 정리 완료.

- **브랜드**: 무브나우 (MoveNow)
- **타겟**: 대구 헬스장 100개 기업계정 → 트레이너 → 회원 (역방향 깔때기)
- **스택**: Softr + Airtable + Make + 토스페이먼츠
- **영업 무기**: 3개월 무료 체험 + 헬스장 맞춤 커스터마이징

```
황철순 OS (개인 루틴 봇)
       ↓ "이거 수익화되지 않을까?"
헬스장용 SaaS 기획
       ↓ 차별화 포인트 설정
웹 기반 + 헬스장 기구 세팅 → 내 헬스장에 맞는 루틴
```

**기존 헬스 앱과 차별점:**
- 앱 설치 없이 웹 기반으로 가볍게 접근
- 헬스장마다 보유 기구 세팅만 하면 그 기구에 맞는 루틴 자동 생성
- B2C가 아니라 헬스장 기업계정(B2B) → 트레이너 → 회원 순으로 침투

### 과정 (타임라인별 + 삽질)

처음부터 무브나우를 만들어야겠다 한 건 아님. 흐름이 있었음:

1. 스터디 미션 "나만의 OS 구현" 시작
2. 황철순 OS 만들기 → 매주 운동 루틴 짜주는 Claude Code 스킬 완성
3. "이걸 그냥 쓰기엔 아깝다 → 수익화 해보자"
4. 기존 헬스 앱 살펴봄 → 다 무겁고 앱 설치 필요함 → 웹 기반으로 가볍게 가자
5. 헬스장 기구가 다 다르다는 걸 포인트로 잡음 → 기구 세팅 기반 루틴 → 차별화
6. 대구 헬스장 100개 영업 전략까지 구상

**고민한 부분 — 커스터마이징 딜레마:**
100개 헬스장한테 커스터마이징 약속하면 100개 요구가 옴. 노코드 1인 운영자한테 치명적. 미리 룰 설정:
- 공통 기능 요청 → 무료, 1-2주 안에 반영
- 특정 헬스장만 쓸 기능 → 월 +5만원 옵션 or 다음 분기 로드맵

### 공유할만한 인사이트

**"내 문제부터 풀고, 그다음 수익화를 붙여라"**
황철순 OS는 내가 쓰려고 만든 것. 근데 그게 시장이 될 수 있었음. 처음부터 "수익화할 앱 만들자"가 아니라 내가 진짜 쓰는 것에서 출발했기 때문에 페인 포인트가 명확함.

**커스터마이징 약속 전에 룰부터 짜라**
영업 무기로 커스터마이징을 쓰려면 반드시 기준이 먼저 있어야 함. 없으면 번아웃.
