# 5주차 과제 — Nina


## 미션1: '이기적공유'할 프로덕트 마무리

### Summary

 Glance 데모를 "그럴듯한 프로토타입"에서 "실제 CS 현장 사람이 봐도 납득이 가는 도구"로 다듬는 작업을 했습니다. 
 
 뿌까의 4주차 과제 방식에서 영감을 받아, 전문가 3인(현장 경력자, 팀장, 신입)의 롤플레이 피드백을 받아 어떤 부분이 어색한지 진단하고, 스터디 동료 피드백과 교차 검증해 우선순위를 정한 뒤 직접 반영했습니다.

### 최종 구현 결과물

[https://glancehq.netlify.app/landing.html](https://glancehq.netlify.app/landing.html)


**랜딩 페이지**

- **팀장·운영자 전용 섹션 신설**: 요금제 바로 위에 "팀으로 쓰면 이렇게 달라집니다" 섹션 추가. 대시보드·온보딩·오남용 방지 세 가지. 결제 결정권자를 설득하는 콘텐츠가 없다는 팀장 페르소나 피드백 반영
- **Stats Bar 문구 교체**: "3가지 오프닝 후보" → "맥락 맞춤 오프닝 / 추천 이유 함께 표시"로 교체. 숫자만 있어서 의미 전달이 안 됐던 항목
- **후기 업종 태그 구체화**: "소규모 이커머스 CS 1인 운영" → "패션 소품 쇼핑몰 · 1인 CS 운영" 식으로. 나와 같은 상황의 사람이 쓴다는 인식이 전환에 직결되기 때문

**데모 앱**

- **추천 첫마디 아래 "추천 이유" 칩 추가**: 왜 이 문장이 추천됐는지 한 줄로 표시 (예: "재문의 고객 — 공감 먼저, 사과를 구체적으로"). 신입 상담사가 복붙 전 맥락을 이해하고 쓸 수 있고, 장기적으로 학습 효과도 생김
- **채팅창 고객 말투 현실화**: 화난 고객 3명·불만 고객 2명의 대화를 실제 고객처럼 수정. "주문한 게 아직도 안 왔는데 어떻게 된 건지 알 수가 없어요." → "주문한거 아직도 안왔어요 도대체 어떻게 된건지" 식으로
- **분노 가이드 단계 카드 UI 개선**: 텍스트 나열에서 카드 분리 + 번호 뱃지 정리


### 과정 (타임라인별 + 삽질)

**① 전문가 피드백 시뮬레이션**  
CS 경력자·팀장·신입 세 캐릭터로 도구를 리뷰. 세 명이 공통으로 짚은 게 두 가지였음 — "AI가 왜 이 말을 추천하는지 안 보인다"와 "채팅창 고객 말투가 너무 정제돼 있다".

**② 스폰지클럽 동료 피드백과 교차 검증**  
동료가 "산업별 세분화"와 "채널톡 벤치마킹"을 제안했는데, 전문가 셋 중 아무도 같은 말을 안 했다는 게 포인트. 기초 품질이 안 잡힌 상태에서 커버리지 확장은 노이즈라고 판단해 제외.

**③ 구현 — 삽질 포인트**

- 추천 이유 UI: 처음에 카드 좌우로 텍스트가 나란히 들어가는 문제가 생겼음. 카드 내부가 flex 가로 방향으로 설정돼 있어서 이유가 본문 옆에 붙어버린 것. flex 방향을 세로로 바꾸고 overflow hidden을 걸어서 해결

**④ 추천 이유 UI 후보 선정**  
A (구분선 아래 칩), B (좌측 컬러 바), C (토글 버튼) 세 가지를 먼저 제안하고 선택 후 반영. 한 번에 박으면 되돌리기 불편하니까 후보 제시 → 선택 → 구현 순서로 진행

### 공유할만한 인사이트

**1. 채팅 데이터가 현실적이지 않으면 신뢰가 먼저 깎인다**  
기능이 아무리 좋아도 데모에서 고객 말투가 "주문한 게 아직도 안 왔는데 어떻게 된 건지 알 수가 없어요."처럼 완성된 문장이면, 현장 경험이 있는 사람은 바로 "이건 연습용이다"라고 느낌. 데이터 현실감이 UI 퀄리티보다 먼저 신뢰에 영향을 줌.

**2. 결제 결정권자와 실사용자는 다른 사람이다**  
상담사가 편하다고 팀장이 도입하지 않음. "팀으로 쓰면 어떻게 관리하냐"는 질문에 랜딩이 답을 못 하면 구매 전환이 안 일어남. 하나의 제품에 설득해야 할 사람이 두 명이라는 걸 초기부터 설계에 반영해야 함.

**3. AI 추천 기능은 "왜"가 없으면 반쪽짜리다**  
추천 문장만 있으면 "이거 그대로 써도 되나?" 라는 불안이 생기고, 신뢰하지 못해서 안 쓰거나 맹목적으로 쓰게 됨. 이유 한 줄이 붙으면 상담사가 판단 주체가 되고, 도구 의존도가 낮아지면서 오히려 더 자주 쓰게 됨.
