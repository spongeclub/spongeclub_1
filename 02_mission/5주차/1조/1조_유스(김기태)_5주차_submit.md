## 미션1: <MEDIT 딜러 지원 도구 — 계측되는 트러블슈팅 체크리스트 + 맥락 실은 문의>

### Summary
MEDIT 구강스캐너 **딜러가 현장에서 문제를 한 단계씩 스스로 해결**하고, 안 되면 **시도 과정이 그대로 담긴 문의**로 넘어가며, 그 모든 행동이 **데이터로 쌓여 "어떤 해결법이 통하는지"가 보이는** 딜러 전용 웹 도구. 기존 PDF·헬프센터의 한계(특히 **데이터 부재**)를, 문서를 추적 가능한 단위로 쪼개 **방법별 효과 데이터 + 맥락 실은 문의**로 푼다. Claude Code로 작은 단위 반복으로 동작하는 프로토타입까지 구현.
### 최종 구현 결과물
동작하는 웹앱 프로토타입(Next.js 16 + node:sqlite):

- **딜러**: 가입신청·승인·로그인 / 검색 / 계측 체크리스트(펼침·auto-advance) / 맥락 실은 문의(제품·시리얼·사진) / 내 문의함 추적
- **어드민 콘솔**: 데이터 대시보드(방법별 효과·죽은 단계·검색어 통계) / 계정 승인·감사로그 / 콘텐츠 검수 게이트 / Zendesk 미리보기·동기화 와꾸
- **기반**: 쿠키 인증·역할, DB 영속화, 워크북 기반 디자인 시스템
- **부가**: 소개 PPT + 스크롤 웹페이지
### 과정 (타임라인별 + 삽질)
9단계: ①체크리스트 프로토타입 → ②어드민 대시보드 → ③디자인+문의함 → ④백엔드·DB → ⑤인증·역할 → ⑥콘텐츠 검수 → ⑦문의 양식 → ⑧사진 업로드+Zendesk 와꾸 → ⑨어드민 콘솔 통합  
**삽질**: 캐러셀→체크리스트 방향 전환 · 조직 저항→웹으로 우회 · Tailwind @import 순서로 전 페이지 깨짐 · node:sqlite 타입/스키마 재시드 · "안건드림 vs 효과없음" 정합성 · LibreOffice 없어 Playwright로 QA 우회
