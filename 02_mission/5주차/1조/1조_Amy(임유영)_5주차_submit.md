## 미션1: 노마드-로컬플랫폼

## Summary

- 퇴사 후 독립한 사이드프로젝터가, **수요 기반 서비스**를 찾으려고 시작.
- "노마드 커뮤니티 → 로컬 플랫폼"이라는 막연한 그림에서 출발해, **포지셔닝을 수십 번 갈아엎으며** "회사 밖에서도 혼자가 아니도록 — 동네 독립워커와 로컬 사장님을 잇는 소속 거점 **베이스캠프**"로 수렴.
- AI(클로드)와 페어로 **기획 → 브랜드 → 디자인 → 풀스택 구현 → 실배포**까지. Next.js + Supabase + Vercel.
- 핵심 깨달음: **포지셔닝이 곧 제품이다.** 기능을 만드는 것보다 "이게 무슨 서비스인가"를 정하는 데 90%의 시간이 들었다.

## 과정 (타임라인별 + 삽질)

### 1막 — 막연함, 그리고 길 잃음
- 시작은 "종소세 가이드 + 노마드 커뮤니티(PLOT)". 목업 데이터로 화면부터 찍음.
- **삽질①:** 정작 "이게 무슨 서비스인지" 본인도 모름. 커뮤니티? 도구? 로컬 플랫폼? **며칠을 빙빙 돌았다.**
- **삽질②:** 곁길로 새서 "목표를 할 일로 쪼개주는 앱(클리어)"까지 만들었다가 접음. (스코프 이탈)

### 2막 — 페르소나에서 진실을 봄
- "노마드↔로컬 사장님 연결"로 방향. 박지수(카페 사장)·김태양(프리랜서) 페르소나 설정.
- **삽질③:** "사장님은 정말 교류·도움이 필요할까?" 직접 의심. → **수요 비대칭** 발견: 워커는 절실, 사장님은 미지근. (양면 플랫폼의 함정)
- 정직한 결론: 사장님 수요는 미검증 가정. **인터뷰가 답.**

### 3막 — 브랜드·디자인 3번 갈아엎기
- 이름: PLOT → **베이스캠프** ("독립했을 때 돌아올 거점").
- 디자인: **결(뉴브루탈리즘)** → **POSTY(소프트 에디토리얼)** → **공식 브랜드 가이드(캠프그린)**. 세 번 다 새로 입힘.
- **삽질④:** CSS `@import` 순서 때문에 빌드 깨짐. 폰트를 `<link>`로 옮겨 해결.
- **삽질⑤:** 캐시 때문에 "흰 배경 적용했는데 안 보여" 반복 → 하드 리프레시·`.next` 삭제.

- **총무 에이전트:** 세금 SRS(체류일→제안→승인→캘린더)를 5화면으로 구현. 가드레일(판정 금지) 준수.

### 5막 — "데모 말고 진짜로 돌아가게"
- 셀피쉬클럽 강의(수신동의 최전방·가입 최소화) 적용 → **카카오/구글 로그인 폼을 "1기 알림 받기" 대기 등록으로 교체.** OAuth 블로커가 자연스럽게 사라짐.
- Supabase 연결 → 실제 연락처 수집.
- **삽질⑦:** anon 키로는 `ALTER TABLE`(DDL) 불가 — 보안 경계. 컬럼 추가할 때마다 대시보드 SQL을 사람이 돌려야 했다.
- **삽질⑧:** 커스텀 도메인이 401(배포 보호). 대시보드 토글이 안 보여서, CLI로 프로덕션 도메인 승격해 우회 → `joinbasecamp.vercel.app` 공개.

### 6막 — 진짜 데이터로 살아나기

- **라운지(커뮤니티)** — 게시글·댓글 실시간 저장. 닉네임은 마이에서, 내 댓글 삭제.

## 공유할만한 인사이트

1. **포지셔닝이 곧 제품이다.** 코드보다 "이게 무슨 서비스인가"에 시간이 90% 들었다. 흔들릴 땐 한 장 요약(앵커 문서)으로 돌아왔다.

2. **소속 > 매칭.** "워커↔사장님을 잇는다"고 쓰면 **크몽 동네판(외주 플랫폼)**으로 읽힌다 → 즉사. "소속을 만든다"로 프레임을 옮기니 살았다. 일·매칭은 소속의 *결과*지 목적이 아니다.

3. **입력 안 받은 걸로 점수 매기지 마라.** 매칭 산식에 거리·체류가 있었지만 입력칸이 없었다. 유저가 두 번이나 짚었다. **정직한 알고리즘 = 실제 수집한 신호만.**

4. **수요 비대칭을 경계하라.** 양면 플랫폼에서 한쪽(워커)만 절실하고 다른 쪽(사장님)이 미지근하면, 미지근한 쪽이 병목이다. "사장님은 미끼, 돈은 ROI 있는 쪽(워커·지자체)."

5. **가입을 최소화하라.** 검증·로그인을 앞단에 들이밀면 이탈한다. **수신동의(연락처)만 먼저, 검증은 합류로.** OAuth 블로커도 이 결정으로 사라졌다.

6. **"데모"와 "진짜"는 다르다.** localStorage 목업은 한 브라우저에서만 산다. Supabase로 옮기는 순간 전 기기·전 사용자가 보는 진짜 서비스가 된다. 단, 보안 경계(anon 키로 DDL 불가, 프로덕션 도메인만 보호 면제)를 정직하게 마주해야 한다.

7. **창업자 본인이 1번 유저면 강하다.** Amy 자신이 퇴사·독립한 당사자라, 페인포인트가 생생했다. 외부 리서치보다 본인 경험이 더 정확했다.

8. **AI 시대 = 소속 수요 ↑.** 혼자 다 할 수 있게 될수록 더 외로워진다. AI가 못 하는 것(오프라인·로컬·신뢰·소속)이 해자.

9. **Test. Fail. Iterate.** 완벽한 기획보다 시도 횟수. 라이브로 올려두고 진짜 신청을 받아보는 게 어떤 플레이북보다 빠른 검증이다.
