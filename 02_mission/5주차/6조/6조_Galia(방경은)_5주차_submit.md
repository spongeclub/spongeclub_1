## 미션1: '이기적공유'할 프로덕트 마무리

### Summary

갤러리 페이지를 비전공자도 재밌게 볼 수 있게 크게 개편하고, 크루 소개 페이지도 더 쓸모 있게 다듬음.

* 갤러리에 산출물 48개를 스토리텔링 카드로 정리
* 크루 페이지는 조별/유닛별로 골라 볼 수 있게 함
* 멤버가 직접 채울 자기소개·산출물 '양식'도 미리 만들어 두고 스킬화

* **갤러리 페이지 개편** — ![](attachments/스크린샷%202026-06-07%20오후%207.09.14.png)카드 누르면 'Before → After + 쉬운 기능 설명' 스토리텔링 모달로 바꿈. 산출물 48개 다 올리고, MVP 배지·정렬/필터 추가.
* **크루 소개 페이지 개편** — 조별/유닛별 전환 버튼, 유닛 캐릭터 프로필, 모바일 조 선택 칩, 카드 뒷면 정리.
* **제출 양식** — `/gallery`(산출물)·`/profile`(자기소개) 명령이랑 76명분 빈 노트 미리 만들어 둠.
* **성능 최적화** — 프로필·로고 사진 약 5MB → 120KB로 줄여서 페이지 빨리 뜨게 함.

### 과정 (타임라인별 + 삽질)

1. **갤러리 개편** — 카드 누르면 외부 링크로 바로 가던 걸 '스토리텔링 모달'로 바꿈. 비전공자도 이해하게 Before/After·쉬운 기능 설명·기술 스택 접이식으로 구성. 운영 엑셀에서 배포 URL 뽑아서 미션 노트랑 매칭, 48개 산출물 등록. MVP 배지·정렬/필터 추가.
2. **갤러리 제출 시스템** — 옵시디언에서 `/gallery`로 산출물 노트 만들게 하고, 제출 양식(frontmatter 체크박스 포함) 정리.
3. **유닛별 보기** — 조(1~6조)랑 별개인 유닛 그룹을 데이터로 정리하고 토글로 전환되게 함. 유닛에 안 속한 사람은 유닛 보기에서 숨김.
4. **유닛 설명·번호 추가** — '유닛 01 · 데굴데굴 유닛(운영 OS)'처럼 번호·태그·한 줄 설명을 큰 글씨로.
5. **프로필 사진 넣기** — 루트에 올려둔 캐릭터 이미지 5장 정리해서 카드에 매칭.
6. **사진이 너무 무거웠던 문제**
	* 문제: 사진 한 장이 760KB~1.1MB(원본 1080px)인데 화면엔 88px로만 보임 → 5MB 낭비
	* 시도: webp 변환 시도했는데 이 맥에선 도구(cwebp/sips webp)가 안 됨
	* 해결: 사진은 256px JPEG, 로고는 투명 유지하려고 256px PNG로 줄임 → 합계 ~120KB
7. **자기소개 제출 시스템** — 갤러리 방식 그대로, 옵시디언에서 `/profile`로 노트 만들게 함. 양식을 여러 번 다듬음(브런치 빼기, SNS는 본문에 적기 등).
	* 삽질: 76명 노트 한 번에 만들 때, 멤버목록 파일 맨 아래 '갱신 규칙' 항목까지 6조 멤버로 잘못 읽어서 이상한 파일이 생김 → 헤더 인식 조건 고쳐서 다시 생성
8. **토글 위치·모바일 칩** — 토글을 제목 오른쪽으로 옮기고, 모바일엔 선택 칩 추가. 칩이 토글이랑 너무 멀어서(80px) 간격을 16px로 맞춤.
	* 삽질: 칩이랑 토글 사이가 이상하게 벌어짐 → 알고 보니 페이지 전체가 항목 사이 56px 간격(flex gap)을 갖고 있어서였음. 모바일에서만 그 간격을 상쇄.
9. **머지 충돌 2번** — 작업 중에 메인이 계속 바뀌어서(네비게이션 링크, 제목 도형 제거 등) 충돌. 양쪽 변경 다 살리는 방향으로 수동 병합.
10. **카드 뒷면 정리** — 이름 왼쪽·SNS 로고 오른쪽, 배포 사이트 링크는 제거(갤러리로 일원화).
11. **총평 항목 추가** — 자기소개 양식에 '스폰지클럽 총평' 섹션 추가하고 76개 노트에도 반영.
	* 삽질: 76개 노트에 섹션 추가할 때 끝줄 공백이 미세하게 달라서 치환 실패 → 파일 끝에 직접 덧붙이는 방식으로 해결.

### 공유할만한 인사이트

* **결국 '보는 사람'을 생각하는 마음이 제일 중요하다.** 아무리 좋은 산출물도 비전공자한테 안 맞는 설명을 하면 가치가 전달이 안 된다. 그래서 갤러리 모달을 'Before → After'로 풀었음 — 기술 용어 나열하는 대신 "이게 없을 땐 이렇게 불편했는데, 생기니까 이렇게 편해졌다"로 보여주니 누구나 이해함. 설명도 결국 고객을 생각하는 일.
* **'입력하는 사람'의 수준이랑 진도도 다 제각각이다.** 정보를 직접 채워야 하는 크루들이 익숙한 정도가 다 다른데, 템플릿 기능이나 단축키를 강요하면 힘들어할 수밖에 없음. 그래서 최대한 스킬(`/gallery`·`/profile`) 형태로 만들어서 누구나 같은 방식으로 쉽게 채우게 함. 이렇게 '어떻게 하면 모두가 부담 없이 참여할까' 고민한 과정 자체가 제일 큰 인사이트라고 생각함.
