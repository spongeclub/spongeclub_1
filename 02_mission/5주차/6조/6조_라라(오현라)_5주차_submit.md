## 미션1: 콘텐츠 관측기 & 작성기 (실시간 트렌드 레이더)

### Summary

지금 막 터지고 있는 이슈 콘텐츠를 **감이 아니라 데이터로** 먼저 잡아내고 싶어서 만든 웹 대시보드다. 전 세계 유튜브의 트렌딩·키워드 검색을 한 곳에 모으고, 단순 조회수가 아니라 **'시간당 조회수 증가량(급상승)'으로 떡상 직전 영상을 포착**한다. 거기서 끝나지 않고, 잡아낸 트렌드를 재료로 **릴스 대본·카드뉴스 원고까지 생성**되도록 연결해 "관측 → 작성"을 한 흐름으로 묶었다.

핵심 결정은 **타깃을 좁힌 것**이었다. "모든 이슈"는 범위가 너무 넓어 아무것도 검증되지 않는다. 그래서 우선 **커플 콘텐츠 한 분야로 좁혀** 작동 여부를 먼저 검증했고, 주제(키워드)는 설정값으로 분리해 **나중에 다른 분야로 그대로 확장**할 수 있게 설계했다.

### 최종 구현 결과물

- **배포 링크(시연용):** https://recordings-vcr-graphics-cottage.trycloudflare.com/
- **기술 스택:** Python, Streamlit, YouTube Data API v3, yt-dlp, youtube-transcript-api, pandas, SQLite

기능 요약:

- **글로벌 트렌딩 수집** — 미국·한국·일본·영국·브라질 등 여러 국가의 유튜브 트렌딩을 한 번에 수집
- **급상승 감지(⚡velocity)** — 수집 스냅샷을 비교해 '시간당 조회수 증가량'으로 떡상 중인 영상 포착 (레이더의 핵심)
- **주제 필터링(현재: 커플)** — 다국어 키워드(커플 / boyfriend / カップル / pareja …)로 특정 분야만 골라냄. 키워드만 바꾸면 다른 주제로 확장 가능
- **자막·대본 자동 수집** — 영상 자막을 받아 .txt로 다운로드, 이슈 분석 재료로 활용
- **콘텐츠 생성 연동** — 추적한 트렌드를 재료로 릴스 대본·8장 카드뉴스 원고까지 바로 생성
- **대시보드 탭 구성** — 🔥트렌딩 / 📈급상승 / 🔍키워드 검색 / 📝자막 / 🎬생성

### 과정 (타임라인별 + 삽질)

#### ① 타깃 좁히기 — "모든 이슈"는 검증이 안 된다

처음 목표는 "실시간 이슈 콘텐츠 전부를 잡아낸다"였다. 그대로 갔다면 범위가 너무 넓어 완성도, 검증 둘 다 놓쳤을 것이다. 그래서 **커플 콘텐츠 한 분야로 좁혀 MVP**를 먼저 만들었다. 대신 주제를 코드에 박지 않고 **설정값(키워드)으로 분리**해, 검증 후 다른 분야로 갈아끼울 수 있게 했다. → 범위가 명확해진 게 전체에서 가장 효율적인 순간이었다.

#### ② 급상승 로직 — "한 번 수집"으로는 절대 안 나온다

조회수는 한 시점의 스냅샷이라, 그 값 하나로는 "뜨고 있다"를 알 수 없다. **시간 간격을 두고 2번 이상 수집해 변화량을 비교**해야 비로소 '급상승(velocity)'이 계산된다는 걸 알게 됐다. 트렌드의 본질은 '값'이 아니라 '속도'였고, 이 깨달음이 레이더의 핵심 기능이 됐다.

#### ③ 데이터 수집 안정화 — yt-dlp 단독은 자주 막힌다

처음엔 API 키 없이 yt-dlp로 트렌딩을 긁었는데, 유튜브가 종종 막아 **결과가 0개**로 떴다. 그래서 **"API 키가 있으면 정밀 수집 / 없으면 yt-dlp 폴백"** 이중 구조로 설계해 안정성을 확보했다.

#### ④ 시연용 배포 — 코드 수정 없이 외부 공개

발표 때 다른 사람도 접속할 수 있어야 했다. Streamlit 앱을 로컬에서 띄우고 **Cloudflare 터널(cloudflared)** 로 임시 공개 링크를 만들어, 코드 한 줄 안 고치고 인터넷 어디서나 접속되게 했다. (단, 내 PC가 켜져 있어야 유지되는 임시 방식)

#### ⑤ 삽질·보안 — 공개 직전 API 키 노출 발견

공개 링크를 만들고 보니, 사이드바 입력칸에 **YouTube API 키가 그대로 노출**될 수 있었다(개발자도구로 추출 가능). 그래서 **입력칸 자체를 제거하고 키는 서버(config.json)에서만 읽도록** 수정해, 접속자가 키를 빼낼 수 없게 막았다. 화면엔 "🔑 API 키: 연결됨" 상태 표시만 남겼다.

### 공유할만한 인사이트

**1. 타깃은 좁힐수록 빨리 검증된다.** "전부 다"는 멋져 보이지만 아무것도 증명하지 못한다. 한 분야로 좁혀 작동을 확인하고, 확장은 설정값으로 열어두는 게 훨씬 빠른 길이었다.

**2. 트렌드는 '값'이 아니라 '속도'다.** 조회수 절대값보다 '시간당 증가량'이 떡상 신호를 훨씬 잘 잡는다. 그래서 수집을 스냅샷으로 쌓아 변화량을 비교하는 구조가 핵심이 됐다.

**3. 비개발자에게 시연시키는 가장 빠른 길은 터널이다.** 서버 배포 없이 cloudflared 한 줄로 공개 링크가 나온다. 단, 내 PC가 꺼지면 끊기는 임시 방식이라 상시 운영은 별도(예: Streamlit Cloud)로 가야 한다.

**4. "공개" 버튼을 누르기 전, 화면에 비밀값이 새지 않는지 반드시 점검하라.** 마스킹된 비밀번호 칸이라도 값은 브라우저로 전송된다. 키는 서버에서만 다루고 화면엔 상태만 노출하는 게 안전하다.
