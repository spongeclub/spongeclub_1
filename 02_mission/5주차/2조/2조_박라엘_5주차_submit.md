### 공유할만한 인사이트


**1. 한국 뉴스는 한국 서버에서 가져와야 함.** 미국에 있는 Vercel 서버에서 한국 언론사 RSS를 긁으면 IP 차단된다. 구글뉴스 → RSS → 네이버 API 순으로 3번 수정

**2. 실시간 매물은 진짜로 불가능하다.** 네이버·직방은 API를 공개하지 않는다. 스크래핑은 이용약관 위반. 현실적인 대안은 예산 연동 + 플랫폼 링크였다. 불가능을 인정하고 현실적인 대안을 찾는 것도 능력이다. ㅠ
