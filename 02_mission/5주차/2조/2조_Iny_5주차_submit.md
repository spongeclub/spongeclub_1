## 미션1: OPIc IH 플래너 — 내가 매일 쓰려고 만든 오픽 AI 튜터

### Summary
퇴사를 결정하며 오픽 자격증을 다시 따보겠다고 결심했다. 이번엔 학원이나 유료 강의가 아니라 AI로 직접 테스트해보고 싶었다. 얼마나 걸리는지, 어떻게 활용해야 하는지, 영어 실력이 어떻게 누적되는지 직접 확인하고 싶어서 만들었다.

### 최종 구현 결과물
🔗 https://opic-ih-planner.vercel.app

- 로그인 — 비밀번호로 개인 접근 제한
- 대시보드 — 목표 등급, 진도율, 달성률, 누적 세션 한눈에
- 커리큘럼 — 오픽노잼 3단계(기초 이해 → 주제별 훈련 → 실전 모의) 강의 체크리스트
- 연습하기 — AI 튜터와 영어 대화, 답변하면 즉석 피드백
- 학습 기록 — 세션별 추정 등급·피드백 저장 (Supabase 연결 예정)

### 과정 (타임라인별 + 삽질)
회사 일이 아닌 내 걸 만들어야겠다고 생각했는데, 막상 시작하려니 뭘 만들지 몰라서 이것저것 벌려놓고 고민만 반복했다.

오프라인 모임에서 크루들한테 얘기했더니 "일단 다양하게 해봐라, 가볍게 시작해"라는 말을 들었다. 그 말 듣고 나서 다시 가벼운 마음으로 냅다 만들기 시작했다.

Claude Code로 뼈대를 짜고 Gemini API를 연결해 AI 튜터 기능을 붙였다. Vercel 배포까지 코드 한 줄 직접 쓰지 않고 완성했다.

### 공유할만한 인사이트
- "내가 매일 쓸 것"을 만들면 기획에서 막히지 않는다 — 타겟이 나 자신이라 결정이 빠름
- Gemini API 무료 키 하나면 AI 튜터 완성 — 개인 연습엔 충분하고 비용 제로
- API 키는 서버에서만 처리되어 브라우저에 노출되지 않음 — Next.js API 라우트 덕분
- Vercel + Supabase 조합으로 학습 기록 저장까지 무료 배포 가능 (DB 구조 설계 중)
- 가볍게 시작하라는 말이 맞았다 — 완성도 걱정보다 일단 돌아가는 게 먼저
