## 미션1: <제목>

### Summary

① 리뷰 분석 메뉴(상품 URL → 리뷰 자동 분석) 
② 이벤트 검색수 수집 기능 추가
③ 수집 캘린더 + "오늘 수집했나" 안내 
④ 데이터를 엑셀 자동 저장
⑤ 버그 수정

### 최종 구현 결과물

▪리뷰 분석 메뉴 : 큐텐 상품 URL 넣으면 리뷰를 긁어 별점 분포·키워드·장단점(문장)·재구매·포토비율·옵션별·추이를 분석　👉API 사용 안하는 방향으로 진행해서 퀄리티 아쉬움. 수정 필요.
![](attachments/Pasted%20image%2020260607173859.png)

▪이벤트 검색수 수집 : 이벤트 기간 검색량이 별도로 표시되어, 이벤트 기간동안은 별도 수집 기능 추가 (美容液 평소 1,365 → 이벤트기간 8,507)


▪수집 캘린더 : 노출일별 수집현황을 월간/연간 달력으로 확인
![](attachments/Pasted%20image%2020260607173943.png)

▪"오늘 수집했나" 상태 배너 : 들어가면 완료/일부/안함 즉시 안내
![](attachments/Pasted%20image%2020260607174001.png)


▪엑셀 자동 저장 : 수집 끝나면 엑셀 파일로 자동 저장 + 파일명에 각 파트 별 수집현황 표기)


▪분석 메뉴 - 우상향/우하향 추세 카드 추가 : 상승,하락 들쑥날쑥해도 전체 방향이 위/아래인 키워드 확인
![](attachments/Pasted%20image%2020260607173912.png)

▪버그 수정: '모두 수집' 시 카테고리 누락 / 끊긴 회차 삭제 불가


### 과정 (타임라인별 + 삽질)

▪삽질1 - 클로드가 수집할 데이터 위치(이벤트기간 검색수)를 못 찾음
스크린샷으로 요청 했으나 기존에 수집할 데이터 카드에서만 찾음 → 스크린샷과 함께 다시 길게 설명
▪삽질2 - 리뷰분석의 '키워드' 추출 시, 일부 일본어 단어를 한단어로 인식하지 못함
洗い上がり가 洗い+上がり로 두 단어로 쪼개져서 인식 (각각 별도 의미 있는 단어들) → 복합명사는 합쳐서 인식하도록 지시
▪삽질3 - '모두수집' 버튼 클릭 시, 키워드만 수집되고 카테고리 누락
원인 = 키워드·카테고리를 별도 프로세스 2개로 돌려서, 긴 수집 중 화면 새로고침이 끼면 카테고리가 끊김 → 한 프로세스로 묶어 해결

### 공유할만한 인사이트

기능보다 정의를 먼저 확실하게 - "기준(축)" 을 처음부터 제대로 정하지 않으면 나중에 겉잡을 수 없이 꼬여버림 (하네스의 중요성)
