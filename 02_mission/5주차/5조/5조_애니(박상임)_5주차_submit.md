### 과정 (타임라인별 + 삽질)
**친구 피드백:**

1. 화면 이동 없이 클릭 시 아래로 펼침
2. 메인에 서비스 설명 필요
3. 혜택 칩이 클릭 가능해 보임
4. 결과에 데이터/통화/문자/월요금 표시
5. "통신비 0원 + 순수익 25만원"보다 단일 금액이 더 와닿음

**작업 순서:**

- (4) 결과 카드에 데이터/통화/문자 표시 → 데이터 구조 손 안 댐, 렌더링만 추가
- (5) 키비주얼 "최대 47만원" + 카피 결정 흐름 (8개 후보 → 3-G "지금 알뜰폰 갈아타면 받는 돈" 선택)
- (2) 키비주얼에 흡수, 추가 작업 없음
- (3) 혜택 칩 → 정보 리스트 + 합계 47만원
- (1) Step 1/2 분리 제거 → 헬로 카드 아코디언 펼침 구조

**삽질 + 발견:**

- **숫자 정직성 vs 임팩트 충돌**: 25만(정직, 차별점) vs 47만(임팩트). 결국 "최대 47만원"으로 합의 — 정직성 보존하면서 임팩트 살림
- **"순수익 25만원" 노란 박스가 메인 47만원과 충돌** → 박스 통째 제거. 한 화면에 두 숫자 보이면 친구 또 헷갈림
- **카피 디벨롭 8개 → 3-G 선택 → 다시 8개 디벨롭** — 카피 하나에 한 시간
- **결과 화면 너무 길어짐 + 비교하기 결과 안 보임**: 7개 카드 다 펼치니까 화면 1500px. 1위만 풀 + 나머지 한 줄 압축 + 자동 스크롤로 해결
- **옵션 영역이 비교 후에도 계속 보임** → 비교하기 누른 순간 숨김, 새로고침 전엔 안 나옴
- **버튼 위계 깨짐**: 비교하기 검정 + 가입하러 가기 검정 → 가입하러 가기 빨강으로 변경
- **URL 수정 누락 삽질**: 가입 URL 알려줬는데 그 직후 프로모션 버튼 논의로 넘어가서 코드 수정 안 함 → 가입하러 가기 누르면 메인 페이지로 가는 버그 발생 → 디버깅으로 발견
- **클릭 이벤트 전파 함정**: 프로모션 버튼이 카드 안에 있어서 클릭 시 카드도 같이 펼쳐짐 → `event.stopPropagation()`으로 해결

### 공유할만한 인사이트
**1. "내가 정리한 방식 ≠ 내가 추천하는 방식"** 사용자가 자기 행동 관찰하면 진짜 니즈 보임. 5/22 정리(분석)와 친구 추천 답(통신사 단일 추천)이 달랐다는 발견.

**2. 친구 한 명 = 일주일 노동 절약** "그래서 어디가 돈 많이 줘?" 한 마디로 화면 구조 통째 전환. "통신비 0원 + 순수익 25만원"이 헷갈린다는 한 마디로 박스 제거.

**3. 사용자 직접 작성한 카피가 AI 제안보다 우월** "정점" → "사용 추천"은 AI 제안. "7개월 후엔 다른 통신사로 갈아타기"는 사용자 직접 작성. 후자가 명확.

**4. 결정도 데이터로 검증·폐기** 정렬 옵션 3개 만들었다가 데이터 검증 후 의미 없음 확인 → 폐기. 만든 거 아까워서 안 버리는 함정 피함.

**5. 24개월 풀로 쓰면 적자** 헬로 모든 요금제. "기간당 혜택 밀도가 진짜 지표"의 시각적 증명. 마케팅 "최대 54만원"의 함정 폭로 = 서비스 차별점.

**6. 정직성 vs 임팩트는 "최대"가 해결** 47만원 = 24개월 이론값, 7개월 실제 순수익 = 25만원. "최대 47만원"으로 정직성 보존 + 임팩트 확보.

**7. 카피 작업은 8개 펼치고 1개 골라도 다시 8개 디벨롭** 첫 후보 8개에서 3-G 골랐는데, 그 약점 짚고 다시 디벨롭 8개. 카피 하나 정하는 데 한 시간. **시간 들이는 게 정상**.
