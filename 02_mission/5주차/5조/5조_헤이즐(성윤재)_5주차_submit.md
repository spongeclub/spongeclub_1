## 미션1: <제목>

### Summary
매주 미용실 원장님을 대상으로 헤어짱을 홍보하는 카드뉴스를 **빠르고 일관되게 만들 수 있는 시스템**이 필요했다. 주제만 입력하면 AI가 기획하고, 디자인까지 자동 생성되는 카드뉴스 OS를 만들었다. 
### 최종 구현 결과물
배포 주소: [https://yjseong0809-lgtm.github.io/hairjjang-cardnews-os/hairjjang_cardnews_os.html](https://yjseong0809-lgtm.github.io/hairjjang-cardnews-os/hairjjang_cardnews_os.html)

### 과정 (타임라인별 + 삽질)
### 1. 레퍼런스 분석 & 디자인 시스템 수립

티오더 카드뉴스(7장)를 레퍼런스로 분석해 헤어짱 디자인 시스템 MD 파일 제작. 티오더 Red → 헤어짱 Purple(`#6538B6`)로 포인트 컬러 전환.

### 2. 슬라이드 타입별 템플릿 제작 (하나씩 확정)

- **1장 커버** → HTML 파일 기반으로 바로 완성
- **2장 텍스트 본문** → 페이지 인디케이터 제거 / 하이라이트 드래그 편집 구현
    - 삽질: `onclick` → `onmousedown`으로 바꿔야 선택 영역 유지됨
    - 삽질: 두 문단을 하나의 편집 영역으로 통합 요청
- **3장 섹션 인트로** → 이미지 업로드 + 이모지 선택 추가
- **4장 데이터 표** → "자주 쓰기 어려운 템플릿"으로 스킵
- **5장 이모지+본문** → 2장 구조에서 이미지만 제거한 심플 버전
- **CTA** → 네이버 검색창 목업 / 이모지 제거로 집중도 향상

### 3. 카드뉴스 OS 통합

4개 템플릿을 하나의 앱으로 통합. Claude API 연결해서 AI 기획 자동화.

- 삽질: 슬라이드 수를 미리 선택하는 방식 → "주제가 얼마나 되는 내용인지 모름" → AI가 주제 분석 후 슬라이드 수 직접 추천하는 방식으로 변경
- 삽질: AI가 "헤어짱이란?" 고정 소개로 시작 → 주제와 얼라인 안 맞음 → 핵심 메시지 한 문장 먼저 잡고 스토리 전개하는 방식으로 변경
- 추가: 기본 설정 패널 (시스템 프롬프트처럼 동작)
- 추가: 드래그 순서 변경 (커버/CTA 고정)

### 4. GitHub Pages 배포

`hairjjang-cardnews-os` 레포 생성 → HTML 업로드 → Pages 활성화 → 배포 완료

### 공유할만한 인사이트
"카드뉴스 OS"라는 프레임이 핵심이었다
단순히 카드 하나를 만드는 게 아니라, 매주 반복해서 쓸 수 있는 시스템을 만든다는 관점. 템플릿을 최소화하고(4종), 내용만 바꾸면 되는 구조로 설계한 것이 포인트.
슬라이드 타입은 적을수록 좋다
처음엔 6종으로 시작했지만 데이터 표(자주 못 씀), 텍스트 본문(밋밋함) 등을 제거하면서 4종으로 압축. "매주 쓸 수 있나?"가 기준이 됐다.
AI 기획은 "큰 주제 → 핵심 메시지 → 스토리 흐름" 순서가 맞다
주제를 바로 슬라이드로 쪼개면 각 장이 따로 놀게 됨. 핵심 메시지 한 문장을 먼저 정하고, 그 메시지를 향해 모든 슬라이드가 수렴하게 설계해야 얼라인이 맞는다
