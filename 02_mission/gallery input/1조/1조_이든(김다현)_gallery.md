# ADHD 약 복용 기록 앱

- **배포 링크**: https://adhd-taking-record.vercel.app

## 📸 캡처 이미지
![[이든_adhd앱_스크린샷.png]]

## 💬 WHY — 왜 만들었나
ADHD 진단 3년차, 1년간 약을 바꿔가며 고생했다. 의사선생님께 효과와 부작용을 기억에만 의존해 말해온 게 치료를 늦췄다. 정확한 기록으로 더 빠르게 맞는 약을 찾기 위해 만들었다.

## 📝 한 줄 소개
ADHD 약 복용 기록 앱 — 효과·부작용·수면을 매일 기록하고 의사선생님과 공유하세요.

## 😣 Before → ✨ After
- **Before**: "지난주 약 어땠어요?" — 기억에 의존해 두리뭉술하게 대답. 의사가 판단하기 어렵고 치료가 길어짐
- **After**: 날짜별 복용 기록 + 효과/부작용 태그 + 수면 데이터를 그대로 보여줄 수 있음

## 🎯 주요 기능 (3~5개)
- 💊 약 기록: 먹었어 / 늦게 먹었어 / 까먹었어 + 복용 시각 원터치 기록
- 😴 수면 기록: 잠든 시각 → 기상 시각, 수면 시간 자동 계산
- 🏷 효과/부작용 태그: 집중력·두통·식욕 감소 등 레벨별 선택
- ✏️ 지금 느낌: 즉흥 감정·증상 즉시 메모
- 📥 데이터 백업·복원: 진료 공유용 JSON 내보내기

## 🔧 이렇게 만들었어요 (기술 스택)
React, Vite, localStorage, Vercel, Claude Code

## 💡 삽질 & 인사이트
- 앱을 배포까지 했는데 정작 알림이 없어서 약을 까먹는 문제가 해결 안 됨. 구현 완료 ≠ 문제 해결
- 기능을 늘릴수록 ADHD 사용자는 오히려 회피하게 된다. 단순함이 핵심
- 병원 연계가 가장 현실적인 유통 경로 — 의사가 처방하듯 앱을 소개해주는 구조
