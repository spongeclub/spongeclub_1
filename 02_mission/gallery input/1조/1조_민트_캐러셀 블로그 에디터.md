## 💬 WHY — 왜 만들었나

핫플 인스타 계정을 만들어보고 싶었는데, 정작 캐러셀 한 장도 못 만들고 계속 미루고 있었어요. 텍스트는 밋밋하게 나오고, 이미지는 결국 피그마에서 따로 만들어야 하고… 시작도 하기 전에 지쳐버리더라고요. 그러다 **다니 캐러셀 제작 워크플로우를 보고 "이거다" 싶어서 참고**해 만들기 시작했고, 거기서 한발 더 나아가 "기획부터 발행 글까지" 한 번에 끝나는 나만의 콘텐츠 OS로 키웠어요.

## 📝 한 줄 소개

핫플 캐러셀 OS — 주제 한 줄만 넣으면 슬라이드·캡션·매니챗·블로그까지 AI가 한 번에 만들어주는 인스타 콘텐츠 제작기예요.

## 😣 Before → ✨ After

- **Before**: 캡션은 챗GPT, 이미지는 피그마, 매니챗 문구는 메모장… 도구를 넘나들다 매번 디자인은 흐트러지고, 한 세트 만들려다 결국 시작도 못 함
- **After**: 주제 입력 → 🚀 버튼 → 슬라이드 9장 + 캡션 2종 + 매니챗 문구 + **블로그 글**까지 디자인 고정된 채로 한 번에. 이제 사진만 넣고 검수 5분이면 발행 가능

## 🎯 주요 기능 (3~5개)

- 🚀 AI 전체 생성: 주제 한 줄만 넣으면 제목·슬라이드 구성·캡션·매니챗·블로그를 Claude가 3단계로 통째 만들어줘요
- 🎨 슬라이드 에디터: 1080×1350 실시간 미리보기 + 텍스트·크기·색상·딤·사진 원터치 편집. 디자인 토큰이 고정돼 있어서 룩이 절대 안 흐트러져요
- 📝 **블로그 에디터(일부러 같이 넣었어요)**: 인스타 캐러셀이랑 블로그를 한 앱에 넣어서, 같은 주제를 네이버 SEO 제목·본문·태그로 자동 변환해줘요. 수명 짧은 인스타 콘텐츠를 검색에 오래 남는 자산으로 재활용하려고요
- 🏷 플랫폼별 카피: 인스타·스레드 캡션 + 매니챗(ManyChat) DM 문구 3종 + 단톡방 공유 멘트
- 📥 PNG/ZIP 내보내기 + JSON 백업: 슬라이드 9장 한 번에 다운로드, 작업물 저장·복원

## 🔧 이렇게 만들었어요 (기술 스택)

HTML·CSS·Vanilla JS (단일 파일), Claude API (Anthropic SDK · 브라우저 직접 호출), html-to-image, JSZip, localStorage, Netlify, Claude Code

## 💡 삽질 & 인사이트

- 다니 캐러셀은 "인스타 한 채널"에 맞춰져 있었는데, 만들다 보니 **블로그 에디터를 일부러 같이 넣은 게 신의 한 수**였어요. 한 번 기획한 콘텐츠가 인스타+네이버 두 채널로 쓰이니까, 같은 노력으로 도달 채널이 공짜로 하나 더 생기더라고요
- AI한테 디자인까지 맡기면 매번 다른 게 나와요. **디자인은 코드에 고정하고 AI한테는 "내용만" 맡기는 구조**가 핵심이었어요 (토큰 = 단일 진실 공급원)
- 기능을 늘릴수록 오히려 안 쓰게 되더라고요. 탭을 2개(에디터·블로그)로 줄이고 "주제 한 줄 → 버튼 하나"로 압축하니까 그제서야 손이 가기 시작했어요. **단순함이 곧 지속성**인 것 같아요
