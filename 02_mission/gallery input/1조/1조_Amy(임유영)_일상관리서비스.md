## 📝 한 줄 소개
> 카드에 보일 1~2문장
브레인포그에도 내 방향을 잃지 않는 OKR 실행 시스템

## 😣 Before → ✨ After
- **Before**: 오늘 하루 뭘해야할지, 이것을 어떻게 실행해야할지 계획도 실행도 되지 않았다
- **After**: 이앱을 열면 내 목표들이 보이고, 각 할 일마다 "이것만 하면 시작된다"는 30초 행동이 붙어있다. 브레인포그가 와도 다음에 뭘 해야 할지 겁을 먹거나 오래 생각할 필요가 없다

## 🎯 주요 기능 (3~5개)
1. **트랙 + 목표 관리** — OKR Focus Area 구조로 삶의 영역을 세팅
2. **아침 준비** — 오늘 할 일 입력 → 목표에 연결 → 실행계획 세팅
3. **오늘 대시보드** — 컨디션 선택 + 시작행동 기반 실행 리스트
4. **시작행동 제안** — 할 일별로 30초짜리 첫 행동 3개 제안
5. **마무리 + 데일리 체크** — 완료 체크 + 루틴 기록 합산
6. **기록** — 트랙별 실행 비중, 컨디션 히스토리, 목표별 완료율
