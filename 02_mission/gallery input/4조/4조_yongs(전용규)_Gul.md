## 💬 WHY — 왜 만들었나
> 번역하면 몇 단어로 납작해지는 한국 감성 단어의 결을, K-컬처 팬이 제대로 **느끼고 소장하게** 만들고 싶어요 


## 📝 한 줄 소개
> 번역이 안 되는 한국 감성 단어를 감정·지문·소리·이미지·문화 5개의 축으로 풀어내는 PWA. K-컬처 팬이 단어를 느끼고, 수집하고, 카드로 공유한다.


## 😣 Before → ✨ After
- **Before**: 아련·한 같은 단어를 사전에서 찾으면 "faint / deep sorrow" 같은 납작한 번역 한 줄로 끝. 정작 그 단어가 품은 정서·문화 맥락은 사라지고, 팬이 콘텐츠에서 느낀 감정을 붙들 방법이 없었다.
- **After**: 한 단어를 **감정 지문(레이더) + 발음 + 무드 이미지 + 시·속담 구절 + 용례**로 입체적으로 체험하고, 마음에 든 단어를 **도감**에 모으고, **SNS 공유 카드**로 나눈다.

## 🎯 주요 기능 (3~5개)
-**감성 프로파일**: 감정 지문 레이더 + AI 무드 이미지 + 소리(BGM) + 퍼블릭도메인 시/속담 인용 + 오늘의 용례
-발음 듣기: 감정에 맞춘 보이스로 한국어 발음 재생 (TTS, Web Speech 폴백)
-감정 도감: 마음에 든 단어 수집 + 캘리그라피 따라쓰기 + 한 줄 메모
-공유 카드: 단어를 SNS용 이미지 카드로 생성 (손글씨·메모까지 합성)
-오늘의 단어 + 이메일 구독**: 매일 한 단어 리텐션 루프

## 🔧 이렇게 만들었어요 (기술 스택)
> Vanilla JS (프레임워크·외부 의존성 0), 단일 HTML + 모듈식 `src/*.js`, `node --test` 기반 TDD, Cloudflare Workers(배포·자동 재배포), GoatCounter(분석 깔때기), Buttondown(이메일), Google Cloud TTS(발음), Replicate Flux/MusicGen(이미지·BGM 사전 생성), Claude Code(페어 개발)
