## 💬 WHY — 왜 만들었나
> 검사는 정상인데 늘 피곤한 사람이, 영양제부터 사기 전에 *내 몸 어디가 지쳤는지 작동원리부터* 이해하게 하고 싶었다. (의사로서 추천·진단으로 미끄러지지 않는, 안전한 교육 도구로.)


## 📝 한 줄 소개
> 신경과 전문의가 만든 "내 몸 사용설명서". 증상으로 6개 시스템(소화·해독·면역·호르몬·에너지·영양 운반) 중 하나를 골라 둘러보며, 내 피로가 어디서 오는지 *작동원리를 공부*하는 학습 도구입니다. (진단 아님 · 데이터 수집 0)


## 😣 Before → ✨ After
- **Before**: 같은 6시스템 자가진단 앱이 영양소를 추천하고 "당신은 ~에 신호가 보입니다"라는 진단스러운 결과를 줬다 — 실명 전문의가 공개하기엔 의료법·건기식 광고 리스크가 컸다.
- **After**: 영양소 추천·데이터 수집·진단 verdict를 외과적으로 들어내고, *메커니즘 설명 + 자기관찰*만 남긴 교육 버전으로. 같은 콘텐츠가 안전지대로 옮겨가 공개 가능해졌다.

## 🎯 주요 기능 (3~5개)
- **증상으로 골라 둘러보기**: 6시스템 중 가장 신경 쓰이는 과정을 자가선택 → 그 시스템만 학습
- **작동원리 설명 + 도식**: "왜 이런 피로가 오는지"를 쉬운 비유와 그림으로
- **자기관찰 체크**: 습관 → 시스템 되짚기 (전부 내 브라우저에만, 외부 전송 0)
- **영양제 고르기 전 3가지**: 활성형·형태·복용 시간 *일반 상식* (개인 추천 아님, 별도 페이지로 분리)
- **데이터 수집 0**: 이메일·개인정보 요구 없음

## 🔧 이렇게 만들었어요 (기술 스택)
- 단일 HTML + CSS + 바닐라 JS (외부 의존성 최소), localStorage
- Vercel (배포), GitHub (버전 관리)
- Claude Code (전환 기획·6종 결과지 일괄 개조·검증 전부 AI 페어로)

## 💡 삽질 & 인사이트
- **"법적으로 위험한 건 도구이지 지식이 아니다."** 데이터 수집·성분 추천·진단 단정만 외과적으로 들어내니, 같은 자산이 안전지대로 옮겨갔다. 통째로 버리는 게 제일 아까운 선택이었다.
- **"안 만드는 결정"도 결과물.** 변호사 검토를 못 받은 1차안은 *봉인*(삭제 X)하고, 안전한 교육 버전만 공개했다. 멈추는 판단은 사람 몫.
- **프리뷰가 안 뜰 땐 화면 말고 데이터로 검증.** 브라우저가 localhost에 안 붙어서, HTTP로 HTML을 직접 받아 grep으로 "위험 콘텐츠(추천·verdict) 부재"를 증거 기반으로 전수 확인했다.
