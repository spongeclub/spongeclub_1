# 4주차 과제 — 거북이의꿈

  

## 미션1: <오늘 세션 적용 포인트 반영해서 내 프로덕트 개선하기>

네이버 쇼핑인사이트 인기키워드 분석 — Tailscale 외부 접속 + AI 응답속도 개선

  

### Summary

- **무엇**: 내 PC에서만 돌아가던 앱을 Tailscale(VPN)로 연결해 폰·노트북·스터디원이 어디서든 접속할 수 있게 했다. 동시에 AI 분석 대기 시간도 실용적인 수준으로 줄였다.

- **Tailscale이란**: 내 PC에 설치하면 인터넷 어디서든 내 PC로 안전한 사설 통로(VPN)가 생긴다. 클라우드 서버를 따로 만들 필요 없이, 내 PC 자체가 서버가 되는 방식.

  

### 최종 구현 결과물

- Tailscale로 외부 접속 완료 — 폰, 노트북, 스터디원 node 공유 모두 확인

- AI 분석(키워드 100개 분해) 대기 시간: 사실상 무한대기 → **18초**로 단축

- 진행 상황 표시: "5/100 → 10/100…" 진도율이 보여 기다릴 수 있게 됨

  

### 과정 (타임라인별 + 삽질)

1. **외부 접속 필요성**: PC 앞에서만 쓸 수 있으면 한계가 있어서 방법을 찾기 시작.

2. **클라우드 서버(VPS) 시도 → 포기**: 처음엔 VPS에 올려서 어디서나 쓰려 했는데, 이 앱은 네이버 데이터를 임의로 스크래핑하는 방식이라, 공개 서버에 올리면 네이버 측에 문제의 소지가 있어 배제했다.

3. **Tailscale로 방향 전환**: 서버를 새로 만드는 대신, 내 PC에 Tailscale만 설치해서 어디서든 접속 가능하게 전환. 접속자에게는 앱 화면만 보이고 내 PC 파일·화면은 노출되지 않는다.

4. **삽질 — "외부에서 분석이 안 돼"**: 외부 접속 후 분석을 돌리면 0%에서 멈췄다. 네트워크 문제인가 의심했는데…

5. **진짜 원인은 따로 있었다**: 외부 접속은 무죄. AI가 키워드 100개를 한꺼번에 처리하다 시간 초과로 죽는 것이었다(로컬에서도 같은 문제).

6. **AI 작업 쪼개기 + 모델 분리**: 100개를 5개씩 나눠 여러 개 동시 처리로 바꾸고, 단순 반복 작업엔 빠른 경량 모델(Haiku), 해석·비교엔 좋은 모델로 역할을 나눔 → 18초로 단축.

  

### 공유할만한 인사이트

- **Tailscale: 클라우드 서버 없이 내 PC를 공유하는 방법**: 서버 세팅이 복잡하거나 AI 로그인 문제로 클라우드 배포가 막힐 때 유용한 대안. 설치만으로 스터디원과 앱을 공유할 수 있다.

- **AI 작업도 쪼개면 빨라진다**: 100개를 한꺼번에 맡기는 것보다 5개씩 나눠 동시에 처리하는 게 훨씬 빠르다. 사람 업무도 마찬가지지만, AI에도 그대로 적용된다.

- **모델을 목적에 맞게 나눠 쓴다**: 단순 반복(분류)엔 빠른 경량 모델, 판단이 필요한 해석엔 상위 모델. 모든 걸 최고 모델에 맡기지 않아도 속도·품질을 같이 잡을 수 있다.

  

### 앞으로 할일

1. **카테고리 분석 스킬 개발**: 새로운 카테고리를 처음 스터디할 때 체계적으로 접근할 수 있는 분석 스킬(AI 지침·프레임워크)을 만든다. 어떤 카테고리든 일관된 방식으로 "이 시장의 성격은 무엇인가"를 파악할 수 있게.

2. **헤르메스 연결 — 정기 카테고리 스터디**: 그 스킬을 헤르메스(오케스트레이션)에 연결해서, 내가 직접 실행하지 않아도 정기적으로 새로운 카테고리를 자동으로 스터디하도록 한다.

3. **지식체계 → 시장 분석 보고서**: 쌓인 카테고리별 결과보고서들을 연결해 지식체계로 만들고, 그것을 토대로 더 큰 시장 분석 보고서를 생성한다. 단발 분석이 자산이 되는 구조.
