## 미션1: 사장님용 "AX 반복업무 진단" 사이트 — 받은 피드백 반영 + 실제 배포

- 👉 **바로 보기: https://ax-intake-copilot.vercel.app**

### Summary

지난번 받은 피드백 4가지를 사이트에 그대로 반영하고, 실제 인터넷 주소로 띄우는(배포) 것까지 끝냈습니다.

한 줄로: **사장님이 "매번 반복하는 일"만 적으면 → "2주 안에 해볼 작은 실험 / 지금 필요한 자료 / 다음에 확인할 질문"을 쉽게 정리해주는 사이트**입니다. 어려운 점수·용어는 뒤로 빼고, 업무에서 쓰는 말로 다시 썼습니다.

### 최종 구현 결과물

- **주소:** https://ax-intake-copilot.vercel.app (인터넷에 공개, 로그인 없이 바로 열림)
- **쓰는 법:** 쉬운 질문 몇 개에 답(예시로 채우기 버튼 있음) → 결과 화면에서 4가지를 바로 보여줌
- **사장님 자료를 함부로 다루지 않음:** 입력한 내용은 인터넷으로 보내지 않고 화면 안에서만 계산, 운영 중인 시스템은 건드리지 않음

받은 피드백 → 이렇게 고쳤어요:

- **① "결과가 조금 더 손에 잡히게"** → 어려운 점수를 앞세우던 걸 멈추고, **"지금 반복하는 일 / 2주 안에 해볼 작은 실험 / 지금 필요한 자료 / 다음에 확인할 질문"** 4가지를 먼저 보여줍니다. 정보가 부족하면 억지 답 대신 "먼저 정리부터 하자"고 솔직하게 안내합니다.
- **② "비개발자도 편한 말로"** → 어려운 IT 용어를 일상 업무 말로 바꿨습니다 (예: 어려운 영어 약자 대신 "초기 운영 구성안", "승인 단계", "진단 결과" 등).
- **③ "지식 없이도 쉽게"** → 처음 보는 사람이 겁먹지 않게, 어려운 진단 점수·유형은 뒤로 내리고 질문을 "지금 사람이 반복해서 하는 일은? / 자료는 어디에 있나요?"처럼 업무 말로 바꿨습니다.
- **④ "무엇을 써야 할지 막막함"** → **"재고/배분 예시", "엑셀 취합 예시" 채우기 버튼**(누르면 자동으로 채워짐), 모든 칸에 예시 문장, **"잘 모르겠습니다"도 그냥 선택 가능**, "완벽하게 안 써도 됩니다, 아는 만큼만"이라고 안내합니다.

### 과정 (타임라인별 + 삽질)

1. **어디를 고칠지부터 헷갈림** — 비슷한 화면이 두 개 있어서 처음엔 엉뚱한 걸 보고 있었습니다. 곧 알아채고 진짜 사이트로 바로잡았습니다.
2. **솔직하게 점검** — 지금 사이트가 *아무것도 안 눌러도 "최고 등급"* 을 띄우고, 어려운 점수를 앞세워서 처음 보는 사람이 겁먹기 쉬웠습니다. 여기부터 손봐야겠다고 판단.
3. **(가장 큰 삽질) 방향을 여러 번 바꿈** — "이 사이트로 결국 뭘 하려는 건가"를 먼저 정하지 않고 화면부터 고치다 보니 목적을 두세 번 갈아엎었습니다. 결국 **"사장님이 쉽게 적고 → 쉽게 결과를 보는 것"** 으로 단순하게 정리하고 나서야 길이 잡혔습니다.
4. **피드백 4개 반영** — 위 내용대로 화면과 말투를 다 바꿨습니다.
5. **다음 단계로 넘길 정리본 추가** — 적은 내용을 담당자가 이어받을 수 있게 **파일로 내려받는 기능**을 붙였습니다.
6. **점검 단계의 삽질** — 화면을 자동으로 확인해주는 도구가 잠깐 끊겨서, 하나하나 직접 돌려보며 결과를 확인했습니다.
7. **배포의 삽질** — 인터넷에 올리는 과정에서 한 번 길을 잘못 들었다가, **깃허브에 올린 뒤 → Vercel로 배포**하는 정석 경로로 바로잡아 공개 주소를 얻었습니다.

### 공유할만한 인사이트

- **글자만 보고 판단하면 거꾸로 거릅니다.** 예전엔 "고객정보는 **안** 다룹니다"라는 *안전한* 답을 오히려 위험으로 잘못 분류했어요. 안전한 사람을 놓치지 않게 고쳤습니다.
- **만든 사람이 자기 데모에 100점을 주면 오히려 안 믿깁니다.** 점수를 앞세우기보다 "그래서 뭘 할지"를 먼저 보여주는 게 낫습니다.
- **"무슨 사이트인지"를 먼저 못 정하면, 화면을 아무리 예쁘게 고쳐도 계속 흔들립니다.** 목적 먼저, 화면은 그 다음.
- **비개발자에게 쉬움 = 어려운 말 빼기 + 예시 채우기 + "잘 모르겠음" 허용 + 점수보다 할 일 먼저.**
- **진짜 중요한 건 화면이 아니라 화면 밖에 있습니다** — 손님이 어디서 오는지, 돈은 어느 단계에서 받는지, 실제로 만들어 줄 수 있는지. 다음엔 화면을 더 다듬기보다 **진짜 사장님 몇 분에게 직접 보여주고 반응을 보는 것**이 우선입니다.
