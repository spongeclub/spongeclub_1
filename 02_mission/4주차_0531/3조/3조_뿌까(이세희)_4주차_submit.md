## 미션1: 사람마다 다른 질문을 던지는 자서전 인터뷰 만들기

summary

질문 하나로 모든 사람을 인터뷰할 수는 없다고 생각했다. 그래서 "먼저 이 사람이 어떤 책을 원하는지 알아본 다음, 그에 맞는 질문으로 갈라지는" 방식으로 만들었다. 혼자 테스트하니 너무 오래 걸려서, 페르소나(가상 손님)를 만들어 자기들끼리 인터뷰하게 시켰다.

**최종 구현 결과물**

- 인터뷰 문서 7개 완성
  - 사람 유형을 알아보는 질문 1개 + 유형별 질문 4개(나를 위한 책 / 살아온 순서대로 / 가족에게 남기는 / 한 가지 경험을 깊이) + 인터뷰 끝나고 보여줄 정리 양식 1개 + 전체 사용 설명서 1개
- 중요한 장치 3개:
  - 손님이 어떤 책을 원하는지 + 어디까지 솔직하게 쓸지를 먼저 파악
  - 이야기마다 "그대로 쓸지 / 살짝 바꿀지 / 뺄지"를 손님이 직접 고르게 함
  - 질문 개수를 정해두지 않고, "필요한 내용이 다 채워지면" 끝나게 함
- 인터뷰가 끝나면 손님이 받는 것: "내 책이 어떤 모양이 될지" 한눈에 보여주는 그림 한 장 (손님용 / 나만 보는 작업용 두 가지)
- 페르소나로 인터뷰 돌려봄 (말 짧은 어르신 / 말 많은 가게 사장 / 자꾸 딴 얘기로 새는 사장)

**과정 (타임라인별 + 삽질)**

1. 인터뷰 끝에 손님한테 뭘 보여줄지부터 먼저 정함 → 그래야 질문이 거기에 맞게 따라옴
2. 첫 질문은 쉽고 또렷하게(유형 알아보기), 그 다음 질문은 깊게(이야기 끌어내기)로 성격을 나눔
3. 유형별 질문을 하나만 먼저 잘 만들고, 잘 되는 걸 확인한 뒤 나머지 3개를 똑같은 틀로 만듦
4. 삽질①: 혼자서 손님인 척 테스트하니 너무 느리고, 내 얘기만 나와서 다양한 경우를 못 봄
5. 방향 바꿈: 페르소나(가상 손님)를 만들어 자기들끼리 인터뷰하게 함 → 4가지 유형을 빠르게 확인
6. 삽질②: 두 유형이 자꾸 헷갈리는 문제 발견(나를 위한 책 ↔ 가족에게 남기는 책) → 헷갈릴 때 한 번 더 묻는 질문을 추가
7. 4번 테스트한 걸 모아서, 고칠 점 3개를 고치고 1차 완성

**공유할 만한 인사이트**

- 페르소나의 한계가 오히려 핵심을 알려줌: 페르소나는 곤란한 질문을 피하긴 하는데, 진짜 사람처럼 "불편해서 입을 닫거나 말을 돌리지" 않는다. 너무 술술 대답함. → 결국 진짜 사람이 머뭇거릴 때 어떻게 마음을 여느냐가 이 서비스의 진짜 실력이라는 걸 거꾸로 알게 됨.
- 실제로 고친 문제 3개 중 2개가 페르소나가 아니라 내가 직접 받아본 인터뷰에서 나옴 → 진짜 사람이 받아봐야 진짜 문제가 보인다.
- 한 번 이상하다고 바로 고치지 말고, 두세 번 반복되는 것만 고친다 → 손님 한 명 취향에 휘둘리지 않기 위함
