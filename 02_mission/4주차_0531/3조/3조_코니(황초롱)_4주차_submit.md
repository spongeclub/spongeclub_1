## 미션 1: 기록만 쌓이는 앱 말고, 나한테 먼저 말 거는 와인 앱으로

### Summary

이번 주엔 만들던 걸 또 엎었다. "환자 시선으로 콘텐츠의 빈 곳을 찾는 판독기"를 접고, 예전에 셀피쉬클럽 클로드 코드 워크샵 때 만들어본 와인 웹앱을 다시 꺼내 v2로 발전시켰다. 핵심 방향은 하나다 — 기록이 쌓이기만 하는 앱이 아니라, **앱이 나한테 먼저 말을 거는 쪽.** 이번 주 세션에서 배운 하네스·워크로그는 제품 기능이 아니라 "두 대 PC에서 작업이 이어지게" 만드는 데 적용했다.

### 최종 구현 결과물

배포 주소: https://wine-tasting-app-hazel.vercel.app

지금 되는 것:

- 와인 등록 · 셀러 재고 관리 · 테이스팅 노트 기록
- AI가 세 군데서 한 줄을 건넨다 — 와인 저장 직후 `✦ 한 모금에 부치는 말`, 홈의 `✦ 오늘 밤을 위한 한 줄`, 셀러의 `✦ 마실 적기`(지금이 마실 때인지 + 적기 연도 + 상태 배지)
- 호두나무 다크 테마 + 5개 탭(오늘 · 셀러 · 등록 · 취향 · 나)

세션 적용 결과물: 작업 맥락(서버 식별자·환경변수 목록·반복 버그 패턴)을 GitHub에 올라가는 문서 3개로 옮겨, 회사 PC에서 받아오기만 하면 맥락이 따라오게 만들었다.

아직 발전 중인 단계다. 모든 기능이 다 들어간 건 아니고, 디자인도 계속 수정하고 있다. 앱 캐릭터 '결이'도 시안 작업 중이다 — 콘셉트(취향에 따라 색이 변하고, 말풍선으로 말을 거는 동반자)는 잡혔고, 지금은 너무 정령처럼 보여서 빛 효과를 덜어내 톤다운할 계획이다.

### 과정 (타임라인 + 삽질)

**5/28 — 판독기 접고 와인 앱 다시 꺼냄** 이 앱은 원래 셀피쉬클럽 코드 워크숍 때 만들었다. 처음엔 "나한테 진짜 필요한 거다" 싶어 잘 썼다. 그런데 와인셀러를 사면서 LG 셀러 앱을 쓰게 됐는데, 셀러 관리(상·하칸 온도, 레드/화이트 몇 병, 몇 번 칸)도 잘 되고, 무엇보다 라벨만 찍으면 와인 종류·평균가·어울리는 음식까지 자동으로 들어갔다. 내가 만든 앱의 핵심(따자마자 테이스팅으로 연결)도 LG 앱에 이미 있다 보니 점점 안 쓰게 됐다. 그래서 이번엔 방향을 틀었다. 
보관·기록을 넘어, 앱이 내 취향을 먼저 찾아 "이 와인 이때쯤 따면 좋아요" 하고 말을 거는 쪽으로.

**5/29~30 — AI 붙이기 삽질** AI 한 줄 기능을 붙이려고 처음엔 Anthropic을 쓰려 했는데 결제가 안 돼서 Gemini로 바꿨다. 근데 Gemini도 모델이 자꾸 막혔다(쓰려던 모델이 신규 지원 중단이거나 레거시라 오류). 마침 이번 주 3조 오프라인 모임에서 Gemini API 오류난다는 이야기를 했는데, 구글 클라우드라는 팁을 줘서 API 키를 새로 발급받고 연결 후 지금은 정상 동작 중.

**5/30 — 화면 개편** 디자인을 전체적으로 한번 개편했다. 셀러를 병이 늘어선 그리드로 바꾸고 "마실 적기" 배지도 이때 붙였다.

**5/31 (오늘) — 세션 적용 (하네스·워크로그)** 내 앱이 하네스·워크로그 기준으로 잘 돼 있는지 Claude Code한테 진단을 시켰다. 규칙 문서 비대함이나 문서 연결은 양호했는데 "두 대 PC 연속성"이 약점으로 나왔다. 중요한 맥락이 전부 집 PC 안에만 있고 GitHub엔 안 올라가서, 회사 PC에선 매번 0에서 시작됐던 것. 그래서 GitHub 문서로 옮기고 비밀 값(키·토큰)이 새지 않게 파일을 바로 만들지 않고 내용 미리보기부터 받아 한 줄씩 검사했다.

### 공유할만한 인사이트

1. **만들었다고 다 쓰는 게 아니더라.** LG앱이 셀러 관리를 더 잘하니 내 앱을 안 쓰게 됐다. 그래서 "기존 앱이 잘하는 것" 말고 "기존 앱이 안 하는 것"으로 방향을 틀어야 했다. 평점도 남이 보는 평점으로 안 만든 이유가 비슷하다 — 남을 의식하면 솔직하게 못 쓰니까, 나만 보는 솔직한 기록으로 두고 싶었다. 그리고 단순한 기록에서 끝나는게 아니라, 내 취향을 찾아주고 내 와인 취향 동반자 느낌으로 발전시키고 싶었다.
    
2. **탄탄한 기획이 정말 중요하다** 기획을 잘 잡고 진행했다고 생각했는데도 초반에 더 탄탄하게 기획을 잘 잡고 갔어야 한다는 생각이 중간중간 들었다.

## 미션 2: 찐 고객 2명에게 피드백 받기

아직 바뀔 부분이 많지만 지금 상태 그대로 보여주고 솔직한 반응을 받았다. 
### 친구가 준 피드백 (원문)

> 일단 나같은 초보자한테 필요한 건
> 
> - 취향이 만들어지면(ex. 5병 이상 기록) 와인 추천해주는 거
> - 먹을 음식을 넣으면 잘 어울리는 와인 중에 내 취향에 맞는 거 추천해주는 거
> - 기록할 때 와인명만 입력하면 품종·산지는 못 끌어오나? 수기 입력 부분이 좀 줄었으면
> - '나' 탭에서 각 항목을 누르면 해당 데이터로 이동하면 좋을 듯 (테이스팅 기록 → 지난 모금, 셀러 보유 → 셀러 탭)
> - 선호 품종·산지는 별점으로 가중치 매겨서 가져오는 거야? 아니면 마셨으면 그냥 1점?

### 정리 — 두 종류로 갈림

**새로 만들 기능 (방향 제안)**

1. 취향 쌓이면 추천 / 2. 음식 → 취향 맞는 와인 추천 / 3. 와인명 입력 시 품종·산지 자동 채우기

**지금도 고칠 수 있는 것** 4. '나' 탭 항목 클릭 시 해당 데이터로 이동

### 친구 질문에 대한 답

선호 품종·산지는 **별점 가중치 없이 단순 횟수 카운트**다. 마신 횟수만 센다. 그래서 "별로였는데 자주 마신 와인"이 1위로 뜰 수 있다. 앞으로 별점을 반영하는 방식(횟수 × 평균별점 등)으로 바꿀 계획.

### 인사이트

친구가 제일 원한 게 1·2번(취향 기반 추천)이었는데, 이게 내가 원래 가려던 방향("앱이 내 취향 먼저 찾아 말 걸어주기")과 똑같았다. 3번(수기 입력 줄이기)도 내가 계획 중인 칩 입력과 같은 줄기. **친구 피드백이 내 방향을 검증해준 셈.** 그리고 5번 질문(횟수 vs 별점)은 내가 미처 안 챙긴 빈틈을 정확히 찔렀다 — "솔직한 취향"을 보여주는 앱인데 정작 취향 계산은 횟수만 보고 있었다.
