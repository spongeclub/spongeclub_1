### 공유할만한 인사이트

- **디자인 MD = SSoT의 위력**: 색·폰트·레이아웃을 코드에 박지 않고 MD에 박으면 디자인 수정 = *문서 갱신*. 5주차에 CLI를 웹과 동기화할 때 design.md만 보면 됨. 메타 정합성 회복.
- **본인용·공유용 인터페이스 분리 유지**: CLI는 깊은 자동화 (history.json·하네스·콘텐츠 MD), 웹은 단순함·와우 (폰트/테마 선택). 같은 코어, 다른 입력 압력. 한 프로덕트가 두 페르소나에게 다른 얼굴로.
- **EXIF 회전 같은 사소한 자국**: CLI는 한 줄 (Pillow의 `ImageOps`), 웹은 한 줄 (`createImageBitmap` 옵션). 안 하면 카드 전체가 망가짐. *사소한 디테일이 도구의 신뢰감*.
- **Canvas는 fonts.ready 추적 사각지대**: 명시적 `fonts.load()` 호출 필요. 모든 canvas 기반 그래픽 도구에 적용 가능한 일반 교훈.

## 미션2: 두 결의 사용자 피드백 (와이프 + 교회동료) + Good Morning Lion 15명 본부원 사례

### Summary

4주차 미션은 "2명 페르소나 피드백". 가족(와이프)·외부 친구(교회동료) 한 명씩 선정. **결과: 두 분 답이 완전 다른 결로 들어옴**. 와이프는 짧은 감정 반응("좋으네유"), 교회동료는 3층(외부 확증 + 확장 시그널 + 구체 진단). 이 *차이 자체*가 가장 큰 발견 — 같은 도구가 페르소나마다 다르게 받아지고, *KPI도 페르소나별로 달라야* 함.

추가로 회사 슬랙봇 **Good Morning Lion**(15명 본부원 대상)의 4주 운영 사례를 첨부 — 더 큰 표본에서의 실시간 피드백·반복 사이클이 모닝맘의 결론을 양적으로 보강.

### 최종 구현 결과물

- 와이프에게 차콜 폴라로이드 카드 전송 (5/31) → 와이프가 *본인 딸에게* 카드 만들어 보냄 (와이프 작성, 갤러리 추가)
- 교회동료에게 베이지 폴라로이드 카드 전송 (5/31) → 3층 피드백 수신
- **교회동료 피드백 두 가지 즉시 반영** (마감 1시간 전):
  - ✝️ 어울리는 성경 구절 함께 제안 토글 (가족버전 — 받는 사람 컨텍스트 깊이)
  - 관계 메타데이터 (관계·성별) + 관계별 결·예시 분기 (친구버전 — 오글거림 해소 첫 단계)
- Good Morning Lion 4주 실험 가동 중 (2026-05-27 ~ 2026-06-24), `#dailyreport_team` 운영, 누적 답장·결손·개선 기록

### 과정 (타임라인별 + 삽질)

#### A. 모닝맘 피드백 흐름

- 와이프·교회동료 선정 (가장 빨리 요청 가능한 페르소나 — *결*이 의도적으로 다름)
- 폴라로이드 카드 제작 (사진 + 한 줄 메시지) → 카톡 전송
- **와이프 답**: *"좋으네유"* (한 줄, 감정 반응)
- **교회동료 답**: 3층
  - (1) **반응**: *"단순 기능보다도 만든이의 마음이 느껴지고, 사용할 때도 남을 더 생각하게 되는 멋진 작품"*
  - (2) **확장 시그널**: *"가족에게 두루 쓸 것 같다. 친한 친구 버전도 있으면 좋겠다"*
  - (3) **구체 진단**:
    - *가족버전* — 메시지와 어울리는 *성경 구절 검색* 기능 추가해 첨부
    - *친구버전* — 친구와의 *관계(성별·만난이유) 설정* 옵션 필요. 현재 버전 그대로는 친구에게 "오글오글"
- **추가 진짜 확장 시그널**: 와이프가 *본인 딸에게* 카드 만들어 보냄 → 사용자가 직접 갤러리 추가 요청. 도구가 다른 손에 가서 *새 의미*를 만듦.

#### B. Good Morning Lion 피드백 흐름 (4주 실험, 더 큰 표본)

- **5/27 채널 투입, 첫날 즉시 4번 큰 조정** (15명 표본 실시간 관찰)
  - 날씨 API(`wttr.in`) 연동 — 날씨 모순 표현 방지
  - 행운지수 0~100 → 30~100 — *"출근 직후 한 자리수는 위로가 아닌 부담"*
  - `RESPOND_PROBABILITY` 0.75 → **1.0** — *"공개 채널 15명 환경에서 비대칭이 비교 압박 유발 → '강요·부담 없이' 원칙과 정반대"*. **1대1 봇 설계의 직관을 다인 공개 채널에 그대로 적용하면 안 된다는 교훈**.
  - `MIN_MESSAGE_LENGTH` 50 → 20 → **10** — Canvas로 리포트 쓰는 팀원 케이스 발견 → 점진적 하향
- **5/29 13건 답장 결과 포맷 붕괴 확인** (*"흐린 [요일], [기온형용사] 아침이네요"* 패턴이 거의 모든 출력에 등장) → 세 가지 동시 손봄:
  - 길이 20자 → **25~40자** (50% 증가)
  - **9가지 결**(위트·재미·감동·위로·공감·다정한 응원·관찰·시적·호기심) 매 호출 무작위 선택
  - prompt.md 좋은 예시 7개 → 결별 36개(9×4) 재작성
- **5/29 후속**: "100개로 늘릴 수 없나" 요청 → 정적 풀 한계 인지 → *코멘트도 Claude 생성으로 전환* + 정적 풀은 fallback
- **본부장 첫 100점 잭팟 빚 발생** (수동 커피)

### 공유할만한 인사이트

- **같은 도구, 다른 페르소나, 다른 KPI**: 가족 사용자에겐 "감정 반응 한 줄"이 충분한 신호, 외부 사용자에겐 "분석적 진단"이 자연스러움. 두 결 모두 valid — 도구 설계 시 *KPI도 페르소나별로 분리*해야 함. 한 가지 KPI로 모든 사용자를 측정하면 가족의 "좋으네유"가 약한 신호로 보임.
- **외부 진단이 우리 시스템 결손을 정확히 가리킨다**: 교회동료의 "성경 구절 검색" 욕구 = 컨텍스트의 *깊이* 부재 (받는 사람의 외부 자산 활용 미흡). "친구에게 오글오글" = 관계 메타데이터 부재 (톤 만으로는 관계 결 표현 불충분). → 4가지 차별점(컨텍스트·루프·관계·양식) 중 *컨텍스트 깊이*와 *양식의 관계 의존*이 다음 단계.
- **다인 공개 채널 = 1대1 도구의 직관을 뒤집어야 함** (모닝라이언 사례): "변주를 위한 25% 침묵"이 1대1에선 좋은데 15명 공개 채널에선 "왜 내 리포트만?" 비교 압박. **페르소나뿐 아니라 *맥락(채널 구조)*도 KPI를 결정**.
- **빠른 반복의 위력**: 모닝라이언은 운영 첫 둘째 날에 5번 큰 조정 → 4주 실험인데 첫 주에 핵심 결손 거의 다 발견. 일주일 한 번 회고보다 *실시간 사용 → 즉시 조정* 사이클이 훨씬 풍부. **모닝맘에도 똑같이 적용**: 교회동료가 제안한 두 가지(성경 구절·관계 메타데이터)를 원래 5주차 작업으로 미루기로 했다가 *마감 1시간 전 즉시 반영* — "5주차 후보"가 "오늘 라이브"가 됨. 이게 빠른 반복의 진짜 위력.
- **사용자가 본인 손으로 도구를 확장하면 진짜 확장 시그널**: 와이프가 본인 딸에게 카드 만들어 보냄 — 받는 사람만 바뀐 게 아니라 *사용자도 바뀐* 진짜 확장. "이 도구가 다른 손에서 다른 의미를 만든다"가 프로덕트의 진짜 검증.

- 모닝라이언 한 줄 추가: *맥락이 KPI를 결정*하는 원리가 회사 슬랙봇에도 적용 — 4주 동안 발견한 원리들이 *여러 도구에 횡적으로 작용*함을 보여줌
- 갤러리 URL + 본인 도구 URL 포함 → SNS 보는 사람이 바로 체험 가능
- 짧은 버전(스토리/숏폼용) 별도 작성

### 공유할만한 인사이트

- **3주차 SNS글과 결 분리**: 3주차는 morning-mom 자체를 소개, 4주차는 스폰지클럽이 *내 일하는 방식과 사고를 한 단계씩 바꿨다*를 자랑. 같은 모닝맘 사례도 *바라보는 렌즈*에 따라 메시지가 달라짐.
- **SNS글 = 도구의 *외부 게이트웨이***: 글에 본인 도구 URL + 갤러리 URL을 박으면 본인을 따라온 사람이 *바로 체험*. 모닝맘의 정적 LLM 도구 호스팅 패턴(GitHub Pages + Anthropic 브라우저 직접 호출)이 SNS 동선을 살림.
- **4주 누적 변화 자체가 컨텐츠**: 한 주차 자랑이 아니라 *4주 누적 변화*. 사고 변화가 컨텐츠가 되는 게 학습 모임의 가장 큰 산출.
- **다른 본인 도구로의 횡적 전파**: 스폰지클럽에서 발견한 원리가 회사에서 만든 도구(모닝라이언)에도 적용됨. *클럽이 단일 프로덕트를 위한 것이 아니라 내 모든 도구 빌드의 OS를 갈아끼우는* 효과.
