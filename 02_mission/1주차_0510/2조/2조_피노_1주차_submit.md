# 1주차 과제 — 피노

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary

os-interview-skill을 설치하고 40분 인터뷰를 통해 나의 OS 선언문과 첫 부품(아침 브리핑 스킬)을 만들었다.

**OS 선언문**: 나는 누구에게 무엇을 어떻게 전달할지만 결정하고, 나머지는 시스템이 한다.

### 최종 구현 결과물

- `~/.claude/skills/morning-briefing/SKILL.md` — 아침 브리핑 스킬 (설치 완료)
- `피노_os-blueprint.md` — OS 청사진

**사용법**: Claude에게 "오늘 브리핑", "아침 정리", "오늘 할 일" 등 말하면 4단계 인터뷰 후 우선순위별 체크리스트 출력

### 과정 (타임라인별 + 삽질)

1. `https://github.com/selfishclub/os-interview-skill` 클론 후 `~/.claude/skills/os-interview/`에 설치
2. os-interview-skill 발동 → Phase 1 (풍경 → 통점 → 이상향 → 부품 매핑) 인터뷰 진행
3. 가장 큰 통점 발견: 상사 구두 지시를 받을 때 시작 전 결정 비용이 가장 큰 것
4. 6개 부품 후보 중 첫 부품으로 "아침 할 일 요약" 선택
5. A(Claude 스킬) 형태로 결정 → Step 6 질문 5개 답변 후 SKILL.md 자동 생성
6. `~/.claude/skills/morning-briefing/`에 설치 완료

### 공유할만한 인사이트

- 인터뷰를 통해 "다 해야 한다"는 막연함에서 "첫 부품 1개"로 좁혀지는 과정이 핵심이었다
- 통점을 (a)시작 전 / (b)진행 중 / (c)끝낸 뒤로 나눠 물어보니 가장 실질적인 문제가 선명해졌다
- 결과물이 인터뷰 끝나자마자 바로 쓸 수 있는 형태(Claude 스킬)라 즉시 활용 가능

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary

유튜브 채널 **시리얼(Sireal)** 의 노션 업무 OS를 벤치마킹했다.
시리얼은 노션 공식 컨설팅 파트너로, 조직의 업무 방식을 노션 기반으로 체계화하는 전문 채널이다.
핵심 구조인 **대시보드 중심 업무 관리** 방식을 참고해 내 법률 사무 환경에 적용할 포인트를 도출했다.

- 참조 채널: [시리얼 Sireal - YouTube](https://www.youtube.com/@sirealco)

### 벤치마킹 핵심 구조

시리얼이 제안하는 노션 업무 OS의 핵심:

1. **대시보드 허브** — 모든 업무를 한 페이지에서 조망
   - 오늘 할 일 / 진행 중 / 완료로 상태 구분
   - 마감일 기준 자동 정렬

2. **프로젝트 단위 관리** — 사건/업무별 데이터베이스
   - 사건번호, 담당자, 마감, 상태를 한 DB에서 관리
   - 필터·정렬로 원하는 뷰 즉시 생성

3. **반복 업무 템플릿화** — 매일/매주 반복되는 업무를 노션 템플릿으로 1클릭 생성

### 내 상황에 적용할 포인트

| 시리얼 구조 | 피노 적용 방향 |
|------------|--------------|
| 대시보드 허브 | 아침 브리핑 스킬 출력 → 노션 오늘 할 일에 연동 |
| 사건/프로젝트 DB | 법원 사건번호 목록 + 진행상황 DB화 |
| 반복 업무 템플릿 | 상사 구두 지시 → 노션 할 일 항목 자동 생성 |

### 공유할만한 인사이트

- 노션 OS의 핵심은 **도구 자체가 아니라 "어떤 단위로 쪼개느냐"** — 시리얼은 프로젝트·할 일·문서를 분리하지 않고 하나의 DB로 연결하는 방식을 씀
- 내 통점(상사 지시 누락, 사건 진행상황 파악)은 시리얼 구조의 "상태 관리 DB"로 해결 가능하다는 걸 확인
- 미션 1에서 만든 아침 브리핑 스킬의 출력을 노션 대시보드와 연결하면 Claude → 노션 흐름이 완성됨
