## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary
10명 팀으로 모의투자 경연에 참가 중인 상황에서, 가장 큰 통점은 "확신을 얻고 싶다"는 것. 비전문가다 보니 비정상적으로 오르는 시장에서 확신을 갖기 어려워 고점 확인에 대한 인간 지표를 마련해보기로 함. 이상향은 **"나는 최종 매매 결정만 하고, 나머지는 시스템이 한다"로 설정, 첫 번째 OS 부품으로 "시장 심리 분석기" 스킬을 개발.
이 스킬은 최신 경제 뉴스와 댓글을 자동 수집해서 일반 투자자들의 감정을 분석하고, 댓글 수량 변화와 "지금이라도 살까?" vs "너무 올랐는데" 같은 키워드 비율을 조합해서 고점 여부를 판별하는 HTML 리포트를 생성.

### 과정 (타임라인별 + 삽질)
  Phase 1 - OS 청사진 그리기
  - Step 1: 현재 상황 파악 → 투자팀 + AI 프로젝트 활동
  - Step 2: 통점 발굴 → 처음엔 "결정 지연"이라고 생각했지만, 실제로는 "확신 부족"이 핵심이었음
  - Step 3: 이상향 정의 → "나는 최종 매매 결정만 하고, 나머지는 시스템이 한다" 도출
  - Step 4: 부품 후보 → 결정 보조 영역이 가장 필요하다고 판단

  Phase 2 - 첫 부품 선택의 삽질들
  - 첫 제안: 시장 심리 수치화, 과거 사례 분석, 매매 타이밍 → "세 개 다 필요하다" 저항
  - "하나만 해야 하는 이유" 설득 → "왜 하나만?"이라는 반박
  - 각 부품 설명 후 → 1번(이미 공포지수 체크중), 2번(특수상황이라 도움 안됨) 제외
  - 3번(매매 타이밍)도 애매해서 → "완전히 다른 각도" 요청
  - "시장 흐름 해석기" 제안 → 승락했지만...

  Phase 3 - 실용성 의문과 방향 전환
  - 스킬 설계 시작 → "실질적으로 도움이 될지 모르겠다" 의문 제기
  - Claude가 단순 정리만 하는 것보다는... → "기사 댓글 읽어오는 거 가능?" 아이디어
  - 댓글 분석으로 "고점 판별" 방향 전환 → 훨씬 실용적!
  - 계산법 고민: 단순 키워드 비율 vs 가중치 vs 댓글수량+감정 조합법
  - 최종 선택: 3번 (댓글 폭증 × 고점신호 비율)

  핵심 삽질 포인트:
  1. "다 필요하다" vs "하나만" 줄다리기
  2. 처음 아이디어들이 현실적이지 않았음
  3. 댓글 분석 아이디어가 게임 체인저였음
  4. 계산법도 여러 번 수정해서 최적화
### 공유할만한 인사이트
이미 다 알고 계시는 것들이지만 기록 차원에서 남겨봅니둔-
  1. "너는 어떻게 생각해?" 효과
  - 계산법 여러 개 제시했을 때 "넌 어떻게 생각해?" 물어봄
  - Claude가 이유까지 설명하며 추천 → 더 깊이 있는 답변
  - 포인트: Claude에게 판단을 맡기면 생각보다 합리적 근거 제시함

  2. 실현 가능성 체크의 중요성
  - "어떻게 작동할 건지 알려줘" 질문이 게임 체인저였음
  - 막연한 아이디어를 구체적 한계까지 파악 → "실질적 도움 안 됨" 깨달음
  - 포인트: "어떻게"를 물어봐야 허상 vs 실제 구분 가능

  3. "용량" 같은 현실적 제약 고려
  - HTML vs PDF vs Excel 고를 때 "용량 어떤 게 작지?" 물어봄
  - 기능만이 아니라 실사용 조건까지 고려하는 습관
  - 포인트: Claude에게 현실 제약 조건을 명확히 알려주기

  4. 방향 바꾸기 주저하지 말기
  - 시장 흐름 해석기 → 댓글 분석기로 완전 바뀜
  - "이거 별로네" → 즉시 새 방향. 매몰 비용 의식 안 함
