## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary

1. 클로드와 이야기해서 지금 내 상황에서 어떤 OS를 만들면 좋을지 시장조사하였고, 투두리스트 OS가 좋다고 판단함. 사실 해당 기능은 노션에서도 가능하나 나에게 맞춤화된 OS를 만들고 싶었음
2. PC를 키면 항상 스티커메모 앱을 켜놓고, 그 날 해야 할 일들을 적고 나서 일을 시작하는데, 맞춤화된 투두리스트 OS가 있으면 좋을 것 같다고 생각하기도 했었음
3. https://habitica.com/ 여기에서 캐릭터가 장비를 갖추고 자라는 것을 보고 나도 새싹에서 꽃이되는 움직이는 성장 요소를 넣기로 함
4. 투두리스트에 많은 일들을 해야하지만, 스트레스를 덜받고 재밌게 즐기면서 일을 하나씩 해내가기 위해서 재미있는 요소들을 계속해서 추가함

### 과정 (타임라인별 + 삽질)

1. 노트북을 키면 매일 스티커 메모로 투두리스트를 적고 시작했는데, 나한테 맞춤화 된 투두리스트를 만들고 싶었음
2. 해야할 일이 많아서 스트레스를 받지 않게 재밌는 요소를 넣고 싶어짐
3. 고정적으로 해야할 일들이 너무 나열됨 -> 구조 재정비 필요함
![[Pasted image 20260507164111.png|518]]

4. 이왕이면 재밌는 기능들이 추가되면 좋을 것 같아서, 클로드와 계속 질문해서 업그레이드 함
5. 재밌는 기능을 계속 넣고 싶어서, 계속해서 구조를 개선해서 진행요청함
![[Pasted image 20260507170341.png|654]]
6. 2일차에 사용해보니, 몇가지 에러사항이 있어서 수정 요청함
	1. 2일차인데 여전히 1일차로 표시
	2. PC에서는 가시성이 떨어짐 -> 애초에 반응형으로 디자인 요청했어야 하는 것을 나중에 알아서 수정 요청함
	3. PC와 모바일 작성내용 연동 필요 -> 선택적 로그인 방식으로 수정 가능하다고 함(사용해보고 필요 시 개선 예정)
=> 전체적으로 기획단에서 내가 어떤 디자인 및 기능을 넣어야할지 구체적으로 알려주어야 만들고나서 수정하는 것의 시간을 절약하는 것을 깨달음. 이번이 처음 만드는 거라서, 계속해서 만들다보면 감이 익혀질 것 같음.
