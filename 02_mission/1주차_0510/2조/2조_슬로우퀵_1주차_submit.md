# 1주차 과제 — 슬로우퀵

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary

OS Interview 스킬로 기획부터 시작해 Vibelog 웹앱을 하루 만에 배포까지 완료했다.

### [최종 구현 결과물](https://vibelog-eta.vercel.app/)

매일 배운 것을 기록하고, 같은 내용을 **나 / 전문가 / SNS** 세 가지 관점으로 자동 변환해주는 학습 일지 앱.

### 과정 (타임라인별 + 삽질)

**기획** — OS Interview 스킬로 인터뷰 형식의 기획서를 만드는 것부터 시작했다. 여기서 삽질이 있었다. 원하는 게 무엇인지, 어떤 기능이 필요한지 정리하는 과정이 생각보다 쉽지 않았다.

**개발** — Claude Code와 함께 Next.js + Supabase 연동, 화면 구성, 탭 UI, 마크다운 렌더링까지 진행했다.

**자동화** — 다른 사람이 만들어놓은 write-post 스킬을 기반으로, 나에게 맞게 수정해서 요약 정리부터 배포까지 연결되는 흐름을 만들었다.

### 공유할만한 인사이트

빠르게 만들고 싶은 마음이 독이 됐다. 수정·삭제 같은 기본 기능도 없이 일단 만들었다. 수정은 나중에 고쳤지만, 삭제 기능은 아직도 없다. 처음부터 필요한 기능을 한 번 정리하고 만들었다면 덜 돌아왔을 것.

배포 전에 테스트를 먼저 했어야 했다. 한 번에 배포까지 진행했더니, 뭔가 고칠 때마다 기획→개발→배포 전체 과정을 다시 거쳐야 했다. 배포 전에 충분히 테스트하고 수정한 뒤 올리면 이 반복이 줄어든다는 걸 이번에 알았다.

앞으로 하고 싶은 것 — 좀 더 익숙해지면 Obsidian과 연결해볼 계획이다.

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary

1인 기업가가 구글 서비스 전체를 CLI 하나로 자동화한 영상을 벤치마킹했다.
👉 [gwscli 설치부터 실전 활용까지](https://www.youtube.com/watch?v=S99_UhOQjNw)

### 과정 (타임라인별 + 삽질)

이메일 정리가 계속 쌓이는 게 문제였다. 뉴스레터, 결제 알림, 보안 메일, 프로모션 — 종류는 다른데 매번 손으로 처리하고 있었다.

그러다 이 영상을 발견했다. 세 개 사업을 혼자 운영하는 1인 기업가가 매일 아침 탭 15개씩 열던 루틴을 명령어 하나로 바꾼 이야기였다. 249개 이메일 중요도 분류, 뉴스레터 189개 자동 요약, 유튜브 링크 → 슬라이드 자동 생성까지.

반복되는 잡무에 시간을 쓰고 있다는 건 나도 같았다. 이 사람의 OS가 내게도 필요한 것이었다.

막힌 것도 있었고 끝까지 다 못 한 것도 있었다. 자동 필터 생성은 API 권한 문제로 결국 실패했다.

### 공유할만한 인사이트

**gwscli가 MCP와 다른 점**

Claude Code에 Google 서비스를 연결하는 방법은 MCP 서버를 직접 설정하는 것도 있다. 그런데 gwscli는 MCP 서버가 내장되어 있어서 복잡한 설정 없이 바로 Claude Code와 연결된다. Google API 목록도 실시간으로 읽어서 명령어가 자동으로 생성된다.

- MCP: 직접 연결 설정 필요
- gwscli: 설치하면 연결 포함

**다 해보고 알게 된 것**

막상 다 하고 나니까 — 영상 속 사람만큼 이걸 활용할 상황이 지금의 나에게 필요한 건 아니라는 것도 알았다. 벤치마킹이 꼭 그대로 따라하는 게 아니라, 해보면서 내 상황에 맞는 것과 아닌 것을 가려내는 과정이기도 했다.

그래도 오늘의 수확은 하나였다. 구글과 Claude Code가 연결됐다.
