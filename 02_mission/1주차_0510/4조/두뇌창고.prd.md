# 두뇌창고 PRD

**버전**: v0.1
**작성일**: 2026-05-09
**상태**: 초안

---

## 한 줄 정의

흩어진 메모·사진·음성을 자동으로 수집하고, AI가 분류·정리·검색해주는 개인 지식 관리 모바일 앱.

---

## 문제 정의

### 핵심 통점
"어디다 저장하지?" 결정 비용이 너무 높아서 → 아무데나 저장하게 되고 → 나중에 찾을 수 없다.

### 현재 상황
- 메모 채널: Apple 메모, UpNote, 갤럭시 메모, 카카오톡 나에게 보내기
- 이미지: 아이폰 갤러리에 저장
- 문제: 각 채널은 필요에 따라 계속 써야 하지만, 한 곳에서 볼 수 없고 찾기가 어려움
- 기존 데이터: 수년간 쌓인 메모·사진이 정리되지 않은 채 산재

## 핵심 기능 (v1)

### A. 다채널 수집 (Ingestion)
- Apple 메모 연동 (iCloud API 또는 Shortcuts 자동화)
- UpNote 연동 (Export API 또는 주기적 동기화)
- 갤럭시 메모 연동 (Samsung Notes API 또는 Export)
- 카카오톡 "나에게 보내기" 연동 (카카오 API)
- 아이폰 갤러리 연동 (Photos Framework)
- 수집 주기: 실시간 또는 설정 가능한 주기 동기화

### B. 소급 정리 (Retroactive Cleanup)
- 기존 데이터 일괄 분석
- 중복 내용 감지 및 병합/삭제
- 연관 내용 자동 연결 (유사도 기반)
- 주제별 자동 분류 (AI 생성 카테고리)
- 진행 상황 표시 (정리 전/후 비교)

### C. 신규 자동 분류 (Auto-classification)
- 새로 수집된 항목 자동 분석
- 주제 카테고리 자동 태깅
- 기존 항목과 연관 관계 자동 연결
- 분류 결과 확인 UI (틀리면 수정 가능)

### D. 검색 (Retrieval)
- 자연어 검색: "이 주제 관련 내용 다 보여줘"
- 검색 목표: **30초 안에 원하는 내용 찾기**
- 주제별 집계 뷰 (관련 메모 + 이미지 + 음성 한 화면에)
- 중복 없이, 빠지는 내용 없이 표시

### E. 음성 처리 (Voice to Text)
- 음성 메모 녹음 → 텍스트 자동 변환
- 내용 기반 제목 자동 생성 (기본값 "녹음_날짜" 대신)
- 주제별 자동 분류
