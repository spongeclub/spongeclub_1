# 1주차 과제 — 달빛그린

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary

Claude Code의 `os-interview` 스킬로 6단계 인터뷰를 진행하고, 나만의 OS 청사진과 첫 프로덕트 PRD를 완성했다. 결과물: **두뇌창고** — 흩어진 메모·사진·음성을 AI가 자동으로 수집·분류·정리해주는 모바일 앱 기획서.

### 최종 구현 결과물

- [`os-blueprint.md`](os-blueprint.md) — OS 청사진 전체 (선언문 + 풍경/통점/이상향/부품 목록)
- [`두뇌창고.prd.md`](두뇌창고.prd.md) — 프로덕트 기획서 (기능 정의 + 로드맵 + 기술 스택)

**OS 선언문**: 나는 캡처·기록(음성 포함)만 하고, 나머지는 시스템이 한다.

### 과정 (타임라인별 + 삽질)

**Phase 1 · 청사진 (Step 1~4)**
- Step 1 풍경: 대기업 UX 디자이너 → AX 이동, AI 공부 + 사람 탐구가 핵심 관심사
- Step 2 통점: 메모가 Apple 메모·UpNote·갤럭시·카카오 4군데에 산재. 사진은 아이폰 갤러리 따로.
- Step 3 이상향: 내용에 맞춰 알아서 분류, 30초 안에 찾기
- Step 4 부품: 캡처 자동 분류 / 음성 제목 자동생성 / 기존 메모 소급 정리 / 주제 검색 — 4개 도출

**Phase 2 · 첫 부품 결정 (Step 5)**
- 부품 3(소급 정리)을 첫 부품으로 선택
- 처음엔 A(Claude 스킬) 고려 → 파일량 너무 많아서 B(플러그인)로 → 다채널 연동 필요해서 C(PRD)로 최종 결정

**Phase 3 · PRD 작성 (Step 6)**
- 5개 질문으로 빠르게 정리: 이름·사용자·기능·플랫폼·성공지표·제약조건

### 공유할만한 인사이트

**"어디다 저장하지?"가 진짜 문제였다.**
분류 결정 비용이 높으면 뇌가 아예 분류를 포기한다. 저장은 되는데 꺼내 쓸 수 없는 구조가 된다. 해결책은 결정을 없애는 것 — AI가 내용을 보고 알아서 분류하면 사용자는 그냥 던지기만 하면 된다.
