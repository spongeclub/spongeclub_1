# Foodspot Cards 🍜

달빛그린이 다녀온 맛집 사진 묶음을 던지면, **자동으로 가게 식별 → 정보 보충 → 인스타 카드 시리즈 마크다운**까지 만들어주는 스킬.

회상이나 빈 칸 채우기가 아니라 **사진 안에 있는 단서로 직접 추정하고 검색해서 채운다.** 사용자는 사진만 던지고, 나머지는 부품이 한다.

## When to use this skill

### 자동 발동 트리거

- "맛집 카드 만들어줘", "이 사진들로 카드뉴스", "맛집 후기 정리해줘"
- 음식·가게 사진 폴더(또는 다중 이미지)를 첨부하며 "정리"·"카드"·"인스타"·"후기" 언급
- "이번에 다녀온 ○○ 카드뉴스로", "사진들 던질 테니까 알아서 만들어줘"

### 발동하지 않아야 할 상황

- 사진 없이 글로만 후기 작성 요청 → 일반 글쓰기로 처리
- 식당 추천·검색 ("강남에 좋은 일식집?") → WebSearch 단독 사용, 카드 생성 X
- 일반 사진 정리·앨범화 (음식 외) → 다른 도구로
- 단일 음식 사진 1장만 → 카드 시리즈가 의미 없음, 캡션 한 줄만 제안

## How this skill works

5단계 흐름. **빈 칸 질문은 사진에서 추정 불가능한 것에만 한정.** 그 외는 모두 추정으로 1안을 채워 던지고 사용자가 편집.

### 🔑 모든 단계의 default 패턴: **Draft first, confirm second**

빈 칸 질문은 가장 비싼 입력 방식이다. AI는 매 단계에서:

1. **사진·EXIF·웹 검색 결과로 1안을 먼저 작성**
2. **"이걸로 갈까요? / 다르면 말해주세요"** 형태로 던짐
3. 사용자는 "ㄱㄱ" / "OK" / "이건 바꿔" 한 줄로 답하면 끝

빈 칸 질문은 **본인만 알 수 있는 것**(방문 일자, 동행 여부, 개인적 감상 톤)에서만 사용.

### Step 1 · 사진 스캔 — **시각 단서 우선, 회상은 보충용**

**목적**: 사진 안의 객관적 단서로 가게·메뉴·분위기를 끌어냄.

**Claude의 행동 순서**:

1. **이미지 폴더(또는 첨부 묶음) 자동 스캔** — 각 이미지를 Read하여:
   - **간판·메뉴판·영수증·포장지**의 텍스트(상호, 메뉴명, 주소, 전화번호)
   - **음식 종류**(한식/일식/중식/양식/카페/디저트, 대표 음식 추정)
   - **인테리어·분위기**(좌석 형태, 조명, 인스타 감성/노포/파인다이닝)
   - **EXIF**(촬영 일시, GPS) — 가능하면 추출
2. **사진별로 한 줄씩 요약 테이블** 제시:
   ```
   img_01.jpg — [간판 "○○○"] · 일식 우동집 · 외관
   img_02.jpg — 붓카케 우동 클로즈업 · 면 위 가츠오부시
   img_03.jpg — 영수증 (주소: 서울 ○○구 ○○동 ...)
   ...
   ```
3. **그 다음에 사용자에게 질문** (회상 X, 선별·보충):
   > "사진 단서로 **○○○(가게명)** 같아 보이는데 맞나요? 그리고 카드에 들어갈 사진 **6~8장**만 골라주세요(번호 OK). 추정 안 맞으면 가게명 한 줄만 알려주세요."

4. **단서가 거의 없을 때만** fallback 회상 질문:
   > "사진에서 가게 식별이 어렵네요. 상호 한 줄 / 위치(동네) 한 줄만 알려주세요."

### Step 2 · 가게 정보 보충 — **WebSearch로 한 번에**

**목적**: 가게의 공개 정보를 보충해 카드의 신뢰도와 활용도를 올림.

**Claude의 행동 순서**:

1. 가게명(+ 동네)으로 WebSearch — 후보 정보:
   - 정확한 상호·지점(분점 구분)
   - 도로명 주소
   - 영업시간 / 정기 휴무
   - 대표 메뉴 1~3개 + 가격대
   - 평점·리뷰 수(네이버/구글 중 잡히는 대로)
   - 예약·웨이팅 방식(있다면)
2. **출처가 갈리는 정보는 "확인 필요" 마크.** 자신 있는 것만 단정형으로.
3. 검색 결과를 카드 frontmatter 후보로 정리해 사용자에게 1번에 던짐:
   ```
   가게: ○○○ (○○점)
   주소: 서울 ○○구 ○○로 ...
   영업: 11:30–21:00 (브레이크 15:00–17:00, 일 휴무)
   대표: 붓카케 / 카레우동 / 텐동
   가격대: 1.2~1.8만원
   평점: 4.5 (네이버 ○○○건) [확인 필요]
   ```
4. **"이대로 카드에 박을까요? 틀린 줄 한 줄만 알려주세요."**

### Step 3 · 카드 시리즈 설계 — **사진 순서 = 스토리텔링**

**목적**: 6~8장 카드 시리즈의 흐름을 짠다.

**기본 순서 템플릿** (필요시 변형):

1. **표지** — 대표 사진 1장 + 가게명 + 한 줄 후크
2. **외관/입구** — 위치·분위기 첫인상
3. **시그니처 메뉴** — 1~2장(클로즈업 + 풀샷)
4. **사이드/세트** — 곁들임·세트 구성
5. **공간/디테일** — 인테리어·플레이팅·소품
6. **요약/팁** — 영업시간·예약 팁·재방문 의사

**Claude는 사진 후보를 자동으로 슬롯에 배정**해 1안 제시:
```
1번 표지: img_05 (외관 + 간판)
2번 외관: img_01
3번 시그니처: img_07, img_08 (붓카케)
...
```

> "이 배정으로 갈까요? 1번 표지만 다른 컷으로 바꿔요? 라는 식으로 한 줄만."

### Step 4 · 카피 작성 — **슬라이드 캡션 + 게시물 본문**

**목적**: 슬라이드별 1~2줄 캡션과 게시물 본문(150~250자)을 동시에 출력.

**캡션 톤 옵션** (사용자가 첫 사용 때 한 번만 고름, 이후 기억):
- **담백** — 사실 위주, 군더더기 없음
- **감성** — 분위기·감정 위주, 형용사 풍부
- **위트** — 짧은 농담·후크 위주

**Claude 행동**:
1. Step 1~3 결과로 캡션 1안 + 본문 1안 + 해시태그 후보 8~12개를 한 번에 출력
2. 본인만 알 수 있는 디테일(동행, 방문 목적, 재방문 의사)은 **빈 칸 1줄로 남기고 표시**:
   ```
   [본인 한 줄 추가] 누구랑 갔는지 / 왜 갔는지 / 또 갈 건지
   ```
3. **"본문 톤 OK? 빈 칸 한 줄만 채워주세요."**

### Step 5 · 출력 + 라우팅

**목적**: 마크다운 1파일 산출 + 다음 액션 제안.

**Claude 행동**:
1. `/02_mission/.../attachments/` 또는 사용자가 지정한 위치에 `YYMMDD_<가게슬러그>_cards.md` 저장
2. 후속 액션 후보 1~2개 던짐:
   - "이대로 인스타에 올릴 캡션만 클립보드로 복사할까요?"
   - "이 가게 같은 톤으로 다음 맛집도 만들 거면, 사진 폴더 경로만 다음에 던져주세요."

## Harness rules

### 규칙 1 · 추정 실패 시 사용자 회상으로 도망가지 않기

발동: 사진에서 가게 식별이 안 될 때.

❌ "어디 가셨었죠?" 빈 칸 질문 X
✅ "사진에 잡힌 단서: [메뉴 ○○], [영수증 끝 4자리 ○○○○], [간판 일부 ○○]. 이걸로 검색해 후보 2~3개 던질게요."

### 규칙 2 · 사실과 추정을 섞지 않기

발동: 영업시간·가격 등 변동 정보를 단정형으로 박을 때.

> 검색으로 1차 출처가 잡히면 단정, 출처 갈리면 "[확인 필요]" 마크. 사용자가 본인 방문 시점 정보로 덮어쓸 수 있게.

### 규칙 3 · 카드 수가 너무 많아지면 잡아당김

발동: 사진이 15장 이상 들어와 카드가 10장을 넘어갈 때.

> "10장 넘어가면 인스타에서 끝까지 보는 사람이 절반 이하예요. 핵심 6~8장만 남기고 나머지는 '추가 컷' 폴더로 빼둘게요."

### 규칙 4 · 본인 톤·디테일은 빈 칸 1줄로 남기기

발동: 캡션에 동행·재방문 의사·개인 감상 등 본인만 아는 것을 AI가 지어낼 때.

> "이건 추정으로 채우면 진짜성이 깨져요. 한 줄만 본인이 채워주세요." 빈 칸 1줄로 표시.

## Output format

YAML frontmatter + 슬라이드 섹션 + 게시물 본문 + 해시태그.

```markdown
---
date: YYMMDD
type: foodspot-cards
shop: 가게명 (지점)
address: 도로명 주소
hours: "11:30–21:00 (브레이크 15:00–17:00, 일 휴무)"
signature: [붓카케, 카레우동]
price_range: "1.2~1.8만원"
tone: 담백 | 감성 | 위트
images: [img_05, img_01, img_07, img_08, ...]
---

# 🍜 가게명 — 카드 시리즈

## 1. 표지 (img_05)
> <한 줄 후크>

## 2. 외관 (img_01)
<1~2줄 캡션>

## 3. 시그니처 — 붓카케 (img_07, img_08)
<1~2줄 캡션>

...

## 📝 게시물 본문 (150~250자)

<본문 텍스트>

[본인 한 줄 추가] 누구랑 / 왜 / 또 갈지

## 🏷 해시태그
#가게명 #지역맛집 #일식 #우동맛집 #서울맛집 ...
```

저장 위치 권장: `02_mission/.../attachments/YYMMDD_<가게슬러그>_cards.md`
