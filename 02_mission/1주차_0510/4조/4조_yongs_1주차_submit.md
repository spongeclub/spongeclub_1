# 1주차 과제 — yongs

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary

셀피쉬클럽 GitHub에 공개된 `os-interview-skill`을 Claude Code에 설치하고, 6단계 인터뷰를 완주. 결과물로 **OS 청사진 1장**과 **첫 부품(아이템-노트 스킬)** 을 손에 넣었다.

**OS 선언문**: "나는 방향을 결정하는 것만 하고, 나머지는 시스템이 한다."

### 최종 구현 결과물
**1. `os-blueprint.md`** — OS 청사진

- 풍경: 퇴사 후 창업 준비 중. 하루 대부분을 아이템 리서치·경쟁사 분석에 투입
- 통점: 정보 수집 후 → 구조화·문서화·확신까지 가는 과정 전체가 비용 (구조 모름 + 손 안 감 + "이게 맞나?" 불안)
- 이상향: 데이터는 주제별로 정리되어 있고, 방향 결정만 내가 한다
- 부품 후보 7개 목록화

**2. `~/.claude/skills/아이템-노트/SKILL.md`** — Claude 스킬

- 발동: "아이템 노트 정리해줘"
- 기능: 오늘 아이템 대화 요약 + 개선 방안 3가지 + 내일 액션 아이템
### 과정 (타임라인별 + 삽질)
**Day 1 — 설치**

- GitHub 저장소 확인 → `gh` CLI로 레포 구조 파악
- `~/.claude/skills/os-interview/`에 `git clone`으로 설치
- 삽질: `Skill` 툴로 직접 발동 시도했다가 실패. `os-interview`는 built-in 스킬이 아니라 SKILL.md를 Claude가 읽고 따르는 방식임을 파악. "내 OS 만들고 싶어" 키워드로 수동 발동.

**Day 1 — 인터뷰 (Phase 1~2)**

- Step 1~4까지 진행하다가 중간에 수면으로 중단
- 다음날 "내 OS 이어서 만들고 싶어"로 재개 → 이전 맥락 그대로 유지됨

**Day 2 — 인터뷰 완주 + 결과물 생성**

- Step 4 부품 매핑: 7개 부품 후보 도출
- Step 5 첫 부품 결정: 6번 (아이템 대화 요약·개선안)을 추천 근거와 함께 선택
- A/C 형태 질문 → A 먼저, 나중에 C로 업그레이드하는 전략 채택
- Step 6: 스킬 이름·발동 트리거·출력 구조 결정 → 파일 생성 완료

### 공유할만한 인사이트
- **"A부터 만들고 C로 업그레이드하는 순서"** — 바로 오늘 쓸 수 있는 것 먼저, 나중에 자동화하는 전략이 실행력을 높임

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary
**벤치마킹 대상** 조쉬빌더 (뉴스레터·스레드로 월 5천만원 수익화한 1인 크리에이터) — 글쓰기 습관 → 팬덤 구축 → 수익화 구조

### 최종 구현 결과물
슬랙 기반 글감 파이프라인 OS

- `/글감 [내용]` 입력 시 Notion DB에 자동 저장
- 태그 자동 분류 (K뷰티/대기업/창업/몸·건강/40대)
- 글감 수집 → 초안 → 퇴고 → 발행 4단계 파이프라인

### 과정 (타임라인별 + 삽질)
- 슬랙 앱 생성 — 봇 유저 없음 에러 → App Home에서 봇 이름 등록으로 해결
- Notion 인테그레이션 연결 — 페이지 권한 설정이 까다로움, 표(Table)와 데이터베이스 차이로 인한 오류
- Railway 배포 — `not_in_channel` 에러 → 채널에 봇 초대로 해결
- Notion 토큰 무효화 → 재발급 반복

### 공유할만한 인사이트
- 코딩 경험 0%여도 Claude와 함께 슬랙 봇을 하루 만에 구축 가능
- 글감이 떠오를 때 바로 슬랙에 던지는 구조가 핵심 — 마찰을 줄여야 습관이 생긴다
- 콘텐츠 생산을 하려면 먼저 글감을 쌓는 시스템이 필요
