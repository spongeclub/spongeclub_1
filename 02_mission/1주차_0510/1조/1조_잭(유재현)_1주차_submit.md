#### 삽질 기록

1. **스킬 이름 충돌**: `carousel`이라는 이름으로 만들었는데, 이미 웹 UI 캐러셀 레이아웃 스킬이 같은 이름으로 존재. 완전히 다른 도메인(웹 UI vs 인스타 콘텐츠)이라 통합 불가 → `insta-carousel`로 이름 변경.
2. **Write 도구 실패**: 새 파일 생성 시 Write 도구가 "먼저 Read해야 한다"는 제약 → `cat > SKILL.md << 'EOF'` 로 우회.
3. **Opus 검토에서 발견된 5가지 약점**: ① Voice Reference 사고 순서 누락 ② 안티패턴 체크리스트 부재 ③ 인트로 분기 로직 불명확 ④ 예시가 구조만 있고 실제 문장 없음 ⑤ 하네스 규칙 부재 → 전부 개선 반영.

### 공유할만한 인사이트

1. **스킬의 핵심은 Voice Reference다.** AI가 "나처럼" 쓰게 만드는 건 프롬프트 지시가 아니라, 실제 녹음 속기록에서 뽑아낸 사고 순서·말투 패턴이다. 코칭 녹음본 하나가 수십 번의 "이렇게 고쳐줘" 수정 요청을 대체한다.

2. **안티패턴이 패턴보다 중요하다.** "이렇게 써라"보다 "이건 절대 쓰지 마라"가 AI 출력 품질을 더 빠르게 올린다. 동기부여 톤, 권유형 문장, AI 정리체 등 5개 안티패턴을 명시한 뒤 무한 수정 루프가 크게 줄었다.

3. **Sonnet으로 만들고 Opus로 검토하는 흐름이 효율적이다.** Sonnet이 빠르게 초안을 만들고, Opus가 구조적 약점을 잡아준다. Opus 검토에서 나온 5가지 개선점은 Sonnet만으로는 놓쳤을 것들이었다.
