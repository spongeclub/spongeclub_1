## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary
스킬 사용의 유용성을 알게 되었고, 
스킬을 통해 나만의 새로운 커스텀 스킬을 만드는 것을 경험함. 

### 최종 구현 결과물
1. OS 청사진 : 개인용, 회사용 각2개
2. 부품: 커스텀 스킬 생성 : "호흡의 하루" 1인 회사의 삶에 도움을 주고자하는 스킬을 구현 및 매일 사용 중

### 과정 (타임라인별 + 삽질)
1. 클로드 코드가 그릇된 가설이나 섣부른 판단으로 진행할 때와 충분한 사고 과정을 거치지 않은 결과물 생성할 때마다 매번 정정해줘야하는 비용 발생 -> 초기에는 충분한 협의 없이 바로 결과물이 생성되어 사용하면서 계속 수정사항 발생 
2. 한국어 어휘와 맥락이 잘 학습되지 않은 스킬이라 삽질이 많았음


### 공유할만한 인사이트
- AI사용에서 늘 발견하는 부분으로, 사용자가 제대로 된 방향과 깊은 사고를 통해 똘똘히 리드해야 함
- 기존 가지고있던 OS구조를 다른 시각으로 작업해볼수 있어서 좋은 기회였음.

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary
1인 기업을 위한 좌충우돌 세팅 과정 중 한걸음을 나아가봄.

### 최종 구현 결과물
옵시디언 새로운 보관함 생성 및 PC와 MO SYNC를 통해 작업환경 새롭게 구현. 아래 이미지는 모바일 세팅 화면. 


### 과정 (타임라인별 + 삽질)
1. 1인 기업의 좋은 사례들을 클로드 코드를 통해 조사를 시켰는데 퀄리티 이슈로 클로드로 이동하여 재작업 후, 해당 내용을 코드로 전달함. 그러면서 클로드안에서 깊이 빠져버려 잠시 스킬과 코드를 잊어버림
2. 그리고 동시에 기존 생성한 커스텀 스킬 '호흡의 하루'를 사용하며 불편한점 발생, 문제인식. 해결을 위해 벤치마킹 사례와 더불어 해당 문제 해결하고자함
3. 문제점 : 하루에 3번 코드에 접속하여 대화를 통해 기록해나가는데 외부에 있으면 컴퓨터 접속이 어려워 기록누적이 상실됨. 몇차례 해보니 해당 부분은 개선필요하다고 판단하여 코드와 소통하여 모바일(아이폰)과 PC(윈도우) SYNC 연동을 구현함.
4. 모바일로 옵시디언 설치하고 아이클라우드 폴더 연동시키고, PC에 아이클라우드 설치하고 옵시디언 연동시키고. 이 세팅 과정이 복잡하여 약 1시간 정도 걸쳐 설치 및 테스팅 까지 완료
5. 1차 구조적 문제점 해결완료. 


### 공유할만한 인사이트
한 곳에서 완성도 높고 만족할만한 결과가 나오지 않아,
클로드, 클로드코드, GPT, 노트북LM을 퀄리티이슈로 옮기며 작업을 하였습니다. 작업물을 통일하는 것을 신경썼음에도 산재되는 이슈가 발생하고, 어디서 어떤 작업을 했는지 기억나지 않게 되어 또다른 이슈 발생하였습니다. 이 과정을 매끄럽게 효과적으로 해나가는 것에 개선이 필요하다는 것을 깨달았습니다.
