# 1주차 과제 — 라라

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary

Claude Code와 1:1 인터뷰 형식으로 대화를 진행. 현재 하고 있는 일과 창업 배경, 고객 사례, 앞으로의 방향까지 5개 질문으로 구성된 인터뷰를 완료했다.

### 최종 구현 결과물

**인터뷰 전문**

**Q1. 간단히 자기소개 부탁드려요. 현재 어떤 일을 하고 계신가요?**

> 안녕. 나는 현재 SNS 콘텐츠 제작·운영하는 회사를 준비하고 있어. 그 외에 프리랜서로 콘텐츠 기획을 하고 커뮤니티 운영 일도 하고 있어. 사업가·프리랜서를 돕는 일에 관심이 많고 요즘은 부동산에도 관심이 많아졌어!

**Q2. SNS 콘텐츠 제작 회사를 준비 중이신데, 어떤 계기로 창업을 결심하게 되셨나요?**

> 내가 창업을 하고 싶은 사람이었는데 어려운 점이 많더라. 그래서 초기에 돈을 많이 들이지 않고 세상에 내 비즈니스를 선보이는 방법으로 콘텐츠가 큰 효과가 있다는 생각이 들었어. 내 비즈니스를 하는 사람들이 자신의 특성에 대해 고민하고, 더 잘 살아갈 수 있는 방법과 노하우를 가지도록 돕는 일을 앞으로도 하고 싶어.

**Q3. 지금까지 가장 기억에 남는 클라이언트나 프로젝트가 있나요?**

> 가장 기억에 남는 고객은 코칭을 하시는 분인데, 너무 바쁘게 몰아쳐서 살아오다가 체계화를 시도하신 고객이야. 기존 고객 데이터를 잘 정리하고 체계화하면서 콘텐츠도 만들어나가다 보니 효과가 좋았어. 고객도 자신의 삶에서 공백을 만들고 쉬면서 채우는 시간을 확보할 수 있었어. 외부에 흔들리기보단 자신의 중심을 잡고 외부에 영향을 줘나가는 모습의 변화에 함께할 수 있어서 기뻤어.

**Q4. 부동산 관심을 콘텐츠·커뮤니티 운영과 어떻게 연결하실 생각인가요?**

> 사업가나 프리랜서는 수익의 변동성이 크고 자산 면에서 안정성이 떨어져서 심리에도 영향을 주는 것 같아. 그래서 앞으로 이런 내용의 콘텐츠도 만들고, 사람들이 행복하게 내 일을 하면서 자산 관리도 할 수 있도록 도와나가고 싶어.

**Q5. 1년 후 가장 이루고 싶은 한 가지를 꼽는다면?**

> 가장 이루고 싶은 건 내 콘텐츠 쌓아두기! 내 콘텐츠 저장소에서 그때그때 필요한 자료들 뽑아서 드릴 수 있게 준비해두기. 그리고 고객들과 접점 만들어두기.

### 과정 (타임라인별 + 삽질)

- Claude Code 채팅창에서 바로 인터뷰 진행
- 질문 5개, 자연스러운 대화 흐름으로 완료
- 별도 툴 설치 없이 텍스트 인터뷰만으로 진행 가능하다는 걸 확인

### 공유할만한 인사이트

- Claude Code를 인터뷰어로 쓰면 준비 없이도 자연스럽게 내 생각을 정리할 수 있다
- 질문에 답하다 보면 스스로도 몰랐던 방향성이 정리되는 효과가 있다
- 콘텐츠 기획 초안, 자기소개 작성, 포트폴리오 정리 등에 응용 가능

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

콘텐츠 저장소를 체계적으로 쌓고 꺼내쓰는 시스템을 만들고 싶어서 선정. 내 목표인 "콘텐츠 저장소 구축 → 필요할 때 꺼내서 활용"과 가장 직결되는 시스템.

### 최종 구현 결과물

**Tiago Forte의 시스템 분석**

**누구인가?**
10년 이상 전 세계 2만 명 이상에게 생산성 시스템을 가르친 전문가. 컨설팅 회사에서 정보 과부하에 시달리다가 직접 시스템을 개발. Forte Labs CEO.

**핵심 시스템 1 — PARA 방법론**
모든 디지털 정보를 4가지 카테고리로 분류:
- **P**rojects (프로젝트): 단기 목표가 있는 작업
- **A**reas (영역): 지속적으로 관리하는 삶의 영역
- **R**esources (자원): 참고용 정보·자료
- **A**rchives (아카이브): 완료되거나 더 이상 쓰지 않는 정보

**핵심 시스템 2 — CODE 프레임워크**
수집한 정보를 창의적 결과물로 만드는 흐름:
- **C**apture (캡처): 일단 모은다
- **O**rganize (정리): PARA로 분류한다
- **D**istill (추출): 핵심만 남긴다
- **E**xpress (표현): 콘텐츠로 꺼낸다

**철학**: "뇌는 아이디어를 저장하는 곳이 아니라 생각하는 곳" → 외부 시스템에 맡겨라

**참고 자료**
- 유튜브: Tiago Forte 채널 (Building a Second Brain)
- 공식 사이트: buildingasecondbrain.com

### 과정 (타임라인별 + 삽질)

**Step 3. AI가 시스템 리서치 + 한국어 정리**

> 나: "티아고 포르테의 시스템 찾아서 정리해줘"

AI가 직접 웹 리서치 후 한국어 요약 제공:
- 누구인가 (배경, 경력)

→ 나는 읽고 판단만 함. 조사·정리·번역을 AI가 전담

**Step 4. PARA 시스템 옵시디언에 직접 구현**

> 나: "음 2에서 정리만 하는 게 아니라 직접 만들어야 해. 저거 만들 수 있게 도와줘"
> 나: "응 좋아!"

AI가 내 인터뷰 내용(프리랜서·커뮤니티·부동산·콘텐츠 저장소)을 기반으로 옵시디언 볼트 안에 폴더와 파일을 직접 생성:

```
04_etc/라라_PARA/
├── 01_Projects/
│   ├── SNS회사_준비.md       ← 창업 목표·체크리스트
│   └── 스폰지클럽_1주차.md   ← 현재 진행 중인 과제
├── 02_Areas/
│   ├── 프리랜서_운영.md      ← 클라이언트 목록·월별 수익 관리
│   ├── 커뮤니티_운영.md      ← 멤버 현황·운영 루틴
│   └── 부동산_공부.md        ← 학습 현황·관심 지역 메모
├── 03_Resources/
│   ├── 콘텐츠_저장소.md      ← 핵심! 아이디어·후킹문구·레퍼런스
│   └── 고객_사례_모음.md     ← 코칭 전문가 사례 1호 바로 기록
└── 04_Archives/
    └── README.md
```

빈 폴더가 아니라 내 상황에 맞는 내용이 채워진 스타터 파일로 생성됨

AI가 바탕화면 파일 목록 전체를 분석 후 카테고리 분류 제안:

### 공유할만한 인사이트

- **방향만 내가, 실행은 AI가** — "콘텐츠 저장소", "좋아", "진행해줘" 같은 짧은 말 한 마디로 조사·생성·정리가 다 됨
- **인터뷰 → 목표 발굴 → 시스템 적용** 순서가 효과적. 막연한 생각을 AI 인터뷰로 먼저 언어화하면 다음 단계가 쉬워짐
- **디지털 OS는 한 번에 완성하는 게 아니라** 대화하면서 조금씩 수정·보완하는 것 (번호 추가, 이름 수정 등)
- **PARA는 옵시디언 안에서만이 아니라 바탕화면에도 똑같이 적용 가능** — 어디든 Projects / Areas / Resources 개념으로 나누면 됨
- 옵시디언 + Claude Code 조합으로 나만의 OS를 대화하듯 빠르게 만들 수 있음
