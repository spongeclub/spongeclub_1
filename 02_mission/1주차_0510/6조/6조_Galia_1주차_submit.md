## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary

| 항목          | 내용                                            |
| ----------- | --------------------------------------------- |
| **사용한 스킬**  | `os-interview-skill`                          |
| **만든 것**    | OS 청사진 1장 + 첫 부품 `goal-to-roadmap` Claude 스킬  |
| **OS 선언문**  | _"나는 클로드가 정리해준 거 갖다 붙여넣기만 하고, 나머지는 시스템이 한다."_ |
| **첫 부품 위치** | `~/.claude/skills/goal-to-roadmap/SKILL.md`   |
| **상태**      | 인터뷰 종료 = 즉시 사용 가능                             |
GitHub 레포의 `os-interview-skill`을 클론·심볼릭링크로 설치해서 6단계 인터뷰(풍경 → 통점 → 이상향 → 부품 매핑 → 첫 부품 결정 → 결과물 작성)를 완주. "컨텍스트 휘발" 통점 → "반자동 정리 시스템" 이상향 → 첫 부품으로 **목표→로드맵 자동 분해기**를 만듦.

### 최종 구현 결과물
- **OS 청사진**: `os-blueprint.md`
- **첫 부품 스킬**: `~/.claude/skills/goal-to-roadmap/SKILL.md`
- **첫 부품 출력 형태**: 4단계 인터뷰 → 스테이지 표 + Mermaid Gantt 차트 + 첫 주 일자별 투두 (1페이지 마크다운)

### 과정 (타임라인별 + 삽질)

🙋‍♀️ **사용자 입장**

1. **설치 시도** - 클로드에게 링크 주고 설치해 달라고 함
2. **OS 인터뷰 답변 (Step 1~4)**
   - **Step 1 풍경**: 4개 컨텍스트(취준·알바·플래너·스폰지클럽) → 자발/어쩔수없이 라벨링. 자발 활동(스폰지클럽·플래너)이 위. 욕망과 시간 분배 정렬됨.
   - **Step 2 통점**: 1순위 "컨텍스트 휘발" 즉답. 한 줄 = "내 머릿속을 외장하지 못한다".
   - **Step 3 이상향** ⭐: "월요일 아침에 요약 보고서 + 투두리스트 떠있음" — 짧고 정확.
   - **Step 4 부품 매핑**: 5개 부품 자연 파이프라인 (입력 → 분해 → 일상 → 회고 → 다음주 시작).
3. **첫 부품 + 형태 즉답 (Step 5)** — "목표→로드맵 분해기" / 형태 "A (Claude 스킬)".
4. **Q1~Q6 답변 (Step 6)** — SKILL.md 채울 6개 질문에 답.

🤖 **클로드 입장**

1. **인터뷰 진행** — 6단계(풍경 → 통점 → 이상향 → 부품 매핑 → 첫 부품 결정 → 결과물 작성) 질문 던짐, 라벨링·묶음 분류 발판 제공.
2. **OS 선언문 도출** — Step 3 짧은 답을 한 줄 선언문으로 정리.
3. **부품 후보 묶음 분류** — 입력 처리 / 결정 보조 / 출력 생성 / 소통·관계.
4. **SKILL.md 작성** — Q1~Q6 답을 받아 첫 부품 스킬 파일 채움.

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary

| 항목          | 내용                                                                 |
| ----------- | ------------------------------------------------------------------ |
| **벤치마킹 대상** | Paul Dickson "Notion to Obsidian Life OS" Part 1 (YouTube 5부작 시리즈) |
| **흡수한 것**   | 사이클 연결 — Daily ↔ Weekly ↔ Monthly 자동 링크                            |
| **만든 것**    | 개인 todo 시스템용 옵시디언 개인 vault (`spongeclub_1_private/life-os/`)       |
| **스택**      | Periodic Notes · Templater · Dataview                              |
| **검증**      | `goal-to-roadmap` 출력을 weekly 노트에 그대로 붙임 → 통과                       |

### 최종 구현 결과물

- 개인 vault: `spongeclub_1_private/life-os/` (스폰지클럽 공개 레포와 분리)
- 템플릿 3종: `_templates/{daily,weekly,monthly}.md`
- 검증용 weekly: `weekly/2026-05-W20.md` — Ploplan 로드맵(스테이지 표 + Mermaid Gantt + 5/11~5/17 일자별 투두) 박아둠
- 플러그인: Periodic Notes / Templater / Dataview

### 과정 (타임라인별 + 삽질)

**1. 대상 결정**

다른 멤버 7명 사례 보니 두 갈래 — A) 한 가지 흡수, B) 풀스택 구현. **A 갈래** 선택. Paul Dickson Part 1 안 4가지 중 **사이클 연결**이 미션 1 OS 파이프라인의 빈 칸("일상")과 가장 자연스럽게 엮여서 채택.

**2. 삽질**

🙋‍♀️ 내가 막힌 것

| # | 내용 |
|---|---|
| 1 | 월요일 시작 설정 위치를 못 찾음 → 기본값 유지 |
| 2 | "W19" 표기가 직관과 안 맞음 → 한국식 "5월 N주차"로 바꾸고 싶음 |
| 3 | 첫 시도가 "5월 1주차"로 잘못 뜸 (5/9는 2주차여야 함) |
| 4 | "이번 주" 위키링크 클릭해도 weekly 노트로 안 감 (빈 노트만 생성) |
| 5 | "Day 1 (월), Day 2 (화)" 표기가 헷갈려서 실제 일자로 바꾸고 싶음 |

🤖 클로드가 헤맨 것

| #   | 내용                                                                                                                         |
| --- | -------------------------------------------------------------------------------------------------------------------------- |
| 1   | moment.js에 "week of month" 토큰 없음 → 첫 식 `Math.ceil(date/7)`이 한국 관습 못 맞춤. ISO Monday + 월 첫 Monday 카운팅 공식으로 수정                |
| 2   | Periodic Notes의 `{{date:...}}`는 명령어 호출 시에만 작동, 위키링크 경유는 안 거침. 템플릿을 Templater 전용 `<% %>` 문법으로 다시 쓰고 Folder Templates 매핑에 일임 |

**3. 검증**

`goal-to-roadmap` 4단계 인터뷰(목표 / 마감·투입 / 4스테이지 / 출력) 진행 → 출력의 "첫 주 일자별 투두"를 `weekly/2026-05-W20.md`에 그대로 붙임 → 통과.

### 공유할만한 인사이트

🙋‍♀️ **사용자 입장**

1. **일단 한 가지 골라서 시작하기** = 쪼개서 시작하기
2. **클로드한테 다른 사람 것에서 인사이트 얻게 시키기** = 2번 과제가 감이 안잡혀서 터미널에서 클로드한테 다른 사람들 어떻게 했는지 분석해 오라고 시킴
3. **못 하겠으면 클로드한테 시키기**

🤖 **구현 입장**

1. **Periodic Notes ↔ Templater 통합 트릭** — Periodic Notes Template 칸 비우고 Templater Folder Templates에 일임. 명령어·위키링크 양쪽에서 동일 작동.
2. **한국식 "5월 N주차" 계산** — ISO Monday 기준 + 월 첫 Monday 카운팅 (`firstOfMonth.isoWeekday(1)` 후 이전이면 7일 빼기).
