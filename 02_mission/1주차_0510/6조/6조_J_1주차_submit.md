# 1주차 과제 — J

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary

**핵심 반복 작업 2가지 1)주간 보고서 작성**과 2) **주식 정보 수집/정리** — 를 Claude Code 스킬로 자동화. 코드 한 줄 몰라도 `.skill.md` 파일 하나로 Claude를 전문 파트너로 만들 수 있다는 걸 직접 증명했다.

### 최종 구현 결과물

|결과물|설명|
|---|---|
|`os-blueprint.md`|전체 자동화 전략 설계서. 내가 왜 이걸 만드는지 선언|
|`weekly-report-automation.skill.md`|엑셀 데이터 붙여넣기 → 주간보고서 자동 생성 스킬|
|`stock-analysis.skill.md`|시황 요약 / 종목 분석 / 포트폴리오 점검 / 실적 분석 4모드 스킬|
|`stock-analysis-test.md`|스킬 테스트용 예시 입력 4종 세트|
|주간보고서 Excel 4종|이번주 / 지난주 / 전년동기 / 실제 보고서 생성|
|`briefing-dashboard.html` + `briefing-slide.js`|섹터 브리핑 웹 대시보드|

### 과정 (타임라인별 + 삽질)

**1단계 — 왜 만드냐부터 씀 (OS Blueprint)** 막연히 "자동화하고 싶다"가 아니라 "하루 4시간 + 개인 1~2시간 되찾기"라는 목표를 먼저 글로 썼다. pain point를 3개로 정리하고 우선순위를 정함.

**2단계 — 주간 보고서 스킬 제작** 가장 시간이 많이 드는 것부터. 엑셀 복붙 → 자동 분석 → 보고문 생성 구조를 설계. 톤앤매너(대상, 간결, 숫자 우선)까지 스킬에 명시. 실제 엑셀 데이터로 4종 파일 생성까지 검증.

**3단계 — 주식 분석 스킬 제작** 4가지 모드(시황/종목/포트폴리오/실적) 설계. 테스트 케이스도 별도 파일로 만들어서 재사용 가능하게.

**4단계 — 코드 영역으로 확장 (삽질 구간)** 브리핑 대시보드를 HTML로 만드는 과정에서 Tradingview라는 곳의 위젯을 붙였는데 이상하게 실시간데이터가 맞지 않았다.

그래서 히트맵을 붙여도 보고, 자동 캡처로도 붙여보는 과정에서 삽질의 구간이 있었던 것 같다.

### 공유할만한 인사이트

**OS Blueprint가 먼저 생성되니 왜 만드는지 명확해져서 작업 속도가 올라가는 것 같다.**

역시 기획 의도, 이유가 명확해야 결과물이 목적에 맞게 빠르게 잘 나올 수 있다는 것을 실감했다.

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary

유튜브 영상(클로드×텔레그램 AI 24시간 일시키는법) 참고. 컴퓨터 앞에 없어도 모바일로 Claude Code에 작업을 지시할 수 있는 원격 제어 환경 구축 시도. 이동 중에도 AI를 활용하고 싶다는 니즈에서 출발.

### 최종 구현 결과물

텔레그램 봇 'J의 비서' 생성 완료. 단, 봇 생성 및 토큰 발급 단계까지만 구현됨. Claude Code와의 실시간 양방향 메시지 송수신은 미완성 상태.

### 과정 (타임라인별 + 삽질)

1. 텔레그램 BotFather로 봇 생성 및 API 토큰 발급
2. Claude Code에서 텔레그램 플러그인 설치 (`claude plugins install telegram`)
3. `/telegram config`로 토큰 등록 및 `.env` 저장
4. Telegram MCP 서버 실행 시도 → **실패** (bun 미설치가 원인)
5. bun 설치 후 터미널 재시작
6. 텔레그램에서 DM 발송 테스트 → 여전히 무반응, 상호작용 미완성

bun이 설치되어 있지 않으면 MCP 서버 자체가 뜨지 않음. 에러 메시지만으로는 원인 파악이 어려워 시간 소요.

### 공유할만한 인사이트

- Claude Code 텔레그램 연동의 **bun** 이라는 것을 사전 설치 필수, 공식 문서에 명시가 약하므로 주의
- 봇 생성 자체는 5분이면 되지만, MCP 서버 실행 환경 세팅이 실질적인 허들
- 모바일 원격 제어가 되는 워크플로우가 가능하다는 것을 알게됨
