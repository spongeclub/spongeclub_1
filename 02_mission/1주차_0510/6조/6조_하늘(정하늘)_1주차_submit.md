# 1주차 과제 — 정하늘

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary
콘텐츠 크리에이터로서 매일 반복되는 "오늘 뭐 만들지" 결정 비용을 없애기 위해 OS Interview를 진행했다. 인터뷰 결과 OS 선언문과 첫 부품(아이디어 수집기 스킬)이 완성됐다.
**OS 선언문**: 나는 콘텐츠 제작만 하고, 나머지는 시스템이 한다.
### 최종 구현 결과물

**1. os-blueprint.md** — OS 청사진

- 풍경: 직장인 + 콘텐츠 크리에이터
- 통점: 아이디어 결정 비용 (시작 전 결정 비용이 가장 큼)
- 이상향: 아침에 열면 토픽 리스트가 이미 준비되어 있는 상태
- 부품 후보 4개: 아이디어 수집기 / 성과 분석기 / 콘텐츠 캘린더 / 출판 자동화

**2. idea-collector.skill.md** — Claude 스킬 파일

- 트리거: "콘텐츠 주제", "토픽 추천", "아이디어 뽑아줘"
- 4단계 플로우: 워밍업 → 맥락 파악 → 아이디어 생성 → 정리 출력
- 출력: 제목 + 구성 초안 3개
- `~/.claude/commands/`에 넣으면 즉시 사용 가능
### 과정 (타임라인별 + 삽질)

**시작 전: OS-interview skill 을 어디서 받아야 하는지 헤맸음...다른 skill인 deep interview 기능도 써보게 됨.
**Step 1 풍경** — 직장인 + 콘텐츠 제작. 두 정체성을 동시에 운용 중이라는 것을 명확히 언어화.
**Step 2 통점** — "아이디어 찾기"가 반복 비용. 처음엔 막연했지만 "(a) 시작 전 결정 비용 / (b) 진행 중 집중력 / (c) 끝낸 뒤 정리" 세 가지로 쪼개자 즉시 (a)라는 답이 나옴.
**Step 3 이상향** — "아침에 열면 토픽 리스트가 이미 있다"는 구체적인 장면이 나왔고, 이게 OS 선언문의 핵심이 됨.
**Step 4 부품 매핑** — 아이디어 수집기 / 성과 분석기 / 콘텐츠 캘린더 / 출판 자동화 4개 도출.
**Step 5 첫 부품 결정** — 아이디어 수집기 선택. 형태 결정 과정에서 "트렌드 자동 수집이 A에서 되나요?" 질문이 나왔고, A(스킬)의 한계를 확인한 뒤 일단 A로 시작하기로 결정.
**Step 6 스킬 설계** — 5개 항목(정체성/트리거/단계/질문/출력) 빠르게 확정. "백로그 리스트"보다 "제목+구성 초안 3개"가 더 실용적이라는 사용자 판단으로 출력 형식 수정.
### 공유할만한 인사이트
**1. "통점을 3가지로 쪼개는 질문"이 핵심이었다**  
"뭐가 불편해요?"는 너무 막연하다. "시작 전 / 진행 중 / 끝낸 뒤 — 셋 중 어디가 가장 비용이에요?"라고 쪼개자 즉시 답이 나왔다. 통점 발굴에서 가장 효과적인 장치였다.
**2. 형태 결정 전에 "이 형태로 뭐가 되고 뭐가 안 되는지"를 먼저 물어봐야 한다**  
A/B/C 중 고르라고 하면 막막하다. "트렌드 자동 수집이 A에서 되나요?"처럼 구체적 기능 질문이 나왔을 때 한계를 솔직하게 설명하자 결정이 빨라졌다.
**3. 첫 부품은 가장 가벼운 것부터**  
트렌드 자동 수집(B/C)이 더 강력하지만, 일단 A 스킬로 시작해서 워크플로우를 몸에 익히는 게 맞다. 완벽한 시스템보다 오늘 당장 쓸 수 있는 부품이 OS의 진짜 시작점이다.
**4. 모든걸 클로드에게 묻게 된다. 이 미션에 대한 답도 묻게 되는데, 이게 맞는건지?? 의문이 든다.

### 기능 요약

- **CRUD**: 제목 / 완료여부 / 날짜 / 카테고리
- **자동 그룹화**: 지난 일정 / 오늘 / 내일 / 이번 주 / 나중에 / 날짜 미정 / 완료
- **인라인 편집**: 제목·카테고리·날짜를 클릭해서 그 자리에서 수정 (Enter 저장 / Esc 취소)
- **폼 기반 일괄 편집**: ✎ 클릭 시 상단 폼으로 끌어올려 한꺼번에 편집
- **카테고리 자동완성**: 기존 카테고리를 datalist로 제안
- **반응형**: 데스크톱/모바일 레이아웃 분기
- **안전장치**: XSS 방지(textContent), 깨진 JSON 자동 백업, localStorage 차단 시 메모리 폴백
