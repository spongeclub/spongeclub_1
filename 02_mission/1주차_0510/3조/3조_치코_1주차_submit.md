# 1주차 과제 — 치코

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary
인터뷰 스킬을 통해 어떤 os를 만들어보면 좋을지에 대해서 같이 고민하고
뾰족한 문제 정의와 대략의 제품 구성을 그려봄.

### 최종 구현 결과물

**커리어 OS** — 경험을 인터뷰로 채굴하고, 포지션별로 포트폴리오를 자동 생성하는 시스템
	**`os-blueprint.md`** — OS 청사진 전체  
	**`portfolio-maker.prd.md`** — 포폴 메이커 PRD


### 과정 (타임라인별 + 삽질)

1. 인터뷰 진행
	- "정보가 없어서"가 아니라 **"정보와 생각이 너무 많아서 어디에도 착지하지 못하는" 상태**라는 것을 발견
	- 경험을 묶는 게 어렵다는 것이 정확히 어떤 것을 의미하는지 선택
		- **(a) 시작 전** — 뭘 쓸지 어떻게 골라야 할지, 기준 자체가 없는 느낌  
		- **(b) 진행 중** — 뭔가 쓰고 있는데 "이게 맞나?" 싶어서 계속 멈추게 되는 것  
		- **(c) 다 쓴 뒤** — 써놓고 보면 "이게 나를 제대로 표현하는 건지" 확신이 안 서는 것
	- **"나는 포지션명, 역할, 회사만 말하고 — 골라주고, 묶어주고, 써주고, 검증해주는 건 시스템이 한다."**
2. 부품 매핑
	1. **경험 원재료 채굴** — 여러 각도에서 질문을 던져 편향 없이 경험을 꺼내주는 것
	2. **포지션 분석기** — 지원할 JD(채용공고)를 보고 이 회사가 뭘 원하는지 파악하는 것
	3. **경험 매칭기** — 저장된 경험 중 이 포지션에 맞는 것들을 골라주는 것
	4. **구조화 도우미** — 골른 경험을 논리적으로 묶고 순서를 잡아주는 것
	5. **문장 생성기** — 구조를 설득력 있는 포트폴리오 문장으로 써주는 것
	6. **검증 도우미** — 완성된 내용이 "이게 나인가"를 확인해주는 것

3. PRD 작성
	- 근데 한 번에 다 만들 순 없으니까, **첫 부품**을 정하라고 함.
	- 구현 방식도 **독립 프로덕트 PRD**|웹/앱으로 만들기 


### 공유할만한 인사이트

- 무언가 만들었을 때, 레퍼런스 리서치를 시켜서 비슷한 서비스를 찾음.
	- 나의 prd를 기준으로 리서치 시킴
	- 각 서비스의 장단점을 분석하게시키고 나의 제품의 방향성을 뚜렷하게 잡아봄.

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary
- 위 인터뷰에서 도출된 커리어 OS를 실제 서비스로 구현해 봄. -- 포폴메이커
	- JD, 회사를 입력하면 JD에 알맞은 프로젝트와 핵심역량이 뽑힘.
	- 이를 바탕으로 내 경험중에 비슷한 프로젝트들을 선정해서 인터뷰 진행.
	- 이때 인터뷰에서 내가 미처 캐치하지 못했던 핵심포인트들을 발굴해주기 시작
	- 인터뷰를 마치고 나서는 해당 프로젝트에 대한 경력기술서가 불릿형태로 완성됨.
	- 그리고 내용을 정리해서 다음에도 쓸수 있게 job db에 쌓이는 형태로 구현
