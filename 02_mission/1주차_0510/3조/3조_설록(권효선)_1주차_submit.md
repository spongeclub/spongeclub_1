# 1주차 과제 — 설록

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary
Claude Code의 `os-interview` 스킬로 협동조합 운영 OS 청사진을 만들고, 첫 부품으로 "카톡 회의 → 노션 회의록 DB 자동 정리" 스킬을 제작.
OS 선언문: "나는 막힌 곳을 푸는 결정만 하고, 나머지(조합의 상태 파악·기록·공유)는 시스템이 한다."

### 최종 구현 결과물
OS 청사진 — 풍경/통점/이상향/부품 후보 7개/첫 부품 선정 근거. 부품 묶음: 가시화(1~5) / 정산(6) / 홍보(7).
`kakao-to-notion-meeting` 스킬 — 카톡 대화 → 의사결정·액션아이템·일정·미결정사항으로 구조화 → 노션 WEEKLY MEETING DB에 페이지 생성. `~/.claude/skills/`에 설치 완료.

### 과정 (타임라인별 + 삽질)
처음엔 욕심이 많았다. 홈페이지 제작, 회의 정리, 정산, SNS 콘텐츠 업로드 — 다 하고 싶다고 답했다.
1차 시도에서는 첫 부품으로 홈페이지 제작과 LMS 구축이 나왔다. 그런데 막상 진행하려니까 첫 술에 배부를려고 덤빈 격이라는 생각이 들었다. 그리고 홈페이지 제작은 자동화랑은 좀 결이 다른 활동 같았다.
그래서 2차 시도에서는 방향을 SNS 홍보로 틀어서 SNS 캐러셀 만드는 걸로 바꿨다. 이건 진행이 가능하긴 했는데, 풀고 있는 게 조합의 진짜 문제인지는 잘 모르겠었다.
3차 시도에서야 답이 나왔다. 조합의 가장 큰 문제는 회의 기록이 휘발되는 거였다. 카톡으로 회의가 흘러가고 나면 PM 한 명만 그 내용을 알고, 나머지는 깜깜이가 된다. 이걸 자동화하면 효과가 가장 클 것 같았다. 그래서 첫 부품을 카톡 회의 정리로 확정했다.
부품을 정한 뒤에는 일이 빨리 풀렸다. 노션 DB는 다행히 예전에 만들어둔 게 있어서 그대로 쓸 수 있었고, 스킬도 무리 없이 만들어졌다.

### 공유할만한 인사이트
인터뷰는 한 번에 안 나와도 된다. 세 번 다시 하고서야 진짜 통점이 보였다. 1차에서 골랐던 홈페이지 제작은 사실 자동화 문제가 아니었고, 2차의 SNS도 진짜 아픈 부분이 아니었다. 잘못된 부품을 한두 개 골라봐야 진짜 부품이 보이는 것 같다.
AI가 시키는 대로 가면 위험할 때가 있다. Claude Code가 제출 방식을 자기 마음대로 추측해서 포크/PR 흐름을 짜놨다. 진짜 그 방식이 맞는지 한 번씩 확인해야 한다.
가드가 있어서 다행이었다. PR 만들기 직전에 시스템이 안 멈춰줬으면 민감 정보가 그대로 공개됐을 거다. 자동화는 빠른 게 좋지만, 멈춰주는 지점이 있어야 안전하다.
OS 선언문 한 줄이 생각보다 큰 역할을 했다. 부품 고를 때, 스킬 범위 정할 때, 헷갈릴 때마다 이 문장으로 돌아왔다. 세 번 다시 인터뷰한 것도 결국 이 선언문에 가장 맞는 부품이 뭔지 찾는 과정이었다.

## 미션 2: 따라해보고 싶은 개인/업무/삶 OS 따라서 만들어보기 - SNS(유튜브 등) 에서 찾아 벤치마킹 해오기

### Summary
일잘러 장피엠님 영상 [나의 AI 에이전트 전환기](https://youtu.be/c-a4GBOxhXQ)에서 잠깐 소개된 *카톡 나에게 보내기 자동 아카이빙* 시스템을 보고 가볍게 따라해봤다. 카카오톡 *나와의 채팅* 에 3년 8개월 쌓인 메모 966건을 구글시트에 분류·정리하고, *오늘 다시 볼 메모* 필터로 학습 시스템 작동까지 확인.

### 최종 구현 결과물
카톡 메모 아카이브 구글시트 — 카톡 텍스트 내보내기 → Claude Code로 4개 카테고리(읽기/생각/배움/할 일/쇼핑)로 자동 분류 → 시트 정리 + 카테고리별 다시볼 날짜 자동 계산 + 오늘 ±7일 필터.

### 과정 (타임라인별 + 삽질)
영상 속 시스템은 Mac Mini + OpenClaw + Telegram + cron으로 자동 실행되는 무거운 구조라 그대로는 과했다. 컨셉만 가져오고 '수동 내보내기 + Claude Code 분류 + 시트 붙여넣기'로 가볍게 갔다.
데이터 양이 어마어마했다. 텍스트 메모만 966건, 첨부 사진 705건, 자동 알림 53건. 첨부와 알림은 빼고 텍스트만 50개씩 샘플 분류 → 검토 → 전체 분류 흐름으로 갔다.
삽질 가장 막힌 건 구글시트 필터. *오늘 ±7일* 필터를 거는데 결과 0개로 나와 한참 헤맸다. 알고 보니 F열(다시볼 날짜)이 '날짜'가 아니라 '텍스트'로 인식되고 있었다. 서식 바꾸니 바로 작동했다.

### 공유할만한 인사이트
영상에서 작은 부분만 떼어와도 충분하다. 28분 영상 중에 내가 따라한 건 13분 부근의 한 장면뿐. 전체 다 따라하려고 했으면 시작도 못 했을 거다. 
영상에서는 Mac Mini + OpenClaw + Telegram + cron으로 자동 수집했지만, 나는 수동 내보내기로 충분했다. 자동 수집 안 해도 시스템의 핵심 가치인 메모의 자산화를 했다는 것에 의미를 두려 한다.

1주차 미션에 앞서 내가 해야 할 첫 번째 과제는 ‘스폰지클럽’ 분위기를 파악하는 것이었다. 한동안 잊고 지냈던 인스타를 다시 켰고, 누군가 나를 팔로우하고 내 게시물이 리포스트되는 낯설고도 신기한 경험을 했다.

늘 익숙한 사람들과 익숙한 일상 속에만 머물다가, 이렇게 전혀 새로운 곳에 나를 툭 던져본 게 얼마 만인지 모르겠다. 굳어있던 머리가 기분 좋게 말랑말랑해지는 느낌이다.

최근 에이전트 AI를 제대로 체득하고 싶어서 따로 듣고 있는 강의가 하나 있다. 운세 보기 웹앱을 만들고 카카오톡 로그인 기능까지 구현해 보는 꽤 만족스러운 수업이었고, 디자인을 적용하는 워크플로우도 남달랐다. 하지만 어디까지나 '정해진 길을 따라가는' 방식이었다.

반면, 스폰지클럽에서의 1주차 미션은 결이 완전히 달랐다. 처음엔 무엇을 만들어야 할지 몰라 백지상태에서 시작했다. 특히 중간에 벤치마킹할 주제를 찾지 못해 길을 잃고 끙끙대며 꽤나 애를 먹기도 했다. 그렇게 일주일 내내 '대체 뭘 해야 하나' 머리를 싸매고 고민하다가, 미션 마지막 날에 이르러서야 비로소 '이거다!' 싶은 나의 진짜 필요, 즉 '나만의 Why'를 찾을 수 있었다.

인터뷰 스킬만 세 번이나 반복하게 만드는 스폰지클럽의 과정은 정말 어디서도 쉽게 해볼 수 없는 경험이다. 이곳에서 내가 진정으로 깊게 배우고 있는 건 단순한 '기술'이 아니라, '기술을 대하는 태도' 그 자체인 것 같다.

이제 겨우 1주 차가 지났을 뿐인데, 벌써부터 이 시간이 지나가는 게 아쉬워지려 한다.
