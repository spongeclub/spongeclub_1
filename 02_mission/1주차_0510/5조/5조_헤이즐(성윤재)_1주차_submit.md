## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary
- 구축하려는 서비스에 API 연동이 필요한 경우, 배경과 목적에 따른 기대 아웃풋을 정의하기에 앞서 어떤 데이터를 연동·활용할 수 있는지 우선 파악할 필요가 있다.

### 최종 구현 결과물
https://shinsa-lunch-finder.vercel.app/
![[스크린샷 2026-05-10 오후 1.37.06.png]]
### 과정 (타임라인별 + 삽질)
- 서비스1 - 마케팅 프로모션 페이지 모음집
	- 마케터를 위해 매일 자동 리서치하여 업데이트 되는 페이지를 만들고자 했다
	- 주요 페이지들의 크롤링 접근이 모두 차단되어 헤맸다 (크롤링 작업시 이 지점을 먼저 체크하면 덜 삽질할 것 같다)
- 서비스2 - 회사근처 맛집/카페 지도
	- 회사 건물을 기점으로 맛집/카페 지도를 규격해서 디자인 했다. 
	- 클로드 code에 명령어가 먹히지 않아 헤맸다. 원인은 terminal을 사용하지 않은 것이었다.
	- terminal을 쓰다보니 체크할게 꽤 많았다. 클로드에 이관해서 사용하는 방법을 찾았고 이전대비 수월하게 바이브 코딩이 가능했다. 
	- 이후 지도의 정보 고도화를 위해 리뷰, 가격, 도보권거리 값, 후기, 식대가격 등의 정보를  끌어오는 작업들을 수행했다. 하지만  API 스펙이 맞지 않아 매우 많이 헤맸다. 원하는 정보 소스가 안되면 치환해서라도 끌어오는 방법을 찾아보려 했지만...안됐다. 시간도 너무 많이 썼다.
	- 결국 결과물에 대한 타협을 할 수 밖에 없었다. 

### 공유할만한 인사이트
- visual studio code 에서 터미널에 명령어를 입력하면, 클로드에서 작업이 가능해서 편하다.
	- echo '## Allowed Tools
	- WebSearch: *
	- WebFetch: *
	- Bash: npm run *' >> CLAUDE.md
- 기획할때 크롤링, API 연동을 통해 어떤 정보를 충분히 끌고 올 수 있을지 확인후 초반 기획을 마친다면 완료까지 시간 단축이 가능하다.

### 최종 구현 결과물
![[스크린샷 2026-05-10 오후 1.34.32.png]]
### 과정 (타임라인별 + 삽질)
- 과제를 위해 유튜브, 스레드, 인스타그램을 정말 오랜시간 뒤졌다. 라이트하게 시도할 수 있는 뉴스 스크래핑을 서비스를 시도했다.
	- 1) 여러 내공이 필요해보이는 것들이 작업들이 있는것도 문제지만
	- 2) '나에게 실질적으로 필요한' 서비스를 급 정의하려니 다양한 고민들이 앞섰다.
- 진짜 이 스타트업 업계에 있는 사람들을 위한 기사 스크래핑을 하고 싶지만 프롬프트 퀄리티가 부족했던 것 같다. 기대한것보다 정보 퀄리티가 떨어진다. 

### 공유할만한 인사이트
- "평소 내가 하는 업무보다 한 발짝 뒤에 떨어져서 관찰하는 습관"이 자동화의 첫 발자국이 아닐까 싶다.
