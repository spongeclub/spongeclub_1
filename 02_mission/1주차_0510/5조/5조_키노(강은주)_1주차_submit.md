# 1주차 과제 — Keno

## 미션 1: claude code 로 인터뷰스킬 사용해서 인터뷰 까지 진행

### Summary
여러 퍼소나를 가지고 있는 1인 프리랜서로, 퍼소나 별로 필요한 콘텐츠 제작에 필요한 인터뷰를 진행했습니다. 퍼소나를 선택하고 -> 주제를 선택하면 -> 퍼소나에 맞춰 롱폼 글쓰기와 숏폼 편집을 도와주도록 작업했어요

### 최종 구현 결과물
AI 알려주는 인스타그램 퍼소나로 스폰지타임즈의 키노 콘텐츠를 제작해봤습니다
### 과정 (타임라인별 + 삽질)

1. 인터뷰스킬을 통해서 내가 원하는게 무엇인지 디테일하게 만들어봄
2. 내가 원하는건, 자동화에 가까운 작업이라는걸 인터뷰스킬이 알려줌
3. 내가 했던 일들, 작업물들을 올리면 알아서 롱폼과 숏폼으로 정리하게끔 만들어주기
4. (삽질)리모트 스킬을 통해 카드뉴스를 작업해보려고 했는데 작업이 제대로 되지 않았음
5. 캐릭터를 만드는데 나노바나나가 마음에 들지 않게 작업함
6. 캐릭터 기본 디자인 -> 얼굴형 바꿨는데 마음에 안들어서 원래 결과물을 기반으로 표정 바꾸기 / 배경제거하기 시도
7. 여러가지보다 한번에 하나씩, 디테일하게 잡아가니 오히려 결과물이 잘나옴
8. 클로드 코드 프로젝트가 다운로드 폴더에 있다보니 자기마음대로 상위 폴더를 참고함 -> 권한을 뺴기로 결정함
