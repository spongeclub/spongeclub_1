## 미션1: 내 고객은 누구고 왜 쓰는가 — 클로드 코드로 프로덕트 구현하기

### 프로덕트명: 리뷰 코칭 도구 (가칭)

### 문제 정의
에이블리·지그재그 여성의류 브랜드 대표들은 숫자(매출, 랭킹)는 보지만 숫자 뒤에 있는 고객을 보지 않는다. VIP 고객이 누군지 모르고, 리뷰를 읽지 않는다. "고객을 봐야 한다"는 걸 머리로는 알지만, 매출이 꺾이거나 정체되어 절박해지기 전까지는 움직이지 않는다.

### 타겟 유저
매출이 꺾이거나 정체돼서 코칭을 받으러 온 여성의류 브랜드 대표

### 프로덕트 포지션
코칭 안에서 쓰는 도구. 대표 혼자 쓰는 독립형이 아니라, 코치(무브)의 리딩과 함께 동작하는 구조.

### 핵심 기능
- 입력: 리뷰 스크린샷 업로드 (API 연동 불가, 캡처가 현실적 입력 방식)
- 레이어1 — 수집·분류: OCR로 텍스트 추출, 신호 있는 리뷰(장문/포토/상세) 자동 분류
- 레이어2 — 리딩·기록: 주기적 리마인드 + 리뷰에서 발견한 것 기록·축적
- AI 해석 보조: 세일즈 언어 추출 + 포토리뷰 스타일링 패턴 체크
- 축적: 기록이 쌓이면서 "우리 고객은 이런 사람"이라는 그림이 만들어지는 구조

### 기술 스택
웹앱 / Claude Code로 구현 예정

### 현재 상태
프로덕트 방향·구조 도출 완료. MVP 범위 결정 및 구현 진행 예정.

## 미션2: 하네스 + 오케스트레이션 — Notion/Tiro MCP 연동 실험

### Summary

Carousel OS 웹앱에 직접 코드를 추가하지 않고, Cowork 대화에서 Notion 이야기 자본 DB와 Tiro 코칭 녹음을 MCP로 직접 조회하여 캐러셀 콘텐츠 소스로 활용하는 워크플로우 구축. 두 MCP를 오케스트레이션해서 "콘텐츠 소재 발굴 → 캐러셀 생성"을 하나의 대화에서 끝냄.

### 최종 구현 결과물

- Notion 이야기 자본 DB (15개 필드, 서사유형/서술구조/인사이트유형/훅패턴 등) 조회 가능
- Tiro 코칭 세션 (메리엣, 셀리나, 블러핏, 뮤즈인미 등 10+ 고객사) 검색 + 속기록 조회 가능
- "블러핏 자존감 지킴이" 에피소드 → 10장 캐러셀 카피 + 캡션 + ManyChat DM + 공유멘트 생성 완료

### 과정 (타임라인별 + 삽질)

1. Tiro MCP로 "성장 매출 코칭" 키워드 검색 → 10개 코칭 세션 발견
2. Notion MCP로 이야기 자본 DB 스키마 분석 (collection://0f986602...)
3. 성공 에피소드 후보 4개 추출 (블러핏/제이블린/매출80%/피크온)
4. 블러핏 "자존감 지킴이" 선택 → 성희님 8원칙 적용하여 10장 캐러셀 작성
5. 원칙 체크 8개 항목 모두 통과

### 공유할만한 인사이트

웹앱 코드를 건드리지 않고도 MCP 연동만으로 데이터 소스를 확장할 수 있다는 게 오케스트레이션의 핵심. "코드를 짜는 것"과 "콘텐츠를 만드는 것"을 같은 대화에서 넘나들 수 있음. 하네스 없이도 Cowork 대화 자체가 오케스트레이터 역할을 한다는 걸 실험으로 확인.
