# #상담심리센터 OS 프로젝트 — 


1~2인 소규모 상담심리센터 운영자가 "사람 만나는 것" 외 행정에 시간을 뺏기는 문제를, 부품을 하나씩 만들어 검증하며 푸는 OS 프로젝트.

## 빌더 / 사용자

- 빌더: 린디 (만들어서 센터에 제공)
- 1호 검증 대상: 푸른심리상담센터 (경기 안산, 031-406-8277). 성인·아동청소년·가족·부부·기업 상담 + 종합심리검사 + 수퍼비전·교육을 사실상 1~2인이 다 함. 예약제, 평일 10–20시·주말도.

## OS 선언문

**원장은 사람을 만나고 회기 후 두 줄만 남긴다. 나머지는 시스템이 한다.** 
→ 설계 원칙: 입력은 극단적으로 가볍게, 출력은 시스템이 알아서 무겁게.

## 통점 (확정)

센터 일의 흐름 = 유입 → 예약·접수 → 회기 → 기록·데이터. 1~2인은 전 구간을 같은 사람이 함. 가장 피 흘리는 곳 = **앞단**: 온라인·전화로 자유 서술로 뭉쳐 들어온 문의를 원장이 일일이 읽어 분야·대상·검사 여부를 머릿속으로 분류하고 2~3일 안에 콜백하는 루프. 공통 제약(CONCERN): 아동청소년 비중 → 미성년 정보·보호자 동의·비밀유지가 모든 부품의 전제. 위기 신호는 시스템이 판단 않고 플래그만.

## 부품 지도 (6개, 3묶음)

- 입력단: ① 인테이크 분류기
- 중추: ② 아침 브리핑 + ③ 회기 후 2줄 펼침 (한 몸) + ④ 데이터 척추
- 출력단: ⑤ 행정 마감 + ⑥ 부산물 마케팅 추출 (가장 나중) 순서: 부품 하나씩 만들어 각각 검증 → 살아남으면 마지막에 연결.

## 부품 1 — 인테이크 분류기 (완료, 검증 중)

- 기능: 입구(온라인 자유서술/전화 메모) 무관 → 통일된 한 줄 + "오늘 접수분 표"로 변환.
- 추출 9항목: 입구 · 이름 · 연락처 · 대상(성인/아청/가족/부부/기업) · 분야 · 검사필요 · 희망시간 · 위기신호(⚠ 표시만) · 미성년(보호자동의).
- 규칙: 모르는 건 "미상"(추정 금지) / 분야 안 드러나면 "기타" / 위기는 플래그만 / 콜백 한 줄은 내부 메모 / 개인정보 경고 자동 부착 / 명령 없이 글 붙이면 자동 표.
- 형태: A. Claude 스킬 → 비개발자용으로 **Claude 프로젝트 지침**으로 변환 완료.
