## 미션1: 내 고객은 누구고 왜 쓰는가 — 클로드 코드로 프로덕트 구현하기

### Summary
- "반복되는 업무를 만들어도 마감을 놓치면 의미가 없다"는 문제에서 출발했습니다.
- 업무를 **만들고 → 반복 생성하고 → 놓치지 않도록 알려주는** 3단계 업무관리 시스템을 Excel + Google Sheets + AppSheet로 구현했습니다.
- 고객은 별도 앱 없이 스마트폰에서 바로 업무를 관리하고 싶은 1인/소규모 팀입니다.

### 최종 구현 결과물

#### 🔁 도구 1. 반복업무 자동 생성기 (`recurring_task_generator_template.xlsx`)
반복 패턴을 한 번 등록하면 업무가 자동으로 생성되는 도구.

| 반복 예시 | 설명 |
|-----------|------|
| 매주 월요일 | 팀 회의 업무 자동 생성 |
| 매달 말일 | 세금계산서 발행 업무 자동 생성 |
| 매일 오후 | 마감 체크 업무 자동 생성 |

| 시트 | 역할 |
|------|------|
| 대시보드 | 오늘 자동 생성된 업무 현황 요약 |
| 반복업무마스터 | 반복 규칙 등록 (주기·요일·담당자 등) |
| 생성된업무 | 자동 생성된 업무 목록 |
| 목록 | 드롭다운 항목 중앙 관리 |
| 사용법 | 사용 가이드 |

---

#### ✅ 도구 2. 모바일 업무 체크리스트 (`mobile_work_checklist_template.xlsx`)
일정·할 일·진행 업무를 한 곳에서 관리하는 모바일 최적화 도구.

| 시트 | 역할 |
|------|------|
| 대시보드 | 일정 / 할 일 / 진행 업무 자동 요약 |
| 오늘일정 | 당일 일정 입력 및 확인 |
| 할일체크 | 할 일 목록 체크리스트 |
| 진행업무 | 진행 중인 업무 현황 관리 |
| 목록 | 드롭다운 항목 중앙 관리 |

---

#### 🔔 도구 3. 마감 알림 대시보드 (`deadline_alert_center_template.xlsx`)
놓친 업무·임박 마감을 자동으로 감지하고 알림 메시지까지 생성하는 도구.

**주요 기능**

1. **마감 임박 업무 자동 표시**

| 구분 | 기준 |
|------|------|
| 오늘 마감 | D-Day |
| 내일 마감 | D-1 |
| 3일 이내 마감 | D-3 이내 |
| 지연 업무 | 마감일 초과 |

2. **우선순위 자동 분류** — 긴급 / 중요 / 보통 / 보류
3. **알림용 메시지 자동 생성** — "오늘 마감 업무 3건입니다." 등
4. **AppSheet 모바일 메뉴** — 오늘 마감 / 이번 주 마감 / 지연 업무 / 알림 메시지 / 완료 처리

| 시트 | 역할 |
|------|------|
| 대시보드 | 마감 현황 자동 집계 |
| 마감알림센터 | 업무별 마감일·상태 관리 |
| 알림문구 | 자동 생성된 알림 메시지 |
| 업무가져오기 | 도구1·2에서 업무 연동 |
| 목록 | 드롭다운 항목 관리 |
| 사용법 | 사용 가이드 |

---

### 시스템 전체 구조

```
도구1. 반복업무 자동 생성기
    ↓ 업무 자동 생성
도구2. 업무 체크리스트
    ↓ 업무 현황 전달
도구3. 마감 알림 대시보드
    → 마감 감지 + 우선순위 분류 + 알림 메시지 발송
```

### 과정 (타임라인별 + 삽질)
1. 반복업무를 매번 수동 등록하는 게 비효율적이라 느껴 자동 생성기부터 설계했습니다.
2. 생성된 업무를 한눈에 보고 체크할 수 있는 체크리스트 템플릿을 이어서 제작했습니다.
3. 업무를 만들어도 마감을 놓치면 의미가 줄어든다는 걸 깨닫고 마감 알림 대시보드를 세 번째로 설계했습니다.
4. 드롭다운 항목 관리를 각 시트에 흩어두지 않고 목록 시트로 분리해 중앙 관리 구조로 통일했습니다.
5. Google Sheets 업로드 → AppSheet 연결 테스트 — 세 도구 모두 모바일에서 앱처럼 동작하는 것 확인했습니다.

### 공유할만한 인사이트
- 업무 도구는 **만들기 → 관리하기 → 알림받기** 3단계가 갖춰질 때 비로소 완결됩니다.
- 반복업무는 마스터 데이터와 자동 생성 로직을 분리하는 것이 핵심입니다.
- 드롭다운을 목록 시트로 분리하는 것만으로 여러 시트의 항목을 한 번에 수정할 수 있어 편리합니다.
- 다음에는 AppSheet 알림(Notification) 기능까지 연결해서 마감 임박 시 자동 푸시를 받을 수 있도록 개선하고 싶습니다.

## 미션2: 내가 정의하고 적용해보고 싶은 하네스 + 오케스트레이션

### Summary
- 이번 주 만든 3종 업무관리 시스템을 돌아보며, 내가 이미 하네스와 오케스트레이션을 쓰고 있었다는 걸 뒤늦게 깨달았습니다.
- **하네스**는 도구들이 동작하는 환경과 틀, **오케스트레이션**은 그 도구들이 순서대로 연결되어 하나의 흐름을 만드는 것이라고 정의했습니다.

### 최종 구현 결과물
- 미션1에서 구축한 3종 시스템의 구조 자체가 결과물입니다.
- 하네스: Google Sheets + AppSheet 레이어
- 오케스트레이션: 도구1 → 도구2 → 도구3으로 이어지는 데이터 파이프라인

### 과정 (타임라인별 + 삽질)

#### 내가 정의한 하네스 (Harness)

> "AI 에이전트나 도구들이 실제로 동작할 수 있도록 감싸주는 운영 환경"

이번 주 내가 만든 하네스는 **Google Sheets + AppSheet** 조합이었습니다.

- Google Sheets = 데이터가 저장되고 수식이 계산되는 공간
- AppSheet = 그 데이터를 모바일에서 입력·조회·알림까지 받을 수 있게 감싸주는 인터페이스

엑셀 파일 하나로는 모바일에서 쓸 수 없었고, AppSheet 없이는 알림도 불가능했습니다. 하네스가 없으면 도구는 그냥 파일일 뿐이라는 걸 체감했습니다.

#### 내가 정의한 오케스트레이션 (Orchestration)

> "독립적인 도구들이 정해진 순서와 역할로 연결되어 하나의 목적을 이루는 흐름"

세 도구는 각각 독립적으로 동작하지만, 데이터는 한 방향으로 흐릅니다.

```
반복업무 자동 생성기  →  업무 체크리스트  →  마감 알림 대시보드
  (업무 생성)              (업무 관리)           (마감 감지 + 알림)
```

오케스트레이션이 없으면 도구 3개가 따로 놀고, 사용자가 직접 데이터를 옮겨야 합니다. 연결이 생기자 "시스템"이 됐습니다.

#### 다음에 적용해보고 싶은 것

지금은 수동으로 연결되는 부분이 있습니다. 앞으로 적용해보고 싶은 방향:

| 현재 | 개선 방향 |
|------|-----------|
| 도구1에서 생성된 업무를 도구2에 수동 복사 | AppSheet 자동화 또는 Google Apps Script로 자동 연동 |
| 마감 알림을 대시보드에서 직접 확인 | AppSheet Notification으로 자동 푸시 발송 |
| 각 도구를 별도 파일로 관리 | 하나의 Google Sheets 내 시트로 통합 |

### 공유할만한 인사이트
- 하네스와 오케스트레이션은 거창한 개념이 아니었습니다. 도구를 감싸는 환경과, 도구들을 연결하는 흐름 — 이 두 가지를 의식하는 것만으로 만드는 방식이 달라집니다.
- 도구를 먼저 만들고 나서 개념을 붙였는데, 오히려 그게 더 이해가 잘 됐습니다. 개념부터 공부하는 것보다 만들고 나서 "아, 이게 그거였구나" 하는 순서가 저한테는 맞는 것 같습니다.
- 다음 주는 이 개념을 먼저 설계에 반영해보고 싶습니다. 연결 구조를 먼저 그리고 도구를 만드는 순서로.
