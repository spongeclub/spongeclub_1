## 미션1: 내 고객은 누구고 왜 쓰는가 — 클로드 코드로 프로덕트 구현하기

### Summary
- 이번 주에는 **반복업무 자동 생성기**와 **모바일 업무 체크리스트 템플릿** 두 가지 도구를 제작했습니다.
- 고객은 매주·매달 반복되는 업무를 수동으로 등록하느라 시간을 낭비하는 사람들이며, 한 번 설정하면 자동으로 업무가 생성되는 구조를 Excel + Google Sheets + AppSheet로 구현했습니다.

### 최종 구현 결과물

#### 🔁 도구 1: 반복업무 자동 생성기 (`recurring_task_generator_template.xlsx`)

반복 패턴만 등록해두면 업무가 자동으로 생성되는 도구.

| 반복 예시 | 설명 |
|-----------|------|
| 매주 월요일 | 팀 회의 업무 자동 생성 |
| 매달 말일 | 세금계산서 발행 업무 자동 생성 |
| 매일 오후 | 마감 체크 업무 자동 생성 |

**시트 구성**

| 시트 | 역할 |
|------|------|
| **대시보드** | 오늘 자동 생성된 업무 현황 요약 |
| **반복업무마스터** | 반복 규칙 등록 (주기·요일·담당자 등) |
| **생성된업무** | 자동 생성된 업무 목록 |
| **목록** | 드롭다운 항목 중앙 관리 |
| **사용법** | 사용 가이드 |

---

#### ✅ 도구 2: 모바일 업무 체크리스트 템플릿 (`mobile_work_checklist_template.xlsx`)

일정·할 일·진행 업무를 한 곳에서 관리하는 모바일 최적화 도구.

**시트 구성**

| 시트 | 역할 |
|------|------|
| **대시보드** | 일정 / 할 일 / 진행 업무 자동 요약 |
| **오늘일정** | 당일 일정 입력 및 확인 |
| **할일체크** | 할 일 목록 체크리스트 |
| **진행업무** | 진행 중인 업무 현황 관리 |
| **목록** | 드롭다운 항목 중앙 관리 |

---

**공통 사용법**: Google Sheets 업로드 → AppSheet 연결 → 모바일 앱처럼 즉시 사용

### 과정 (타임라인별 + 삽질)
1. 반복업무를 매번 수동으로 만드는 게 비효율적이라 느껴서 **자동 생성기**부터 설계했습니다.
2. 반복 주기(매일/매주/매달)를 드롭다운으로 선택하고 마스터 시트에 등록하면 생성된업무 시트에 자동으로 채워지는 구조를 만들었습니다.
3. 이어서 **체크리스트 템플릿**을 제작 — 대시보드에서 나머지 시트 데이터를 자동 요약하도록 수식을 연결했습니다.
4. 드롭다운 항목 관리를 각 시트에 흩어두지 않고 **목록 시트**로 분리해 중앙 관리 구조로 정리했습니다.
5. Google Sheets 업로드 후 AppSheet 연결 테스트 — 모바일에서 앱처럼 동작하는 것 확인했습니다.

### 공유할만한 인사이트
- 반복업무는 **마스터 데이터 + 자동 생성 로직** 분리가 핵심입니다. 규칙만 바꾸면 전체 업무 패턴이 바뀌는 구조가 유지보수에 훨씬 유리합니다.
- Excel 하나로 끝내려 하면 모바일 접근성이 떨어지는데, **Google Sheets + AppSheet 조합**이 생각보다 훨씬 강력했습니다.
- 드롭다운 관리를 별도 시트로 분리하는 것만으로 나중에 항목 수정이 훨씬 편해집니다.
- 다음에는 AppSheet 알림(Notification) 기능까지 연결해서 반복업무 생성 시 자동 푸시를 받을 수 있도록 개선하고 싶습니다.
