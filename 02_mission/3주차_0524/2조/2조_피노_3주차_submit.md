## 미션1: 내 고객은 누구고 왜 쓰는가 — 클로드 코드로 프로덕트 구현하기

### Summary
- "반복되는 업무를 만들어도 마감을 놓치면 의미가 없다"는 문제에서 출발했습니다.
- 업무를 **만들고 → 반복 생성하고 → 놓치지 않도록 알려주는** 3단계 업무관리 시스템을 Excel + Google Sheets + AppSheet로 구현했습니다.
- 고객은 별도 앱 없이 스마트폰에서 바로 업무를 관리하고 싶은 1인/소규모 팀입니다.

### 최종 구현 결과물

#### 🔁 도구 1. 반복업무 자동 생성기 (`recurring_task_generator_template.xlsx`)
반복 패턴을 한 번 등록하면 업무가 자동으로 생성되는 도구.

| 반복 예시 | 설명 |
|-----------|------|
| 매주 월요일 | 팀 회의 업무 자동 생성 |
| 매달 말일 | 세금계산서 발행 업무 자동 생성 |
| 매일 오후 | 마감 체크 업무 자동 생성 |

| 시트 | 역할 |
|------|------|
| 대시보드 | 오늘 자동 생성된 업무 현황 요약 |
| 반복업무마스터 | 반복 규칙 등록 (주기·요일·담당자 등) |
| 생성된업무 | 자동 생성된 업무 목록 |
| 목록 | 드롭다운 항목 중앙 관리 |
| 사용법 | 사용 가이드 |

---

#### ✅ 도구 2. 모바일 업무 체크리스트 (`mobile_work_checklist_template.xlsx`)
일정·할 일·진행 업무를 한 곳에서 관리하는 모바일 최적화 도구.

| 시트 | 역할 |
|------|------|
| 대시보드 | 일정 / 할 일 / 진행 업무 자동 요약 |
| 오늘일정 | 당일 일정 입력 및 확인 |
| 할일체크 | 할 일 목록 체크리스트 |
| 진행업무 | 진행 중인 업무 현황 관리 |
| 목록 | 드롭다운 항목 중앙 관리 |

---

#### 🔔 도구 3. 마감 알림 대시보드 (`deadline_alert_center_template.xlsx`)
놓친 업무·임박 마감을 자동으로 감지하고 알림 메시지까지 생성하는 도구.

**주요 기능**

1. **마감 임박 업무 자동 표시**

| 구분 | 기준 |
|------|------|
| 오늘 마감 | D-Day |
| 내일 마감 | D-1 |
| 3일 이내 마감 | D-3 이내 |
| 지연 업무 | 마감일 초과 |

2. **우선순위 자동 분류**

| 레벨 | 설명 |
|------|------|
| 긴급 | 즉시 처리 필요 |
| 중요 | 오늘 내 처리 |
| 보통 | 이번 주 내 처리 |
| 보류 | 대기 중 |

3. **알림용 메시지 자동 생성**
   - "오늘 마감 업무 3건입니다."
   - "세금계산서 발행 업무가 내일 마감입니다."
   - "지연된 업무가 2건 있습니다."

4. **AppSheet 모바일 화면 메뉴 구성**
   - 오늘 마감 / 이번 주 마감 / 지연 업무 / 알림 메시지 / 완료 처리

| 시트 | 역할 |
|------|------|
| 대시보드 | 마감 현황 자동 집계 |
| 마감알림센터 | 업무별 마감일·상태 관리 |
| 알림문구 | 자동 생성된 알림 메시지 |
| 업무가져오기 | 도구1·2에서 업무 연동 |
| 목록 | 드롭다운 항목 관리 |
| 사용법 | 사용 가이드 |

---

### 시스템 전체 구조

```
도구1. 반복업무 자동 생성기
    ↓ 업무 자동 생성
도구2. 업무 체크리스트
    ↓ 업무 현황 전달
도구3. 마감 알림 대시보드
    → 마감 감지 + 우선순위 분류 + 알림 메시지 발송
```

세 도구를 연결하면 **"만들고 → 관리하고 → 놓치지 않는"** 완결된 업무관리 흐름이 완성됩니다.

### 과정 (타임라인별 + 삽질)
1. 반복업무를 매번 수동 등록하는 게 비효율적이라 느껴 **자동 생성기**부터 설계했습니다.
2. 생성된 업무를 한눈에 보고 체크할 수 있는 **체크리스트 템플릿**을 이어서 제작했습니다.
3. 업무를 만들어도 마감을 놓치면 의미가 줄어든다는 걸 깨닫고 **마감 알림 대시보드**를 세 번째로 설계했습니다.
4. 드롭다운 항목 관리를 각 시트에 흩어두지 않고 **목록 시트**로 분리해 중앙 관리 구조로 통일했습니다.
5. Google Sheets 업로드 → AppSheet 연결 테스트 — 세 도구 모두 모바일에서 앱처럼 동작하는 것 확인했습니다.

### 공유할만한 인사이트
- 업무 도구는 **만들기 → 관리하기 → 알림받기** 3단계가 갖춰질 때 비로소 완결됩니다. 하나만 있으면 나머지 두 개가 빠져 허전합니다.
- 반복업무는 **마스터 데이터 + 자동 생성 로직** 분리가 핵심입니다. 규칙만 바꾸면 전체 업무 패턴이 바뀌는 구조가 유지보수에 훨씬 유리합니다.
- 드롭다운을 별도 목록 시트로 분리하는 것만으로 여러 시트의 항목을 한 번에 수정할 수 있어 편리합니다.
- 다음에는 AppSheet 알림(Notification) 기능까지 연결해서 마감 임박 시 자동 푸시를 받을 수 있도록 개선하고 싶습니다.
