## 미션1: 내 고객은 누구고 왜 쓰는가 — 클로드 코드로 프로덕트 구현하기

### Summary
- 이번 주에는 **모바일 업무 체크리스트 완성형 템플릿**을 제작했습니다.
- 내 고객은 스마트폰으로 업무를 관리하고 싶지만 복잡한 툴 없이 바로 쓰고 싶은 사람들이며, Excel → Google Sheets → AppSheet 조합으로 모바일 앱처럼 쓸 수 있는 완성형 도구를 구현했습니다.

### 최종 구현 결과물
- `mobile_work_checklist_template.xlsx` — 5개 시트로 구성된 완성형 업무 체크리스트 템플릿
- **사용법**: Google Sheets 업로드 → AppSheet 연결 → 모바일에서 앱처럼 즉시 사용

### 시트 구성

| 시트 | 역할 |
|------|------|
| **대시보드** | 일정 / 할 일 / 진행 업무 자동 요약 |
| **오늘일정** | 당일 일정 입력 및 확인 |
| **할일체크** | 할 일 목록 체크리스트 |
| **진행업무** | 진행 중인 업무 현황 관리 |
| **목록** | 드롭다운 항목 중앙 관리 |

### 과정 (타임라인별 + 삽질)
1. 모바일에서 편하게 쓸 수 있는 구조가 무엇인지 시트 설계부터 시작했습니다.
2. 대시보드에서 나머지 시트 데이터를 자동 요약하도록 수식을 연결했습니다.
3. 드롭다운 항목이 각 시트에 흩어지면 관리가 어려워서 **목록 시트**로 분리해 중앙 관리 구조로 바꿨습니다.
4. Google Sheets 업로드 후 AppSheet 연결 테스트 — 모바일 앱처럼 동작하는 것 확인 후 완성했습니다.

### 공유할만한 인사이트
- Excel 하나로 끝내려 하면 모바일 접근성이 떨어지는데, **Google Sheets + AppSheet 조합**이 생각보다 훨씬 강력했습니다.
- 드롭다운 관리를 별도 시트로 분리하는 것만으로 나중에 항목 수정이 훨씬 편해집니다.
- 다음에는 AppSheet 알림(Notification) 기능까지 연결해서 마감 임박 항목을 자동 푸시로 받을 수 있도록 개선하고 싶습니다.
