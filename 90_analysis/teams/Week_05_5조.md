## 요약

5주차 5조는 "프로덕트 마무리"를 단발 도구가 아니라 재사용되는 시스템으로 끝냈다. 거북이의꿈은 코딩 한 줄 없이 대화만으로 콘텐츠 제작 OS를 구축했다 — LLM Wiki를 MCP 서버로 세팅해 자사·경쟁사·고객보이스 자료를 링크 그래프로 묶고, BFS 링크 순회(wiki-query)로 "빠짐없이 읽기"를 규칙화했으며, 클로드 웹 커넥터가 자체 버그로 막히자 OAuth 2.1 PIN 인증을 직접 구현해 우회했다. 이안은 영상 도구 SSCUT을 마무리하며 자체 렌더를 포기하고 CapCut 프로젝트 파일까지만 만드는 핸드오프로 한정했고, 렌더를 버리니 무거운 웹 GUI도 버려져 picker만 남기고 나머지를 CLI로 내려 AI가 직접 호출하는 도구 Weft v0.1.0(public, MIT)으로 배포·도그푸딩했다. 애니는 알뜰폰 도구를 친구 피드백 5개로 메인·결과 화면을 전면 재설계해(페이지 전환→아코디언 펼침) "최대 47만원" 키비주얼로 정직성과 임팩트를 동시에 잡았고, 비키는 Qoo10 도구에 리뷰 자동 분석·이벤트 기간 검색수·수집 캘린더·엑셀 자동 저장을 더하며 일본어 복합명사 인식·프로세스 분리 버그를 잡았다.

## ★ 클로드 인사이트
