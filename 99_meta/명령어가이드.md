# 슬래시 명령어 가이드

스폰지클럽 볼트에서 쓰는 모든 슬래시 명령어 정리.
명령어 정의 파일은 `.claude/commands/` 에 있고, 이 가이드는 사람이 보는 요약본이다.

## 누가 무엇을 쓰는가

| 명령어 | 누가 | 언제 |
|--------|------|------|
| `/set-missions` | 운영진 | 주차 시작 시 (1회) |
| `/draft` | 멤버 | 주말, 본인 작업 정리할 때 |
| `/mission` | 멤버 | `/draft`로 부족할 때 (수동 정리) |
| `/analyze` | 운영진 | 주말, 멤버 제출 모인 후 |
| `/ln` | 운영진 | 분석 후, 링크드인 초안 만들 때 |
| `/retag` | 운영진 | 인사이트가 쌓여서 키워드가 어지러울 때 |
| `/publish` | 운영진 | 사이트 배포 시 (※사이트 레포 결정 후 작동) |

---

## 한 주의 흐름

```
[토요일 주차 시작]
  운영진 → /set-missions 1 "AI 코딩 비교" "프롬프트 라이브러리"
            ↓ 모든 멤버 노트의 미션 헤더가 통일됨

[월~금 작업]
  멤버 → 본인이 만들고 싶은 거 만든다 (클로드코드, 노션, 코드 등)

[주말]
  멤버 → /draft 1
            ↓ 1주차 일정(토~금) 범위 클로드코드 세션을 자동 스캔
            ↓ AI 초안이 callout으로 채워짐 (사람 글과 시각적 구분)
  멤버 → callout 검토 후 본인 말투로 다시 씀

[주말 마감 후]
  운영진 → /analyze 1     (통합 분석 + 스킬 제안 + 멤버 프로필 갱신)
        → /ln 1           (멤버별 링크드인 초안)
        → /publish        (사이트 배포, 추후)
```

---

## `/set-missions` — 운영진, 주차 시작

```
/set-missions 1 "AI 코딩 어시스턴트 비교 체험"
/set-missions 1 "AI 코딩 비교" "프롬프트 라이브러리"
/set-missions 1 "X" "Y" "Z"
/set-missions 1                       → 인터랙티브 (몇 개? 제목은?)
```

해당 주차의 6개 조 × 멤버 노트 78개 모두에 대해 `## 미션1: <제목>` 줄을 동일한 제목으로 일괄 교체. 본문은 손대지 않는다.

**왜 일괄 적용**: 멤버마다 같은 미션을 다른 이름으로 쓰면 `/analyze`가 동일 미션을 묶어서 비교/분석할 수 없다. 제목이 분석 키 역할.

**미션 개수가 1~2개면**: 사용 안 하는 미션 헤더는 `## 미션N: (이번 주 미사용)`로 표시.

## `/draft` — 멤버, 주말 정리

```
/draft 0510-0516       → 5월 10~16일 작업 요약 (1주차 노트로 자동 매핑)
/draft 0510            → 5월 10일 하루
/draft 0510-0511       → 토·일 이틀치
/draft 0510-0516 1조-신연수   → 운영진이 멤버 대신 작성 시
```

**입력은 MMDD 또는 MMDD-MMDD**. 연도는 오늘 기준 자동 추론.

### 동작
1. `99_meta/멤버목록.md`에서 본인 조·닉네임 확인 (모르면 물어봄)
2. 입력 날짜 범위로 클로드코드 세션 검색 (`session_search`)
3. `99_meta/주차일정.md`와 비교해 어느 주차 노트에 채울지 자동 매핑
   - 한 주차 안에 들어가면 자동
   - 여러 주차에 걸치거나 주차 밖이면 멤버에게 확인
4. 그 주차 노트의 미션 제목을 보여주고 어느 미션에 매핑할지 확인
5. 본문을 **`> [!ai]` callout** 으로 감싸서 채움

### AI 초안 callout
```markdown
### Summary
> [!ai] 🤖 AI 초안 — 검토 후 본인 말투로 수정해주세요
> 클로드코드로 슬래시 명령어 `/draft`를 만들었다.
```

검토 후 callout 마커(`> [!ai]`와 줄 앞 `>`)를 지우면 일반 본문 = "검토 완료" 표시.

### 주의
- 미션 제목은 **절대 안 바꾼다** (운영진이 정한 그대로 유지)
- 입력 날짜 범위 **밖** 작업은 제외 — 다른 주차 작업이 섞이지 않음
- 사실 확인 안 된 내용은 추측해서 채우지 않음 (빈 칸이 낫다)
- 링크는 AI가 만들어내지 않음 (placeholder만, 멤버가 직접 입력)

## `/mission` — 멤버, 수동 정리

```
/mission 4 웹사이트 구축
/mission 4
```

`/draft`가 자동화라면 `/mission`은 **인터뷰 방식**. 클로드코드 세션 기반이 아니라 멤버가 답변하면서 채우는 흐름.

세션 기록이 없거나(클로드코드 외 도구로 작업), 자동 초안이 빗나갈 때 사용.

자세한 절차는 `.claude/commands/mission.md` 참고.

## `/analyze` — 운영진, 주차 마감

```
/analyze 1
```

1주차 모든 멤버 노트를 통합 분석하고:
- `90_analysis/weekly/Week_01_분석.md` — 에디토리얼 톤 주차 리포트
- `91_proposals/스킬_제안.md` — 반복 패턴에서 도출된 공용 스킬 후보 (누적)
- `91_proposals/AAA_봇_인사이트.md` — 프로젝트 아이디어, 멤버별 next step (누적)
- `90_analysis/members/{닉네임}_프로필.md` — 멤버별 참여 이력·키워드·주차 요약 갱신
- `92_status/진행현황.md` — 출석/제출 현황

**작성 원칙**:
- 닉네임 직접 언급 금지 ("한 멤버는", "여러 멤버가" 식으로)
- 제출현황 O/X 테이블 금지
- 핵심 발견 = 한 줄, 그 다음 트렌드 3개

## `/ln` — 운영진, 링크드인 초안

```
/ln 1
```

1주차 제출 멤버 각각에 대해 `_linkedin/Week_01_닉네임.md` 초안 생성.

링크드인 알고리즘 최적화: 글자 수 1,200~1,500자, 첫 2줄 후킹, 본문 링크 금지(첫 댓글), 해시태그 3~5개. 자세한 톤 가이드는 `.claude/commands/ln.md` 참고.

멤버는 본인 스타일로 수정 후 게시.

---

## `/retag` — 운영진, 키워드 정리

```
/retag
```

`02_skill&insight/` 또는 `03_insights/`의 모든 파일 키워드를 재집계해서 어지러워진 frontmatter `keywords`를 정리한다.

기준: 파일당 3~5개, 구체적인 도구명/기법명 우선, 범용 키워드(AI, 자동화) 회피.

본문은 절대 수정하지 않음. 사용자 확인 후 적용.

---

## `/publish` — 운영진, 사이트 배포

```
/publish
```

> ⚠️ 현재 사이트 레포 미정 상태. 결정 후 명령어 재작성 예정.

기존 정의는 `selfish-aaa-site-astro` 기준이지만 스폰지클럽은 사이트 레포가 정해지면 새로 작성한다.

자동화 흐름 (예정):
1. 공개 폴더(`02_mission/`, `03_insights/`, `90_analysis/`)를 사이트 레포로 sync
2. Astro 빌드 테스트
3. 커밋 → push → Vercel 자동 배포

## 주차일정·멤버목록 의존성

이 명령어들은 다음 두 파일을 매번 참조한다:

| 파일 | 누가 갱신 | 무엇이 깨지나 |
|------|---------|-------------|
| `99_meta/주차일정.md` | 운영진 | `/draft`, `/analyze`의 날짜 범위 필터 |
| `99_meta/멤버목록.md` | 운영진 | `/draft` 멤버 인식, `/analyze` 프로필 갱신, `/ln` 대상 멤버 |

명단 변경(가입/탈퇴/조 이동) 또는 일정 변경 시 위 파일만 갱신하면 명령어가 자동 반영.

## FAQ

**Q. `/draft`가 "주차 범위 안 세션이 없다"고 함**
→ 클로드코드 외 도구로 작업했거나 세션 검색이 실패한 경우. `/draft N now`로 현재 세션을 쓰거나 `/mission N`으로 수동 정리.

**Q. 미션 제목을 잘못 정해서 바꾸고 싶음**
→ `/set-missions N "새제목1" "새제목2"` 다시 실행. 헤더만 갱신되고 본문은 보존. 단, 이미 분석을 돌린 후 바꾸면 분석 결과와 어긋남 주의.

**Q. AI 초안 callout이 너무 많아서 정리하기 귀찮음**
→ 한 섹션씩 검토 후 `> [!ai]` 헤더와 각 줄 앞 `>`를 지우면 됨. Obsidian의 다중 라인 편집(Cmd+클릭)으로 한꺼번에 처리 가능.

**Q. 미션이 1개뿐인데 2/3은 어떻게**
→ `/set-missions N "유일한미션"`만 실행하면 미션2/3은 `(이번 주 미사용)`으로 표시됨. 멤버 노트의 미션2/3은 빈 채로 둬도 분석에서 무시됨.

**Q. 명령어 자체를 수정하고 싶음**
→ `.claude/commands/{명령어}.md` 직접 편집. CLAUDE.md 표와 이 가이드도 함께 갱신.
