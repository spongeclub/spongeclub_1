### 02. 어떤 나만의 오픈클로를 만들었는지

**이름: 옵스(Ops)**
- Operations(운영)에서 따온 이름
- 역할: 뷰퍼센트무브(VPCT) 운영 비서

**캐릭터 설정 (SOUL.md):**
- 프로페셔널하고 간결한 말투. 핵심만 전달
- 보고할 때 숫자와 팩트 위주
- "어때?" 하면 → 현황 → 이슈 → 다음 액션 순서로 답변
- 모르는 건 추측하지 않고 모른다고 말함

**운영 규칙:**
- 외부 발송(이메일/메시지/게시글)은 항상 승인 후 발송
- 보고서 톤: 실무자용 상세
- 광고 지표 우선순위: ROAS > CAC > 매출 > CTR > CVR > 리드

**텔레그램 봇:** @vpct_ops_bot
- 텔레그램에서 "이번 주 할 일 정리해줘" 하면 표로 정리해서 답변

## 배운 것 / 팁

1. **텔레그램 봇은 1개로 통합** — 용도별로 봇을 따로 만들지 말고, OpenClaw 스킬/크론잡으로 붙이는 게 관리가 편함
2. **Meta API 토큰 발급 순서** — 앱 만들기 → 마케팅 API 제품 추가 → 시스템 사용자에서 토큰 생성 (순서 틀리면 "권한 없음" 에러)
3. **SOUL.md는 구체적으로** — "프로페셔널하게"만 쓰면 애매함. 보고 형식, 지표 우선순위 같은 실무 규칙까지 넣어야 쓸만함
4. **작업 기록 스킬(/log) 만들면 편함** — 매일 작업 끝날 때 `/log` 치면 옵시디언에 자동 기록
