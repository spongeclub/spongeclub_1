### 1. 데일리 루틴 에이전트 (1, 2, 14번 통합)

**현재 반복:** 매일 아침 할 일 체크 → 일정·메일 확인 → 저녁에 랩업

**오픈클로 위임 시나리오:**

- **아침 8시**: 오늘 일정(구글 캘린더) + 미답변 메일 + 어제 미완료 할 일 → 슬랙으로 "오늘의 브리핑" 한 장
- **저녁 9시**: 오늘 캘린더 이벤트·메일·슬랙 활동 긁어서 → 노션에 "오늘 한 일 / 내일 할 일 / 미뤄진 것" 자동 초안 → 오웬은 5분만 손보면 됨
- **수시**: "내일 3시 미팅 잡아줘" 한 줄 → 캘린더 등록 + 참석자 메일 자동 초안

**난이도:** ⭐⭐ (캘린더 + Gmail MCP만 있으면 됨)

### 2. 위클리 운영 에이전트 (7, 8, 11번 통합)

**현재 반복:** 매주 컨설팅 성과 체크 + AAA팀 금토일 과제 챙기기 + 일요일 세션 준비 + 한 주 회고

**오픈클로 위임 시나리오:**

- **금요일 저녁**: AAA팀 8명 과제 제출 현황 자동 점검(노션/슬랙) → 미제출자 명단 + 리마인드 문구 초안
- **토요일 아침**: 일요 세션 어젠다 초안(이번 주 팀 활동 요약 + 논의 포인트 추출)
- **일요일 저녁**: 한 주 회고 자동 생성 → 캘린더에 있던 미팅 + 슬랙 활동 + 출시한 것들 → "이번 주 했던 것 / 안 한 것 / 다음 주 우선순위" 노션 페이지
- **월요일 아침**: 컨설팅 클라이언트별(플러스모어 등) 지난주 지표 변화 + 개선 제안 초안

**난이도:** ⭐⭐⭐ (노션 + 슬랙 + 클라이언트 데이터 소스 연결 필요)

### 3. 런치 키트 제너레이터 (5번)

**현재 반복:** 매월 제품 출시 직후 → 영상 + UTM + 카톡/메일/슬랙 홍보 문구

**오픈클로 위임 시나리오:**

- 새 제품 정보(이름, URL, 한 줄 소개, 핵심 기능) 한 번 입력
- 자동 생성: ① 채널별 UTM 링크 5종 (카톡, 슬랙, 디스콰이엇, 링크드인, 메일), ② 채널 톤별 홍보 문구 5종 (찜마켓 때 쓴 톤 학습), ③ Remotion 영상 스크립트 초안, ④ 노션 런치 페이지 자동 생성
- 그동안의 찜마켓·토닉카카오 런치 자료를 학습 데이터로 넣어두면 오웬 톤으로 나옴

**난이도:** ⭐⭐ (이게 ROI 가장 높음 — 매달 반복이고, 형식 고정되어 있음)

### 4. 마켓 인텔 에이전트 (9, 12번 통합)

**현재 반복 + 욕망:** 미국 증시 + 세계 경제 흐름, 기사 스크래핑, 경쟁자 분석

**오픈클로 위임 시나리오:**

- **매일 아침 7시**: 미국 증시 마감 + 한국 시장 영향 + 주요 매크로 이슈 → 핀테크 뉴스 브리핑 옆에 나란히
- **매주 월요일**: 경쟁자(더즌, 셀러 정산 서비스 등) 신규 보도자료·SNS·홈페이지 변경사항 → "이번 주 경쟁사 움직임" 리포트
- **트리거 기반**: 특정 키워드(국방주, 핀테크 M&A, AI 에이전트 툴) 신규 기사 → 슬랙 즉시 알림

**난이도:** ⭐⭐ (이미 돌고 있는 핀테크 브리핑 패턴 복제)

### 5. 그로스 모니터 (3번)

**현재 반복:** 찜마켓·토닉카카오 고객 유입 체크

**오픈클로 위임 시나리오:**

- **매일 저녁**: 찜마켓·토닉카카오 일일 신규 가입자 수, UTM별 유입 출처, 액티브 유저 → 슬랙 한 장 카드
- **주말**: UTM 캠페인별 ROI 비교 → 어디서 새는지 + 어디 더 태울지 자동 인사이트
- **이상 감지**: 갑자기 유입 늘거나 줄면 즉시 알림 (그 채널/콘텐츠 추적해서 원인 파악)

**난이도:** ⭐⭐⭐ (Vercel Analytics나 GA 연결 + 데이터 정제 필요)
