# OpenClaw 셋업데이 사전 과제 답변

## 1. 클로드 코드만 잘 쓰면 되는데, 오픈클로로 왜 필요해?

### 핵심 차이: "시키면 하는 장인" vs "알아서 돌아가는 비서"

Claude Code는 터미널에서 코딩 작업을 시키는 에이전트다. 시킬 때만 일하고, 터미널을 닫으면 끝난다.

OpenClaw는 결이 다르다:

**항상 켜져 있다 (Always-on)**
대부분의 AI 도구가 요청-응답 루프로 동작하는 반면, OpenClaw는 지속적으로 실행되면서 다단계 워크플로를 처리한다. 크론잡, 웹훅 트리거, 백그라운드 모니터링이 가능하다.

**메신저가 인터페이스**
WhatsApp, Telegram, Slack, Discord 등 20개 이상의 채널 지원. 터미널을 열 필요 없이 카톡하듯 지시하면 된다.

**스킬 시스템이 Claude Code와 구조가 같다**
SKILL.md 파일이 들어있는 디렉토리 형태. 내가 Claude Code에서 만든 500개+ 스킬 구조와 거의 동일하다.

**로컬 파일·셸·브라우저·API 직접 제어**
셸 명령 직접 실행, 파일 읽고 쓰기, API 호출, Playwright 브라우저 제어까지.

### 내 인프라에서 빠진 레이어

현재 인프라: Claude Code(코딩/빌드) + Claude 프로젝트(대화/전략) + Vercel 앱 5종 + Notion DB + Tiro 속기록

이것들을 연결하는 **"상시 가동 레이어"**가 없다. OpenClaw가 그 빈칸을 채운다.

## 2. 나에게 어떻게 쓸모를 만들 수 있을까?

### 반복되거나 귀찮은 작업
- 잠재 클라이언트에게 세일즈 DM 보내기 → 한 건당 10-15분 소요
- 콘텐츠 제작 (카피 쓰기 + 이미지 작업) → 클로드와의 핑퐁 횟수가 시간을 잡아먹음
- 클라이언트별 광고 데이터 보고서 작성 → 클라이언트 수만큼 반복

### 활용 시나리오 3개

**시나리오 A — 세일즈 DM 파이프라인**
OpenClaw가 백그라운드에서:
- 타겟 브랜드 인스타 계정 분석 (광고 스타일, 팔로워 규모, 최근 콘텐츠 톤)
- 브랜드별 약점 포인트 자동 추출 (광고 소재 반복, 릴스 미활용, 셀러 후기 부재 등)
- 약점 기반으로 맞춤 DM 초안 생성
- WhatsApp으로 "이 브랜드, 이 초안으로 보낼까요?" 알림
- 나는 확인 → 수정 → 전송. 한 건당 15분이 3분으로.

**시나리오 B — 콘텐츠 풀세트 자동 생성**
OpenClaw가 매일 아침 자동으로:
- 이야기 자본 DB에서 오늘 쓸 소재 선정
- 카피 초안 생성 (성희님 8원칙 적용)
- 그 카피에 맞는 이미지 프롬프트까지 세팅
- Claude Code에 이미지 생성 작업 자동 트리거
- 완성된 카피 + 이미지 세트를 WhatsApp으로 전송
- 아침에 일어나면 "오늘 콘텐츠 3세트 준비됐어요"가 와 있는 구조.

**시나리오 C — 광고 데이터 보고서 자동 생성**
- 크론잡으로 매주 정해진 시간에 자동 실행
- 광고 플랫폼에서 데이터 크롤링/API 호출
- 클라이언트별 핵심 지표 자동 정리 (ROAS, CPC, CTR, 매출 등)
- 이상치나 주목할 변화 자동 코멘트 ("이번 주 CTR 23% 하락, 소재 피로도 의심")
- 보고서 초안을 클라이언트별로 생성
- WhatsApp으로 "3개 브랜드 주간 보고서 준비됐어요" 알림
- 나는 코멘트 확인하고 한두 줄 수정해서 전달만.

### 공통 구조
세 시나리오 모두 **"내가 판단만 하고, 실행은 OpenClaw가 하는"** 구조다.
