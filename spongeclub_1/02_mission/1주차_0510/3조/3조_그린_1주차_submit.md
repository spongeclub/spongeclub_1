### 공유할만한 인사이트

1. **첫 결정에 갇히지 말 것** — 인터뷰 직후 진짜 답이 떠오르는 일이 자주 있음. 결과를 갈아끼울 수 있어야 인터뷰가 작동한 것
2. **인터뷰만으론 부족, 실물 점검을 끼워라** — 노션을 *직접 열어본 후* 통점 정의가 한 단계 깊어졌음
3. **AI 효과 큰 것 vs 외주 가능한 것을 먼저 분리** — 도구 깔면 끝나는 건 외주, 스킬은 AI가 끼어야 시간 돌아오는 영역에만
4. **AI가 짠 분류·모델은 첫 시도에 완벽 X** — 사용자가 메타 시각으로 잡아줘야 함 (이번에 4번 교정함)
5. **환경 자산을 먼저 확인** — 이미 있는 MCP/스킬을 활용하면 부품 형태가 가벼워짐 (B → A로 단순화)
6. **안전 모델은 처음부터 디자인** — 특히 삭제·외부 전송. archive만, 사전 격리, 7일 복구

# notion-cleaner 🧹

흩어진 노션을 — AI가 1차 분류해서 묶어주고, 카테고리 단위로 일괄 archive하는 스킬. 사용자가 한 페이지씩 결정하지 않게.

## When to use this skill

자동 발동 트리거:
- "노션 정리", "노션 청소", "노션 트리아지", "노션 비우기", "/notion-cleaner"

발동 안 해야 할 상황:
- 노션 페이지 작성·편집 / 단순 검색 / Mac 파일 정리

## How this skill works

5단계. AI는 1차 분류만, 사용자는 카테고리 단위로만 결정.

### Step 1 · 범위 설정
"어느 영역? — (1) 전체 워크스페이스 (2) 특정 페이지/하위 트리 (3) 특정 DB"
⚠️ 첫 라운드는 작게.

### Step 2 · 메타 스캔
Notion MCP로 자동 수집: 페이지 목록, 마지막 수정일, 자식 페이지 수, 본문 길이, 키워드

### Step 3 · 1차 분류 (사유와 함께)
- 💎 보석 후보: 본문 충분 / 자주 수정 / 의미 있는 키워드
- 🪨 쓰레기 후보: 6개월+ 미수정 / 본문 1~2줄 / "혹시몰라 템플릿"
- ⏸ 검토 보류: 애매한 것
- 🔒 건드리지 말 것: 최근 수정 / 자식 많음 / 활발한 트리

### Step 4 · 카테고리별 일괄 결정
"🪨 N개 — YES / 샘플 검토 / 정밀 검토 / 취소"

### Step 5 · 처리 + 리포트
archive(휴지통, 7일 복구 가능) + 결과 리포트

## Harness rules
1. 영역 너무 클 때 → 한 트리부터 권유
2. 분류 사유 약할 때 → 자동으로 ⏸ 보류
3. "다 삭제해" 일괄 위임 → 거부
4. Notion MCP 미발견 → 인증 안내 후 중단
5. 🔒 침범 금지 → 한 번 더 확인

## Output format
스캔 페이지 수, 결과별 개수, archive 미리보기, 다음 청소 예정일이 담긴 리포트 마크다운

## 향후 진화 로드맵
이 스킬은 트리아지(0단계)만 담당. 1단계 카테고라이징 → 2단계 큐레이션 → 3단계 나만의 웹/앱

### 공유할만한 인사이트

#### 1. **OS는 새로 짓는 게 아니다, 이미 가진 걸 살리는 거다**
1년 전 만들어두고 안 쓰던 PARA 그릇으로 회귀한 게 1주차의 진짜 결과. 외국 유튜버 5명 풀이 화려해도, **이미 내 안에 있는 그릇**이 매칭 정밀도가 가장 높았음.

#### 2. **벤치마킹 대상은 멀리 안 가도 된다**
같은 조 동료의 OS가 외국 유튜버보다 통점·환경·언어·문화 공유로 더 잘 맞음. "글로벌 베스트 사례"보다 "내 옆 사람의 살아있는 사례".

#### 3. **계획 vs 만들기 — "만들어보기" 미션은 결과물이 있어야 정직**
다이어그램·로드맵만 그리면 깔끔해 보이지만, 한 사이클이라도 실제로 돌려봐야 학습이 일어남.

#### 4. **카오스에선 패턴이 안 보인다, 분류돼야 통찰이 emerge**
처음엔 "메모 사이의 연결성을 찾자(2단계 큐레이터)" 같은 깊은 본질로 들어갔는데, 자기 데이터의 실제 형태(=정리 안 된 카오스)와 안 맞았음. 1단계(분류)가 끝나야 2단계(통찰)가 가능.

#### 5. **AI 위임은 6원칙으로 명시 — 사고 방지**
- 한 번에 50개 이하로 묶음 단위 처리
- 사용자 승인 전 실행 X (`이동 OK` 시그널 명시)
- 사유 약하면 "보류"로 (강제 분류 X)
- 위험 도구(DB 스키마 수정 등) 권한 ✋ 유지
- 베이스라인 스냅샷 = 사고 시 비교 기준
- "archive" 같은 모호 단어는 옵션 제시할 때 명시 구분

#### 6. **자동화 = 클로드 안 켜도 돌아감**
Claude Code Routines (Pro/Max/Team에서) — cron으로 등록하면 클라우드에서 매주 자동 실행. 무료 한도 내 일회성 실행은 일일 한도 차감 안 됨.
