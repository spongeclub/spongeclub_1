# 🎨 브랜치랑 PR이 뭐야? (초등학생도 이해하는 설명)

## 🌟 한 줄 요약

> 우리 반 미술시간이랑 똑같아요!  
> **각자 자기 종이에 그림 그리고**, **선생님이 게시판에 모아서 붙여줘요.**

---

## 🎨 우리 반 미술시간 이야기

### 📖 상황

우리 반에 **큰 게시판** 하나가 있어요.  
선생님이 말씀하셨어요.

> "이 게시판이 우리 반의 멋진 작품이야!  
> 60명 모두 그림을 그려서 채워보자!"

근데 어떻게 그릴까요? 🤔

---

### ❌ 방법 1: 다 같이 큰 게시판에 동시에 그리기

```
   🖍️🖍️🖍️🖍️🖍️🖍️ ← 60명이 한꺼번에!
       ↓ ↓ ↓ ↓ ↓
   ┌─────────────────────┐
   │                     │
   │   🌀 팔이 부딪혀!     │
   │   💥 그림이 겹쳐!     │
   │   😭 누가 그렸어?     │
   │                     │
   │   (큰 게시판)        │
   └─────────────────────┘
```

**문제점:**
- 😣 팔이 자꾸 부딪혀요
- 😢 친구 그림 위에 내 그림이 덮여요
- 😵 누가 뭘 그렸는지 몰라요
- 🚨 한 명이 실수하면 다 같이 다시!

---

### ✅ 방법 2: 각자 자기 종이에 그리고 직접 붙이기!

#### 1단계 🖐️ 각자 자기 종이 받기

```
   👧 다다     👦 유스     👩 샤인     👨 ...
    │           │           │           │
    ▼           ▼           ▼           ▼
   📄          📄          📄          📄
   내 종이      내 종이      내 종이      내 종이
```

#### 2단계 ✏️ 자기 종이에 자유롭게 그리기

```
   👧 다다     👦 유스     👩 샤인
    🖍️         🖍️         🖍️
    ▼           ▼           ▼
   📄✏️       📄🎨       📄🌸
   (내 그림)   (내 그림)   (내 그림)
```

✨ **동시에 그려도 안 부딪혀요!**

#### 3단계 📸 다 그렸으면 도장 찍기 (커밋!)

```
   👧 다다     👦 유스     👩 샤인
   📄✏️       📄🎨       📄🌸
    │           │           │
    ▼           ▼           ▼
   📸          📸          📸
  "1주차 제출" "꽃 그림 추가" "스케치 완성"
```

✏️ 도장에 **"뭘 했는지" 메모**도 짧게 적어주세요!  
이게 **커밋(commit)** — 작업 내용 기록 남기기.

#### 4단계 🙋 학교에 제출 + 신청서 쓰기 (푸시 + PR)

```
   👧 다다 ──📄✏️─┐
                 │   ┌──────────────────┐
   👦 유스 ──📄🎨─┼──▶│  학교 게시판 신청   │
                 │   │ "이거 붙여주세요"   │
   👩 샤인 ──📄🌸─┘   └──────────────────┘
                          (= PR)
```

📦 종이를 학교 컴퓨터로 옮기는 게 **푸시(push)**  
🙋 "게시판에 붙여주세요" 신청서가 **PR(Pull Request)**

#### 🔍 (보통은 여기서 검사받아요 — 우리 반은 ❌ 생략)

```
   📋 PR 신청서
        │
        ▼
   👩‍🏫 검사 (리뷰)  ← 보통 회사·학교
        │
        ▼
   ✅ OK 사인
        │
        ▼
   게시판에 붙이기
```

> 💡 우리 반은 자율 운영이라 **검사 없이** 바로 다음 단계로!

#### 5단계 🖐️ 본인이 직접 게시판에 붙이기 (셀프 머지!)

```
   👧 다다     👦 유스     👩 샤인
    │           │           │
    ▼           ▼           ▼
   ┌─────────────────────────┐
   │  ✨ 우리 반 게시판 ✨    │
   │                         │
   │  📄✏️ 📄🎨 📄🌸 📄💕    │
   │  📄⭐ 📄🌟 📄🦋 📄🎀    │
   │                         │
   │   (각자 직접 붙임!)      │
   └─────────────────────────┘
```

✋ 검사 없이 **본인이 직접 붙이기** = **셀프 머지(self-merge)**

🎉 **짠! 우리 반 작품 완성!**

---

## 🤔 이게 컴퓨터랑 무슨 상관이야?

**똑같아요!** 단어만 바꾸면 돼요 👇

| 🎨 미술시간 | 💻 컴퓨터 |
|------------|----------|
| 큰 게시판 | **main** (우리 모두의 공식 결과물) |
| 📄 내 종이 | **브랜치 (branch)** = 내 작업 공간 |
| 🖍️ 종이에 그리기 | 옵시디언에서 글쓰기 |
| 📸 다 그렸다고 도장 찍기 | **커밋 (commit)** = 작업 내용 기록 남기기 |
| 💾 종이 보관하기 | **푸시 (push)** = 내 종이를 인터넷에 저장 |
| 🙋 선생님께 제출 | **PR 만들기** (Pull Request) |
| 👩‍🏫 선생님이 게시판에 붙이기 | **머지 (merge)** = main에 합치기 |
| 👩‍🏫 선생님 | **운영자** (다다) |

## 📸 커밋 = "다 그렸다고 도장 찍기"

그림 다 그렸으면 끝일까요? 아직이에요!  
**도장 찍는 단계**가 필요해요. 그래야 컴퓨터가 "오늘 뭘 했는지" 기억해요.

```
   👧 학생: "오늘 그림 다 그렸다!"
              │
              ▼
       🖍️ 그림 + 📝 메모
              │
              ▼
       📸 도장 찍기 (커밋)
              │
              ▼
   "5/3 — 노란 꽃 그렸음" 라고 기록 저장!
```

이걸 **커밋(commit)**이라고 해요.  
도장에 새기는 메모(커밋 메시지)는 **"뭘 했는지"**를 한 줄로!

### ✅ 좋은 도장 메모
- `[mission] 4조 다다 1주차 제출`
- `이미지 추가`
- `오타 수정`

### ❌ 나쁜 도장 메모
- `update` (뭘 했는지 모름!)
- `asdf` (장난 X)
- (비어있음)

> 💡 **언제 도장 찍어요?** 한 작업 단위가 끝났을 때!  
> 글 다 썼을 때 / 이미지 추가했을 때 / 오타 고쳤을 때 등.  
> 옵시디언은 자동 저장되지만 **도장(커밋)은 본인이 직접 찍어야** 컴퓨터가 기록해요.

## 🔄 전체 순서 — 한눈에

```
   ① 종이 받기 (브랜치)
        │
        ▼
   ② 그림 그리기 (작성)
        │
        ▼
   ③ 📸 도장 찍기 (커밋)  ← ⭐ 빠뜨리지 마세요!
        │
        ▼
   ④ 학교에 제출 (푸시) + 신청서 (PR 만들기)
        │
        ▼
   ⑤ 검사받기 (리뷰)  ← 보통은 있음 / 우리 반은 ❌ 생략
        │
        ▼
   ⑥ 게시판에 붙이기 (머지)  ← 셀프 머지!
```

> 💡 보통 회사·큰 학교에서는 ⑤번(리뷰)을 꼭 거쳐요.  
> 우리 반은 자율 운영이라 ⑤번 건너뛰고 본인이 ⑥번까지 해요.

---

## 🔍 보통은 검사받고 붙여요 (리뷰 = review)

회사나 큰 학교에서는 보통 이래요 👇

```
   👧 학생: "선생님, 다 그렸어요!"
              │
              ▼
   👩‍🏫 선생님: "음... 여기 좀 다듬어와"
              │
              ▼
   👧 수정 → 다시 제출 → 선생님 OK ✓
              │
              ▼
   ✨ 게시판에 붙이기
```

다른 사람이 그림을 검사해주는 걸 **리뷰(review)**라고 해요.  
회사에서는 동료 개발자가 코드를 봐주고 OK 사인을 줘야 머지할 수 있어요.

---

## ✨ 우리 반은 검사 없이 직접 붙여요! (셀프 머지)

스폰지클럽은 **자율적인 분위기**라서 검사 과정을 건너뛰어요.

```
   👧 학생: "다 그렸어요!"
              │
              ▼
   👧 학생: "내가 직접 붙일게요!"
              │
              ▼
   ✨ 바로 게시판에 붙이기 ✨
```

이렇게 본인이 PR 만들고 본인이 바로 머지하는 걸 **셀프 머지(self-merge)**라고 해요.

> 💡 **장점:** 빨라요! 검사 기다릴 필요 없음.  
> ⚠️ **주의:** 본인 책임! 자기 종이(브랜치)에만 그렸는지 확인하고 붙이세요.

| | 보통 (회사·큰 학교) | 우리 반 (스폰지클럽) |
|---|------------------|------------------|
| 검사 | 다른 사람이 검사 (review) | ❌ 없음 |
| 머지하는 사람 | 검사한 사람 또는 운영자 | ✅ 본인 (self-merge) |
| 속도 | 검사 기다려야 함 | ⚡ 즉시 |


## ❓ 자주 묻는 질문

**Q. 친구 종이를 봐도 돼?**  
👀 보는 건 OK! 근데 **건드리면 안 돼요.** 각자 자기 종이만 그려요.

**Q. 그림 망쳤어요!! 😭**  
🆗 괜찮아요! **내 종이**니까 다른 친구한테 피해 안 가요.  
내 종이만 다시 그리면 돼요.

**Q. 그냥 큰 게시판(main)에 직접 쓰면 안 돼요?**  
🚫 **자동으로 막혀요!**  
큰 게시판은 잠겨있어서 **반드시 PR을 통해서만** 붙일 수 있어요.  
PR 만들고 → 본인이 머지(셀프 머지)해야 게시판에 들어가요.

**Q. 매주 새 종이를 받아요?**  
📅 **네!** 매주 새 종이가 깔끔해요.  
- 1주차: `mission/4-다다-week01`  
- 2주차: `mission/4-다다-week02`  
- 3주차: `mission/4-다다-week03` ...

**Q. 검사 안 받고 그냥 머지해도 돼요?**  
✅ **네! 우리 반은 검사 생략이에요.**  
본인이 PR 만들고 본인이 바로 머지(셀프 머지)하면 끝!

**Q. 머지하는 걸 깜빡했어요!**  
🆘 GitHub에 들어가서 본인 PR의 **Squash and merge** 버튼 클릭하면 돼요.  
또는 Claude한테 **"내 PR 머지해줘"** 라고 부탁하기.

**Q. 다른 사람 PR도 머지해도 돼요?**  
🙅 **본인 PR만 머지하세요.** 다른 사람 PR은 그 사람이 직접 머지해야 해요.

## 🎁 끝맺음 — 기억할 건 딱 하나!

```
   👧 나      📄 브랜치     📸 커밋     🙋 PR      ✨ 셀프 머지     🎨 main
   ────▶    ────▶       ────▶      ────▶      ────▶          ────▶
   글쓰기   내 공간 만들기 도장 찍기   제출하기    내가 직접 붙이기  공식 결과물
```

> 🌿 **브랜치 → 작업 → 커밋 → 푸시 → PR → 내가 직접 머지** 🎉
