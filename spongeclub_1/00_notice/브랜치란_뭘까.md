> 우리 반 미술시간이랑 똑같아요!

---

## 🎨 우리 반 미술시간 이야기

### 📖 상황

우리 반에 **큰 게시판** 하나가 있어요.  
선생님이 말씀하셨어요.

> "이 게시판이 우리 반의 멋진 작품이야!  
> 60명 모두 그림을 그려서 채워보자!"

근데 어떻게 그릴까요? 🤔

---

### ❌ 방법 1: 다 같이 큰 게시판에 동시에 그리기

```
   🖍️🖍️🖍️🖍️🖍️🖍️ ← 60명이 한꺼번에!
       ↓ ↓ ↓ ↓ ↓
   ┌─────────────────────┐
   │                     │
   │   🌀 팔이 부딪혀!     │
   │   💥 그림이 겹쳐!     │
   │   😭 누가 그렸어?     │
   │                     │
   │   (큰 게시판)        │
   └─────────────────────┘
```

**문제점:**
- 😣 팔이 자꾸 부딪혀요
- 😢 친구 그림 위에 내 그림이 덮여요
- 😵 누가 뭘 그렸는지 몰라요
- 🚨 한 명이 실수하면 다 같이 다시!

---

### ✅ 방법 2: 각자 자기 종이에 그리고 선생님께 제출!

#### 1단계 🖐️ 각자 자기 종이 받기

```
   👧 다다     👦 유스     👩 샤인     👨 ...
    │           │           │           │
    ▼           ▼           ▼           ▼
   📄          📄          📄          📄
   내 종이      내 종이      내 종이      내 종이
```

#### 2단계 ✏️ 자기 종이에 자유롭게 그리기

```
   👧 다다     👦 유스     👩 샤인
    🖍️         🖍️         🖍️
    ▼           ▼           ▼
   📄✏️       📄🎨       📄🌸
   (내 그림)   (내 그림)   (내 그림)
```

✨ **동시에 그려도 안 부딪혀요!**

#### 3단계 🙋 선생님께 제출

```
   👧 다다 ──📄✏️──┐
                  │
   👦 유스 ──📄🎨──┼──▶ 👩‍🏫 선생님 책상
                  │
   👩 샤인 ──📄🌸──┘
```

#### 4단계 ✨ 선생님이 게시판에 예쁘게 정리

```
   ┌─────────────────────────┐
   │  ✨ 우리 반 게시판 ✨    │
   │                         │
   │  📄✏️ 📄🎨 📄🌸 📄💕    │
   │  📄⭐ 📄🌟 📄🦋 📄🎀    │
   │                         │
   │  (선생님이 깔끔하게 정리)│
   └─────────────────────────┘
```

🎉 **짠! 우리 반 작품 완성!**

## 🤔 이게 컴퓨터랑 무슨 상관이야?

**똑같아요!** 단어만 바꾸면 돼요 👇

| 🎨 미술시간 | 💻 컴퓨터 |
|------------|----------|
| 큰 게시판 | **main** (우리 모두의 공식 결과물) |
| 📄 내 종이 | **브랜치 (branch)** = 내 작업 공간 |
| 🖍️ 종이에 그리기 | 옵시디언에서 글쓰기 |
| 💾 종이 보관하기 | **푸시 (push)** = 내 종이를 인터넷에 저장 |
| 🙋 선생님께 제출 | **PR 만들기** (Pull Request) |
| 👩‍🏫 선생님이 게시판에 붙이기 | **머지 (merge)** = main에 합치기 |
| 👩‍🏫 선생님 | **운영자** (다다) |

## ❓ 자주 묻는 질문

**Q. 친구 종이를 봐도 돼?**  
👀 보는 건 OK! 근데 **건드리면 안 돼요.** 각자 자기 종이만 그려요.

**Q. 그림 망쳤어요!! 😭**  
🆗 괜찮아요! **내 종이**니까 다른 친구한테 피해 안 가요.  
내 종이만 다시 그리면 돼요.

**Q. 선생님 없이 그냥 게시판에 붙이면 안 돼요?**  
🚫 **자동으로 막혀요!**  
게시판은 잠겨있어서 선생님(운영자)만 붙일 수 있어요.

**Q. 매주 새 종이를 받아요?**  
📅 **네!** 매주 새 종이가 깔끔해요.  
- 1주차: `mission/4-다다-week01`  
- 2주차: `mission/4-다다-week02`  
- 3주차: `mission/4-다다-week03` ...

**Q. 선생님이 60명 종이 다 못 붙이면 어떡해요?**  
⚡ 걱정 마세요! 운영자는 마법 명령어로 **60장을 한 번에** 붙일 수 있어요.

**Q. 내가 그린 그림이 게시판에 안 보여요**  
🕒 선생님이 아직 안 붙였을 수도 있어요.  
잠깐 기다리거나 운영자한테 "내 PR 머지해주세요!"라고 부탁하세요.
